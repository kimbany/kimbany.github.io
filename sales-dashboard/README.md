# 매출 대시보드

일 · 주 · 월 · 년 매출을 한 화면에서 보고, **브랜드 / 채널 / 제품**으로 쪼개 보는 단일 HTML 앱입니다.
설치 없이 `index.html` 하나면 동작하고, 데이터는 브라우저(localStorage)에만 저장됩니다.

👉 <https://kimbany.github.io/sales-dashboard/>

## 화면 구성

### 1. 한눈에 보기
오늘 · 이번 주 · 이번 달 · 올해 매출을 항상 함께 보여줍니다. 각 카드의 증감률은 **같은 길이의 직전 기간**과 비교합니다.

| 카드 | 비교 대상 |
|---|---|
| 오늘 | 어제 |
| 이번 주 (월~오늘) | 지난주 같은 요일까지 |
| 이번 달 (1일~오늘) | 지난달 같은 날짜까지 |
| 올해 (1/1~오늘) | 작년 같은 기간까지 |

카드를 누르면 그 단위로 아래 화면이 함께 바뀝니다.

### 2. 기간 · 필터
- **단위**: 일 / 주 / 월 / 년 (주는 월요일 시작)
- **범위**: 직접 지정하거나 `최근 30일 / 3개월 / 1년 / 전체` 프리셋
- **브랜드 · 채널**: 칩을 눌러 켜고 끄기 (끈 항목은 모든 집계에서 빠집니다)

### 3. 기간별 매출
막대그래프 + 표(매출 · 수량 · 건수 · 직전 대비 · 비중). 막대나 표의 줄을 누르면 **그 기간만** 아래에서 자세히 봅니다.

### 4. 구분해서 보기
1단계 / 2단계를 골라 계층으로 봅니다. 예) `브랜드 › 채널`, `채널 › 제품`, `제품`만.

**제품은 규격을 합쳐서 보여줍니다.** `사과 3kg`, `사과 1kg`, `사과 5kg [선물용]` 을 하나의 `사과` 로 묶어
`사과 2,114개 53,550,700원` 처럼 표시하고, ▸ 를 누르면 규격별 내역이 펼쳐집니다.
`규격 그대로` 를 누르면 원래 제품명 그대로 볼 수 있습니다.

## 데이터 넣는 법

### 엑셀 · CSV 붙여넣기 (권장)
엑셀에서 표를 복사해 그대로 붙여넣으면 됩니다. 첫 줄이 머리글이면 열을 자동으로 찾습니다.

| 항목 | 인식하는 머리글 |
|---|---|
| 날짜 | 날짜, 일자, 판매일, 주문일, 결제일, date |
| 브랜드 | 브랜드, 브랜드명, brand |
| 채널 | 채널, 판매처, 판매채널, channel, store, mall |
| 제품 | 제품, 제품명, 상품, 상품명, 품목, product, item, sku |
| 수량 | 수량, 개수, 판매수량, qty, quantity |
| 금액 | 금액, 매출, 매출액, 판매금액, 결제금액, amount, sales |
| 단가 | 단가, 판매가, 가격, price |

- 머리글이 없으면 `날짜 · 브랜드 · 채널 · 제품 · 수량 · 금액` 순서로 읽습니다.
- 날짜는 `2026-08-01`, `2026/08/01`, `2026.08.01`, `20260801` 을 모두 인식하고, 못 읽는 줄은 건너뛴 뒤 몇 줄을 건너뛰었는지 알려줍니다.
- 금액이 비어 있고 단가가 있으면 `수량 × 단가` 로 채웁니다.
- 탭 · 쉼표 · 세미콜론 구분, 따옴표로 감싼 값, `87,000` 같은 천 단위 쉼표를 처리합니다.

### 한 건씩 입력
`매출 입력` 탭에서 날짜 · 브랜드 · 채널 · 제품 · 수량 · 단가(또는 금액)를 넣습니다.

## 제품 묶음 규칙

제품명에서 규격으로 보이는 부분을 떼어 묶음 이름을 만듭니다.

- 숫자 + 단위 (`3kg`, `500g`, `2L`, `10개입`, `30구`, `1되`)
- 괄호 안 문구 (`[선물용]`, `(1+1)`)
- `x2`, `1+1`
- 규격이 떨어져 나간 뒤 뒤에 홀로 남는 포장 단위 (`팩`, `박스`, `세트`)

자동으로 잘 묶이지 않은 이름은 `데이터 관리 › 제품 묶음 이름` 에서 직접 고칠 수 있고, 고친 값은 저장되어 계속 적용됩니다.

## 저장 · 내보내기

데이터는 이 브라우저에만 저장됩니다(서버 전송 없음). 다른 기기에서 보려면 `데이터 관리 › CSV 내보내기` 로 받은 파일을
그 기기에서 붙여넣기로 가져오세요.

| 저장 키 | 내용 |
|---|---|
| `sales-dashboard:rows:v1` | 매출 내역 |
| `sales-dashboard:alias:v1` | 직접 고친 제품 묶음 이름 |
