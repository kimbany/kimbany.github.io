스마트스토어 리뷰 수집기

상품 링크를 붙여넣으면 리뷰·문의를 모아서 별점·키워드·옵션까지 정리하고, 구글 시트로 바로 복사합니다.

프록시(Cloudflare Workers) 주소

브라우저는 보안(CORS) 때문에 네이버를 직접 못 부릅니다. worker.js를 Cloudflare에 배포하고 주소를 넣으면 링크만 붙여넣어도 자동 수집됩니다. 배포가 번거로우면 아래 북마클릿 모드를 쓰세요.

북마클릿 모드 — 프록시 없이 쓰기

상품 페이지에서 직접 실행하므로 CORS 제한이 없고 차단 위험도 가장 낮습니다.

  1. 아래 리뷰수집 링크를 북마크바로 드래그해서 등록 (또는 [코드 복사] 후 새 북마크의 URL에 붙여넣기)
  2. 스마트스토어 상품 페이지를 열고 등록한 북마크를 클릭
  3. 무엇을 가져올지 선택 — 1 리뷰 / 2 상품 문의(Q&A) / 3 둘 다
  4. 가져올 페이지 수를 입력 → 수집이 끝나면 결과 JSON이 클립보드에 복사됨
  5. “[리뷰] 탭을 눌러주세요”(또는 [문의] 탭)가 뜨면 그 탭을 클릭 — 그 순간 페이지가 보내는 진짜 요청을 낚아채 이어서 수집합니다 (이미 열려 있다면 정렬을 바꾸거나 2페이지를 누르세요)
  6. 아래 칸에 붙여넣기(Ctrl+V) 후 [불러오기]

그래도 실패하면 진단 정보가 대신 복사됩니다. 그걸 붙여넣어 알려주시면 원인을 잡을 수 있습니다.
