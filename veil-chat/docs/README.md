# Veil — 익명 친구 매칭 앱 기획·설계 문서

> 외모나 사진이 아닌 **"대화"** 로 사람을 만나는 익명 친구 매칭 모바일 앱

본 문서는 PM / UX·UI / 백엔드 아키텍트 / 모바일 개발 관점에서 작성한 **종합 기획·설계서**입니다.

---

## 📌 프로젝트 한 줄 정의

사진·외모를 배제하고 **랜덤 매칭 + 관심사 기반 + 24시간 타임 채팅 + 단계별 친구 전환**으로
"천천히 알아가는 익명 대화"를 제공하는 앱.

## 🎯 핵심 컨셉 4가지

| 키워드 | 설명 |
| --- | --- |
| **익명성** | 실사진 금지, 아바타/아이콘/캐릭터/배경색으로만 표현 |
| **대화 중심** | 음성·영상·사진 공유 없음. 텍스트 대화만으로 상대 판단 |
| **타임 채팅** | 최초 24시간 → 최대 3회 연장 → 친구 전환 |
| **건강한 커뮤니티** | 상대 평가 · 재매칭 금지 · 신고 · 패널티 시스템 |

## 🗂 핵심 도메인 용어

| 용어 | 정의 |
| --- | --- |
| **세션(Session)** | 한 번의 매칭으로 생성된 1:1 대화. 24시간 단위 |
| **연장(Extension)** | 24시간 만료 시 양측 동의로 24시간 추가 (최대 3회) |
| **친구 전환(Befriend)** | 3회 연장 후 상호 친구 신청 → 무제한 채팅 |
| **재매칭 금지(No-Rematch)** | 평가 시 "다시 만나고 싶지 않음" → 자동 차단 |
| **패널티(Penalty)** | 비매너 행동 누적 점수. 5점 시 매칭 정지 |
