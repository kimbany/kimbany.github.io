# Veil — 익명 텍스트 대화 매칭 앱 (현재 상태 정리)

> 다른 대화에 붙여넣어 맥락을 공유하기 위한 요약 문서입니다.
> 마지막 정리 기준: 프로토타입(목업) + 실시간(Firebase) 버전 모두 반영.

---

## 1. 한 줄 소개
**사진·나이·목소리 없이, 오직 글로만 만나는 익명 친구 매칭 서비스.**
관심사가 통하는 익명의 누군가와 시간제한이 있는 대화를 시작하고, 서로 원할 때만 관계를 이어간다.

## 2. 디자인 철학
- **초미니멀 · 텍스트 우선.** 아이콘·색·박스를 최대한 배제.
- 팔레트: 크림 배경(`#FAF8F2`) / 잉크 텍스트(`#26251F`) / 회색(설명) / **빨강은 위험(삭제·차단·제한)에만**.
- **선택·활성 상태 = 밑줄** (주황색 등 색으로 표시하지 않음).
- 아이콘은 거의 없음(‹ 뒤로, · 구분 정도). 아바타·프로필 이미지 없음(닉네임만).
- 일관된 간격 토큰, 하단 텍스트 내비게이션(`매칭 · 대화 · 설정`).

## 3. 핵심 흐름
```
인트로 → 온보딩(닉네임 → 관심사 → MBTI·채팅유형[선택])
     → 매칭 → 24시간 텍스트 대화
     → (종료 시) 연장 결정 : 양쪽 동의해야 +24h  ← 최대 3회
     → 3회 연장 후 : 친구 추가(양쪽 동의) → 시간제한 없음(무제한)
     → 대화 목록 / 설정
```

## 4. 기능 상세

### 4.1 온보딩 / 프로필
- **닉네임**: 직접 입력 또는 **랜덤 생성**. 랜덤은 `[형용사] + [사물]` 조합(예: `고요한 책`, `반짝이는 별`) — 형용사 123개 × 사물 100개.
- **관심사**: **그룹(포괄) → 세부 태그** 2단계 구조. 12개 그룹(음악·영화영상·독서·여행·운동·요리음식·게임·사진·글쓰기·커피·반려동물·밤산책) 아래 세부 태그 약 50개(예: 음악 → 노래 부르기·악기 연주·춤·댄스·콘서트·음악 감상). 온보딩·프로필에서 세부 태그를 **최소 3개 · 최대 8개** 선택. 그룹 헤더로 묶어 표시. (기존 포괄 관심사는 대표 세부 태그로 자동 마이그레이션)
- **MBTI**: 16유형 + 모름 (단일 선택, 선택 사항).
- **채팅 유형**: 가벼운 수다 / 깊은 대화 / 고민 상담 / 취미 이야기 / 아무거나 (단일 선택, 선택 사항).
- 온보딩은 뒤로가기 가능. 각 선택은 밑줄로 표시.

### 4.2 매칭
- "매칭 시작" → 관심사가 통하는 상대와 연결.
- 매칭 성사 시 시스템 메시지: `매칭됐어요 · 관심사 '음악'이 통해요` (받침에 따라 조사 이/가 자동).
- **제외 대상**: 차단한 상대(영구), **종료 후 재매칭 쿨다운(7일) 중인 상대**.

### 4.3 대화 (채팅)
- 기본 **24시간** 타이머. 남은 시간 표시.
- 텍스트 전용. 한글 IME 중복입력 방지 처리.
- 상단 "관리" 메뉴로 관계 관리.

### 4.4 연장 (양쪽 동의 필수)
- 24시간이 끝나면 **연장 결정 단계**로 전환(입력창 → `연장하기 / 종료하기`).
- **결정 시간(그레이스) 12시간** 안에 결정해야 함.
- **양쪽 모두 연장을 선택해야만** 24시간 연장됨. 한쪽이 거절하면 종료.
- 진행도 `n/3` 표시. **3회 연장하면** 그다음 결정 화면이 `친구 추가 / 종료하기`로 바뀜.
- **연장 시간을 놓치면(12h 초과)**: 자연 종료. (차단 아님 → 쿨다운 후 재매칭 가능)

### 4.5 친구
- 3회 연장 후 **친구 추가**(친구 신청 → 상대 수락, **양쪽 동의**).
- 친구가 되면 **시간제한 없음(무제한)**.

### 4.6 종료 / 나가기 / 차단
- **자연 종료 / 그냥 나가기 / 시간 만료** → 종료됨. 차단 아니면 재매칭 가능(쿨다운 7일 후).
- **그냥 나가기 = 패널티 1점** (아래 참고).
- **차단하고 나가기** → 영구 재매칭 금지(패널티 없음).

### 4.7 패널티 / 매칭 제한
- **대화 그냥 나가기 1회 = 패널티 1점.**
- **3점 누적 → 24시간 매칭 제한**(그 후 점수 0으로 리셋).
- 설정 최상단에 `패널티 n/3` 및 제한 중 남은 시간 표시.

### 4.8 재매칭 쿨다운
- 대화가 종료되면 그 상대는 **7일간 재매칭 제외** → 지나면 다시 매칭 풀에 포함.
- **차단은 별개로 영구 제외.**

### 4.9 설정
- **내 정보**: 닉네임·관심사·MBTI·채팅유형 수정 → **저장하기** 눌러야 반영, 저장 시 **7일 수정 잠금**(그 기간 읽기전용).
- **알림**: 새 메시지 알림 / 알림 미리보기 (켜짐·꺼짐 텍스트 토글).
- **친구 목록**: 친구 보기, 각 항목 `차단` 버튼.
- **차단 목록**: `차단 해제`.
- **잠금(PIN)**: 4자리 앱 잠금. 설정/변경/해제/지금 잠그기. 잠금 시 앱 실행마다 PIN 입력. **키보드 숫자 입력 지원**. **계정 삭제도 PIN 확인 후 진행**.
- **이용약관·개인정보**, **로그아웃**, **계정 삭제(모든 정보 삭제)**.

### 4.10 대화 목록 / 삭제
- 진행중·친구·종료된 대화 목록.
- **종료된 대화 삭제**: 채팅방 "관리 → 대화 삭제" 또는 목록에서 **우클릭**(데스크톱). (진행중·친구 대화는 삭제 불가)

## 5. 신고 / 신뢰도 시스템
### 5.1 신고하기 (구현됨 — 프론트/목업)
- 채팅방 **관리 → 신고하기**(심각한 위반 전용). 진행중·연장·친구 대화에서만 노출.
- **신고 사유**(단일 선택): 성희롱·성적 발언 / 협박·위협 / 사기·금전 요구 / 개인정보 요구 / 미성년자 대상 부적절 / 불법 행위 / 기타. **추가 설명(선택, 500자)**.
- **신고 = 자동 차단**(영구 재매칭 금지) + 신고 기록 저장(`veil2_reports`, 패턴 분석용).
- **단건 신고로 즉시 제재하지 않음.** 안내 문구로 명시(반복 패턴 확인 시에만 조치, 허위 신고는 신고자 불이익).

### 5.2 신뢰도 시스템 (기획 — 서버측 미구현)
> 방향만 합의된 상태. 실제 판정 로직은 서버 몫.
- **"처벌"이 아니라 "관계 종료" 중심.** 좋은 사람을 더 연결하는 것이 목표.
- **두 채널 분리**: ① 대화 종료 이유(통계용, 즉시 제재 없음) ② 신고(위 5.1, 심각 위반 전용).
- **단건 신고·차단으로 제재하지 않음.** 반복·일관된 패턴일 때만.
- **숨겨진 신뢰도 점수**(비공개) + **AI/패턴 분석**. 긍정 지표(관계 유지·연장·친구 전환율)를 더 중시.
- **단계적 패널티**: Level 0 정상 → 1 매칭 빈도 감소 → 2 24h 제한 → 3 7일 제한 → 4 영구 정지.

## 6. 기술 / 구조
- **프론트만으로 동작하는 단일 HTML/CSS/JS 파일** (프레임워크 없음).
- 목업 데이터는 **localStorage**에 저장: `veil2_profile`, `veil2_chats`, `veil2_blocks`, `veil2_recent`(쿨다운), `veil2_reports`(신고 기록).
- **실시간 버전(veil-live)**: **Firebase Realtime Database + 익명 로그인**으로 실제 2인 매칭·실시간 채팅. 같은 브라우저 두 탭도 매칭되도록 **탭별 고유 ID** 사용.
- 배포: **GitHub Pages** + 커스텀 도메인 **invedory.com** (master 브랜치 자동 배포).

## 7. 버전(경로)별 차이
| 경로 | 성격 | 상대 |
|---|---|---|
| `invedory.com/veil-demo/` (= `/veil-match/`, `/veil-chat/prototype/`) | **목업 프로토타입** — 위 모든 기능 UI/흐름 | **AI 가짜 상대**(자동 응답, 연장 60~70% 동의 등) |
| `invedory.com/veil-live/` | **실시간 MVP** — 매칭 + 실시간 채팅만 | **실제 사람**(두 창/기기에서 각각 매칭 시 연결) |

- 목업: 혼자서 전체 흐름 테스트 가능. 24h·연장·친구·패널티·PIN·쿨다운 등 전부 시뮬레이션.
- veil-live: 실제 두 사람 연결 검증용. 아직 24h·연장·친구 등 상세 기능은 미포함(매칭+채팅 코어만).

## 8. 남은/열린 항목
- **신고하기 UI는 구현 완료**(관리 메뉴·자동 차단·기록). **신뢰도 점수/AI 패턴 분석/단계적 패널티**는 서버측 몫으로 미구현.
- 기존 "나가기 패널티"를 신뢰도 시스템으로 대체할지 여부.
- veil-live에 목업의 상세 기능(24h·연장·친구·패널티) 이식.
- 쿨다운 기간(현재 7일) 등 수치 조정 여지.
