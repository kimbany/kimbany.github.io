# 01. 서비스 정책서

## 1. 서비스 정의

Veil은 사진·실명·음성·영상을 배제하고 **텍스트 대화만으로** 새로운 사람을 만나는
익명 친구 매칭 서비스입니다. 매칭은 랜덤이며, 사용자는 관심사 일치/불일치를 선택할 수 있습니다.

---

## 2. 가입 및 연령 정책

| 항목 | 정책 |
| --- | --- |
| 가입 가능 연령 | **만 14세 이상** |
| 연령 확인 | 가입 시 **생년월일 입력** (필수) |
| 만 14세 미만 | **가입 불가** (가입 차단 + 안내) |
| 연령 위조 | 적발 시 영구 이용 정지 |

> **정책 근거**: 국내 개인정보보호법상 만 14세 미만은 법정대리인 동의가 필요하여,
> MVP 단계에서는 서비스 단순화를 위해 만 14세 미만 가입을 전면 차단한다.

### 생년월일 검증 규칙
- 클라이언트: 입력값 기준 만 나이 계산 → 14세 미만 시 다음 단계 차단
- 서버: `birth_date` 저장 시 재검증 (`AGE(birth_date) >= 14년`)
- 변경 불가: 가입 후 생년월일 수정은 고객센터 인증 절차로만 가능

---

## 3. 콘텐츠·표현 정책

| 항목 | 정책 |
| --- | --- |
| 실제 사진 | **사용 전면 금지** (프로필·채팅 모두) |
| 프로필 표현 | 기본 아바타 / 아이콘 / 캐릭터 / 배경 색상만 허용 |
| 닉네임 | 중복 불가 + 욕설 필터 적용 |
| 상태메시지 | 자유 입력 (욕설 필터 적용) |
| 채팅 사진 전송 | **비공개(불가)** — 텍스트만 |
| 음성·영상 통화 | **제공하지 않음** |

### 욕설/비속어 필터
- 닉네임·상태메시지·채팅에 금칙어 사전(블랙리스트) 적용
- 우회 표현(특수문자 삽입, 자모 분리) 정규화 후 검사
- 채팅 내 금칙어는 마스킹(`***`) 또는 전송 차단 (정책 선택 가능)

---

## 4. 매칭 정책

| 항목 | 무료 | 프리미엄 |
| --- | --- | --- |
| 동시 매칭 인원 | **최대 2명** | **제한 없음** |
| 매칭 조건 | 관심사 일치/불일치 선택 | 동일 |
| 매칭 카운트다운 | 5초 (취소 가능) | 동일 |
| 재매칭 금지 대상 | 매칭 풀에서 제외 | 동일 |

---

## 5. 대화·세션 정책

| 항목 | 정책 |
| --- | --- |
| 채팅 형태 | 1:1 텍스트 채팅 |
| 최초 채팅 시간 | **24시간** |
| 연장 단위 | 24시간 / **최대 3회** |
| 친구 전환 | 3회 연장 완료 후 상호 친구 신청 가능 |
| 친구 채팅 | 무제한 (시간 제한 해제) |
| 남은 시간 표시 | `HH:MM:SS` 카운트다운 |

---

## 6. 평가·제재 정책

- 채팅 **종료 또는 연장 시** 상대 평가 진행 (대화 만족도·예의·재대화 의향)
- 평가에서 **"다시 만나고 싶지 않음"** 선택 시 자동 차단 + 재매칭 금지
- **차단 해제**는 설정 > 친구 관리 > 차단 목록에서 가능
- 신고·비매너 행동은 **패널티 점수**로 누적 (5점 시 매칭 정지)

---

## 7. 신고 정책

| 항목 | 정책 |
| --- | --- |
| 신고 가능 시점 | 대화 중 언제든지 |
| 신고 사유 | 욕설/성희롱/광고/사기/혐오 발언/스팸/기타 |
| 증빙 | 스크린샷 최대 5장 + 추가 설명 |
| 신고 후 처리 | 자동 차단 + 운영자 검토 |
| 허위 신고 | 신고자에게 패널티 부여 가능 |

> **신고 안내문**: "허위 신고 또는 정당한 사유가 아닌 신고는 신고자에게
> 패널티가 부여될 수 있습니다."

---

## 8. 패널티 정책 (요약)

| 누적 | 제재 |
| --- | --- |
| 5점 (1차) | 24시간 매칭 금지 → 24시간 후 초기화 |
| 5점 (2차) | 48시간 매칭 금지 → 48시간 후 초기화 |
| 반복 누적 | 단계적 가중 (상세: [10번 문서](./10-report-penalty.md)) |

패널티 발생 행위: 무단 나가기 / 반복 매칭 취소 / 허위 신고 / 비매너 행동

---

## 9. 개인정보·데이터 정책

- 수집 항목: 이메일, 생년월일, 닉네임, 관심사, (소셜 로그인 식별자)
- 실명·전화번호·사진 미수집
- 종료된 대화 기록은 사용자가 직접 삭제 가능
- 신고 관련 데이터(채팅 로그, 스크린샷)는 분쟁 대응을 위해 일정 기간 보관 후 파기
- 회원 탈퇴 시 개인 식별 데이터 즉시 비식별/삭제 (법정 보관 항목 제외)

---

## 10. 운영 정책

- 24시간 신고 접수, 운영자는 영업일 기준 처리
- 중대 위반(성희롱·불법 행위)은 즉시 이용 정지 가능
- 정책 위반 단계: 경고 → 패널티 → 일시 정지 → 영구 정지
- 미성년자 보호: 14세 이상이라도 청소년 보호 가이드라인 적용
