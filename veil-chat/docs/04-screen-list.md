# 04. 화면 목록 (Screen List)

전체 스크린을 ID·목적·주요 컴포넌트·진입경로 기준으로 정리합니다.

## 1. 인증 / 온보딩

| ID | 화면 | 목적 | 주요 컴포넌트 |
| --- | --- | --- | --- |
| A-01 | 스플래시/시작 | 자동 로그인 판단 | 로고, 로딩 |
| A-02 | 로그인 | 진입 | 이메일/PW, Google, Apple 버튼 |
| A-03 | 비밀번호 찾기 | 재설정 | 이메일 입력, 인증코드 |
| A-04 | 회원가입-생년월일 | 연령 검증 | 날짜 피커, 14세 검증 |
| A-05 | 회원가입-인증 | 이메일/소셜 인증 | OTP/소셜 연동 |
| O-01 | 온보딩-닉네임 | 닉네임 설정 | 입력, 중복확인, 욕설필터 |
| O-02 | 온보딩-상태메시지 | 소개 작성 | 텍스트 입력 |
| O-03 | 온보딩-프로필표현 | 아바타 설정 | 아바타/아이콘/캐릭터/배경색 선택 |
| O-04 | 온보딩-관심사 | 관심사 선택 | 칩 다중선택(최소 3개) |
