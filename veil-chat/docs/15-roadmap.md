# 15. MVP 개발 로드맵

## 1. 범위 전략

- **MVP 핵심 가설**: "사진 없이 텍스트 + 타임 채팅으로도 친구를 만들 수 있다."
- MVP는 **매칭 → 24시간 채팅 → 연장 → 평가/신고**의 핵심 루프에 집중.
- 친구 전환·프리미엄·고급 통계는 핵심 루프 검증 후 단계 확장.

---

## 2. 단계별 범위

### Phase 0 — 기반 (1~2주)
- 레포/CI, 환경(dev/stage/prod)
- DB 스키마(핵심 테이블), 인증(JWT) 골격
- Flutter 앱 셸 + 라우팅 + 디자인 토큰

### Phase 1 — MVP Core (4~6주) ★출시 목표
| 영역 | 포함 |
| --- | --- |
| 인증 | 이메일/Google/Apple 로그인, 비밀번호 찾기, **만 14세 검증** |
| 온보딩 | 닉네임(중복+욕설), 상태메시지, 아바타, 관심사 3개 |
| 매칭 | 일치/불일치, 5초 카운트다운, 큐, **무료 2명 제한** |
| 채팅 | 1:1 텍스트, 24시간 타이머, 실시간(WS) |
| 연장 | 양측 합의 연장(최대 3회) |
| 평가 | 종료/연장 시 평가, "다시 만나고 싶지 않음" |
| 신고/차단 | 나가기 팝업, 신고(사유/설명/스크린샷5), 차단 |
| 패널티 | 5점 → 24/48h 매칭 금지 |
| 알림 | 채팅방별 알림/미리보기, 푸시 |
| 설정 | 내정보/알림/친구관리 기본 |
| 어드민 | 회원/신고/패널티/관심사 관리(최소) |

### Phase 2 — 관계·수익화 (3~4주)
- **친구 전환**(3회 연장 후 신청/수락), 친구 목록 분리 관리
- **프리미엄**(동시 매칭 무제한, 결제 검증, 광고 제거)
- 종료 대화 기록/삭제, 매칭 우선 큐

### Phase 3 — 고도화 (지속)
- 매칭 알고리즘 튜닝(가중치/쿨다운), 추천 품질
- 어드민 통계 대시보드 확장
- 운영 자동화(어뷰징 탐지), A/B 테스트
- 다국어/접근성

---

## 3. 마일스톤 일정 (예시, ~12주)

```
W1-2   Phase 0  기반 구축
W3-8   Phase 1  MVP Core  ──► 내부 클로즈 베타(W8)
W9     안정화/QA           ──► 스토어 심사 제출
W10-12 Phase 2  친구/프리미엄
이후    Phase 3  고도화(상시)
```

---

## 4. 핵심 마일스톤 & 완료 기준(DoD)

| 마일스톤 | 완료 기준 |
| --- | --- |
| M1 인증/온보딩 | 가입~관심사 설정까지 무오류, 14세 미만 차단 |
| M2 매칭 루프 | 두 기기 매칭→채팅→메시지 실시간 송수신 |
| M3 타임/연장 | 24h 만료 모달, 양측 합의 연장 정상 |
| M4 안전장치 | 평가/신고/차단/패널티 동작, 재매칭 제외 |
| M5 출시 | 스토어 등록, 크래시율 < 1%, 핵심 지표 수집 |

## 5. 핵심 지표 (North Star & 보조)

| 지표 | 의미 |
| --- | --- |
| **첫 매칭 도달률** | 가입 후 24h 내 첫 매칭 비율 |
| 24h 채팅 유지율 | 만료까지 대화 지속 비율 |
| 연장 동의율 | 만료 시 양측 연장 선택 비율 |
| 친구 전환율 | 세션 중 친구 성립 비율 (Phase 2) |
| 신고/세션 비율 | 커뮤니티 건강도 |
| 프리미엄 전환율 | 무료→유료 (Phase 2) |

## 6. 리스크 & 대응

| 리스크 | 대응 |
| --- | --- |
| 콜드 스타트(매칭 풀 부족) | 초기 지역/시간대 집중, 대기 완화 로직 |
| 어뷰징/유해 콘텐츠 | 욕설 필터 + 신고/패널티 + 운영 모니터링 |
| 14세 연령 규제 | 가입 차단 + 청소년 보호 가이드 |
| 실시간 확장성 | Redis adapter, 무상태 API, 오토스케일 |
| 익명성 악용 | 패널티/차단/재매칭 금지 + 신고 증빙 |

## 7. MVP 제외(Out of Scope) 목록

- 음성/영상/사진 전송 (영구 비제공 정책)
- 그룹 채팅
- 정교한 추천(ML) — 규칙 기반으로 시작
- 고급 통계/마케팅 자동화
