# 03. IA 구조도 (Information Architecture)

## 1. 앱 전체 정보 구조 트리

```
Veil App
│
├── 인증 (비로그인 영역)
│   ├── 시작 화면
│   ├── 로그인 (이메일 / Google / Apple)
│   ├── 회원가입
│   │   ├── 생년월일 입력 (만 14세 검증)
│   │   └── 이메일/소셜 인증
│   └── 비밀번호 찾기
│
├── 온보딩 (최초 1회)
│   ├── 닉네임 설정
│   ├── 상태메시지 설정
│   ├── 프로필 표현 (아바타/아이콘/캐릭터/배경색)
│   └── 관심사 선택 (최소 3개)
│
└── 메인 (하단 탭 3개)
    │
    ├── [탭1] 매칭
    │   ├── 매칭 조건 (관심사 일치 / 불일치)
    │   ├── 매칭하기 버튼
    │   ├── 5초 카운트다운 (취소)
    │   └── 매칭 대기/결과
    │
    ├── [탭2] 대화
    │   ├── 진행중인 채팅 (타이머 표시)
    │   │   └── 채팅방
    │   │       ├── 메시지 영역
    │   │       ├── 남은시간 표시
    │   │       ├── 연장/종료 (만료 시)
    │   │       ├── 친구 신청 (3회 연장 후)
    │   │       ├── 알림 설정 (채팅방별)
    │   │       └── 나가기 → 신고/그냥나가기/취소
    │   ├── 친구 목록
    │   │   └── 친구 채팅방 (무제한)
    │   └── 종료된 대화 기록 (직접 삭제 가능)
    │
    └── [탭3] 설정
        ├── 내 정보
        │   ├── 닉네임
        │   ├── 상태메시지
        │   ├── 관심사
        │   └── 아바타
        ├── 알림 설정
        │   ├── 전체 알림
        │   ├── 채팅 알림
        │   └── 대화 미리보기
        ├── 친구 관리
        │   ├── 친구 목록
        │   ├── 차단 목록
        │   └── 차단 해제
        ├── 프리미엄 (구독)
        ├── 패널티/제재 현황
        ├── 약관·개인정보처리방침
        └── 로그아웃 / 회원탈퇴
```

---

## 2. 하단 탭 네비게이션 (Global Nav)

| 탭 | 아이콘 | 라우트 | 핵심 기능 |
| --- | --- | --- | --- |
| 매칭 | 🔀 | `/match` | 조건 선택 + 매칭 시작 |
| 대화 | 💬 | `/chats` | 진행중/친구/종료 대화 |
| 설정 | ⚙️ | `/settings` | 내정보/알림/친구/구독 |

---

## 3. 화면 깊이(Depth) 맵

```
Depth 0 : 하단 탭 (매칭 / 대화 / 설정)
Depth 1 : 채팅방, 친구목록, 종료기록, 내정보, 알림설정, 친구관리, 프리미엄
Depth 2 : 신고화면, 평가화면, 차단목록, 관심사편집, 아바타편집
Depth 3 : 신고 사유 상세, 스크린샷 첨부
```

---

## 4. 콘텐츠 분류 기준

- **대화 탭의 3분류**: 진행중(타이머 ON) / 친구(무제한) / 종료(기록·삭제 가능)
- **친구는 일반 매칭과 물리적으로 분리** 관리 → 별도 목록·별도 채팅 권한
- **재매칭 금지/차단 사용자**는 매칭 풀에서 제외 (IA상 "차단 목록"에서만 노출)

---

## 5. 알림 IA (계층 구조)

```
전체 알림 (마스터 토글)
 └── 채팅 알림 (글로벌)
      └── 채팅방별 알림 (개별)
           ├── 알림 켜기/끄기
           └── 대화 미리보기 켜기/끄기
```
> 상위 토글 OFF 시 하위 알림은 자동 비활성화(우선순위 상위 → 하위).
