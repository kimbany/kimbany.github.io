# 02. 사용자 플로우

전체 사용자 여정을 단계별 플로우로 정리합니다. (텍스트 다이어그램 기준)

---

## 1. 가입 ~ 온보딩 플로우

```
[앱 실행]
   │
   ▼
[로그인/가입 선택]──► 이메일 / Google / Apple
   │
   ├─ (로그인) ─► 메인(매칭 탭)
   │
   └─ (신규 가입)
        ▼
   [생년월일 입력]
        │
        ├─ 만 14세 미만 ─► [가입 불가 안내] ─► 종료
        │
        └─ 만 14세 이상
             ▼
        [이메일/소셜 인증]
             ▼
        [온보딩 시작]
             ▼
   [① 닉네임 입력] ─ 중복확인 + 욕설필터
             ▼
   [② 상태메시지 입력]
             ▼
   [③ 프로필 표현 설정] ─ 아바타/아이콘/캐릭터/배경색
             ▼
   [④ 관심사 선택] ─ 최소 3개
             ▼
   [온보딩 완료] ─► 메인(매칭 탭)
```

---

## 2. 매칭 플로우

```
[매칭 탭]
   │
   ▼
[매칭 조건 선택]
   □ 관심사 일치
   □ 관심사 불일치
   │
   ▼
[매칭하기 버튼]
   │
   ├─ 무료 사용자 & 진행중 채팅 2개 ─► [매칭 불가 안내 / 프리미엄 유도]
   │
   ├─ 패널티 매칭 금지 상태 ─► [금지 안내 + 남은 시간]
   │
   └─ 매칭 가능
        ▼
   [5초 카운트다운]  5→4→3→2→1   [취소]
        │
        ├─ (취소) ─► 매칭 탭 복귀  (반복 취소 시 패널티 누적)
        │
        └─ (5초 경과)
             ▼
        [매칭 큐 진입]
             ▼
        ┌─ 상대 발견 ─► [세션 생성] ─► [채팅방 입장]
        └─ 일정시간 미발견 ─► [대기/재시도 안내]
```

---

## 3. 채팅 ~ 만료 ~ 연장 플로우

```
[채팅방]  남은시간 23:59:59 ↓
   │
   │  (대화 진행)
   ▼
[24시간 만료]
   │
   ▼
[양쪽에 연장 여부 표시]
   ┌───────────────┐
   │ 연장하기 / 종료하기 │
   └───────────────┘
        │
   ┌────┴───────────────┐
   ▼                    ▼
[종료 선택]          [연장 선택]
   ▼                    ▼
[상대 평가]          [상대 평가]
   ▼                    ▼
[세션 종료]          [추가 24시간 연장]
                        │
                  연장 횟수 < 3 ? ── 예 ─► 채팅 계속
                        │ 아니오(3회 완료)
                        ▼
                  [친구 신청 가능 상태]
```

> **연장 합의 규칙**: 양쪽 모두 "연장하기"를 선택해야 연장 성립.
> 한쪽이라도 "종료하기" 선택 시 세션 종료 (양측 평가 진행).

---

## 4. 친구 전환 플로우

```
[3회 연장 완료]
   │
   ▼
[친구 신청 버튼 활성화]
   │
   ├─ A가 신청 ─► B에게 알림
   │
   └─ B 수락 ?
        ├─ 수락 ─► [친구 성립]
        │            ▼
        │      무제한 채팅 / 친구 목록 이동 / 일반 매칭과 분리
        │
        └─ 거절 ─► [세션 종료 + 평가]
```

---

## 5. 나가기·신고 플로우

```
[채팅방] ─ 나가기 버튼
   │
   ▼
[팝업]
 1. 신고 후 나가기
 2. 그냥 나가기
 3. 취소
   │
   ├─ (1) 신고 후 나가기 ─► [자동 차단] ─► [신고 화면]
   │         ▼
   │   사유 선택 + 설명 + 스크린샷(최대 5장) ─► [제출] ─► 운영 검토
   │
   ├─ (2) 그냥 나가기 ─► [즉시 종료] ─► (패널티 부여 가능)
   │
   └─ (3) 취소 ─► 채팅방 복귀
```

---

## 6. 평가 플로우

```
[세션 종료 or 연장 시점]
   ▼
[상대 평가 화면]
 · 대화가 즐거웠나요? (5점 척도)
 · 예의가 있었나요? (5점 척도)
 · 다시 대화하고 싶나요? (예/아니오)
 · 추가 의견 (최대 500자)
 □ 다시 만나고 싶지 않음
   ▼
[제출]
   ├─ "다시 만나고 싶지 않음" 체크 ─► 자동 차단 + 재매칭 금지
   └─ 평가 데이터 저장 ─► (상대 매너 점수 반영)
```

---

## 7. 상태 전이 요약 (세션 라이프사이클)

```
MATCHING ─► ACTIVE ─► EXPIRING ─┬─► EXTENDED ─► ACTIVE (최대 3회)
                                 ├─► ENDED (평가 완료)
                                 └─► FRIEND (친구 전환)

ACTIVE ─(나가기/신고)─► ENDED / BLOCKED
```
