# 12. 관리자 페이지 설계

> 별도 웹 어드민 (React + TypeScript). 관리자 인증(JWT + 역할 기반 RBAC).

---

## 1. 관리자 역할(RBAC)

| 역할 | 권한 |
| --- | --- |
| super | 전체 + 관리자 계정 관리 |
| operator | 신고/패널티/회원 제재 처리 |
| viewer | 통계·조회만(읽기 전용) |

---

## 2. 어드민 메뉴 구조

```
Admin Web
├── 대시보드 (통계)
├── 회원 관리
│   ├── 회원 검색/상세
│   ├── 상태 변경 (정지/해제/탈퇴)
│   └── 패널티/세션 이력
├── 신고 관리
│   ├── 신고 큐 (pending/reviewing)
│   ├── 신고 상세 (로그+스크린샷)
│   └── 처리 (resolved/rejected)
├── 차단 관리
│   └── 차단 관계 조회/해제
├── 패널티 관리
│   ├── 패널티 부여/회수
│   └── 제재 현황(매칭 금지)
├── 관심사 관리
│   ├── 관심사 추가/수정/비활성화
│   └── 정렬 순서
├── 금칙어 관리 (욕설 필터 사전)
└── 통계
    ├── 가입/활성 사용자
    ├── 매칭/세션/연장/친구 전환
    └── 신고/패널티 추이
```

---

## 3. 주요 화면 명세

### 3.1 대시보드
- KPI 카드: DAU/MAU, 신규 가입, 진행중 세션, 미처리 신고 수
- 그래프: 일별 매칭 수, 친구 전환율, 신고 추이

### 3.2 회원 관리
| 기능 | 설명 |
| --- | --- |
| 검색 | 이메일/닉네임/ID |
| 상세 | 프로필, 관심사, 패널티 점수/strike, 세션 이력 |
| 제재 | active/suspended/banned 전환, 기간 지정 |
| 매칭 금지 | match_banned_until 수동 설정/해제 |

### 3.3 신고 관리 (핵심)
| 기능 | 설명 |
| --- | --- |
| 큐 | 상태/사유/접수일 필터, 중대 사유 우선 정렬 |
| 상세 | 신고 사유·설명·스크린샷, 해당 세션 채팅 로그 |
| 처리 | resolved(+패널티/정지) / rejected(+허위신고 패널티) |
| 메모 | admin_note 기록(감사) |

### 3.4 관심사 관리
- 마스터(`interests`) CRUD, `is_active`, `sort_order`
- 신규 관심사 추가 시 앱에 즉시 반영(캐시 무효화)

### 3.5 통계
- 매칭 성공률, 평균 연장 횟수, 친구 전환율
- 모드별 비중(similar vs different)
- 패널티/제재 발생 추이, 재범률

## 4. 어드민 API (예시)

| Method | Endpoint | 설명 |
| --- | --- | --- |
| GET | `/admin/users` | 회원 목록/검색 |
| GET | `/admin/users/:id` | 회원 상세 |
| PATCH | `/admin/users/:id/status` | 상태 변경 |
| POST | `/admin/users/:id/penalty` | 패널티 부여/회수 |
| GET | `/admin/reports` | 신고 큐 |
| PATCH | `/admin/reports/:id` | 신고 처리 |
| GET | `/admin/blocks` | 차단 조회 |
| DELETE | `/admin/blocks/:id` | 차단 해제 |
| CRUD | `/admin/interests` | 관심사 관리 |
| CRUD | `/admin/banned-words` | 금칙어 관리 |
| GET | `/admin/stats/*` | 통계 |

> 모든 어드민 액션은 감사 로그(`admin_audit_logs`)에 기록 권장.

## 5. 보안

- 관리자 별도 도메인/네트워크 분리, IP 화이트리스트(옵션)
- 2FA 권장, 세션 타임아웃 짧게
- 개인정보 최소 노출(마스킹), 채팅 로그 접근은 신고 건에 한정
