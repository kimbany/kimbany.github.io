# 09. 프리미엄 요금제 정책

## 1. 요금제 개요

| 구분 | 무료 (Free) | 프리미엄 (Plus) |
| --- | --- | --- |
| 동시 매칭 인원 | **최대 2명** | **제한 없음** |
| 매칭 조건(일치/불일치) | ✅ | ✅ |
| 24시간 타임 채팅 | ✅ | ✅ |
| 연장(최대 3회) | ✅ | ✅ |
| 친구 전환 | ✅ | ✅ |
| 광고 노출 | 있음 | 없음 |
| 프로필 아바타 기본 세트 | ✅ | ✅ + 프리미엄 전용 세트 |
| 매칭 우선순위 | 일반 | **우선 큐** |
| 읽음 표시/입력중 표시 | 제한 | ✅ |

> MVP 핵심 차별점은 **동시 매칭 인원 제한 해제**. 나머지는 단계적 도입.

---

## 2. 가격 정책 (예시)

| 플랜 | 가격(원) | 비고 |
| --- | --- | --- |
| 월간 | 4,900 / 월 | 자동 갱신 |
| 분기 | 12,900 / 3개월 | 약 12% 할인 |
| 연간 | 39,000 / 년 | 약 33% 할인 |

- 결제: Apple In-App Purchase / Google Play Billing
- 영수증 서버 검증 후 `users.is_premium`, `premium_until` 갱신
- 무료 체험: 7일(선택, 남용 방지 위해 1계정 1회)

---

## 3. 권한 적용 로직

```
매칭 요청 시:
  if user.is_premium and premium_until > now():
      maxConcurrent = ∞
  else:
      maxConcurrent = 2

  activeSessions = count(sessions where me in (a,b) and status in (active, expiring))
  if activeSessions >= maxConcurrent:
      → MATCH_LIMIT 에러 (프리미엄 유도 화면)
```

- 구독 만료 시: 신규 매칭만 2명 제한, **기존 진행 세션은 유지**(불이익 최소화)
- 우선 큐: 프리미엄 사용자는 매칭 큐에서 가중치 부여(대기 시간 단축)

---

## 4. 업셀(Up-sell) 동선

| 트리거 | 노출 위치 |
| --- | --- |
| 동시 2명 초과 매칭 시도 | M-05 매칭 불가 화면 |
| 광고 시청 후 | 인터스티셜 종료 시점 |
| 설정 진입 | S-08 프리미엄 메뉴 상단 배너 |

---

## 5. 환불·해지 정책

- 해지: 스토어 구독 관리에서 처리, 만료일까지 권한 유지
- 환불: 각 스토어 환불 정책 준수
- 해지 후 재구독 시 무료 체험 미제공

---

## 6. 정책상 주의

- 미성년자(만 14~18세) 결제는 법정대리인 동의 고지 필요
- 프리미엄이라도 패널티·신고·차단 규정은 동일 적용 (제재 면제 없음)
