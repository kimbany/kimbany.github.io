# 05. UX 시나리오

페르소나 기반 핵심 시나리오와 엣지 케이스를 정리합니다.

---

## 1. 페르소나

### 페르소나 A — "지민" (22세, 대학생)
- 외모 평가 없이 편하게 대화할 친구를 원함
- 낯가림이 있어 천천히 알아가는 방식을 선호
- 게임·애니메이션·음악 관심사

### 페르소나 B — "현우" (29세, 직장인)
- 퇴근 후 가벼운 대화로 스트레스 해소
- 새로운 관점(관심사 불일치)에 흥미
- 투자·IT·여행 관심사

### 페르소나 C — "운영자 민지"
- 신고·패널티를 빠르게 처리해 커뮤니티 건강 유지

---

## 2. 핵심 시나리오

### 시나리오 1 — 첫 매칭과 24시간 대화 (지민)

1. 지민은 가입 후 관심사로 게임·애니·음악을 선택한다.
2. 매칭 탭에서 **"관심사 일치"** 를 체크하고 매칭하기를 누른다.
3. 5초 카운트다운이 흐른다. (마음이 바뀌면 취소 가능)
4. 게임·애니 관심사가 겹치는 상대와 매칭된다.
5. 채팅방 상단에 **23:59:59** 타이머가 보인다.
6. 부담 없이 대화하다 24시간이 지나면 연장/종료 선택지가 뜬다.
7. 둘 다 "연장하기"를 눌러 평가 후 24시간이 추가된다.

> **UX 포인트**: 타이머는 "끝이 있는 대화"라는 가벼움을 주어 진입 장벽을 낮춘다.

---

### 시나리오 2 — 관심사 불일치 매칭 (현우)

1. 현우는 새로운 자극을 원해 **"관심사 불일치"** 를 선택한다.
2. 투자에 전혀 관심 없는, 예술·반려동물 관심사 상대와 매칭된다.
3. 서로 다른 세계의 이야기를 나누며 신선함을 느낀다.

> **UX 포인트**: 불일치 옵션은 "에코챔버 탈출" 가치를 제공한다.

---

### 시나리오 3 — 친구 전환 (지민 → 친구)

1. 마음이 맞은 상대와 **3회 연장(총 4일)** 을 마친다.
2. 채팅방에 **"친구 신청"** 버튼이 활성화된다.
3. 지민이 신청 → 상대가 수락 → 친구 성립.
4. 채팅방이 친구 목록으로 이동하고 **타이머가 사라진다(무제한)**.

> **UX 포인트**: 친구 전환은 충분히 알아간 뒤의 "보상"으로 설계.

---

### 시나리오 4 — 무료 사용자 매칭 제한

1. 지민은 이미 2개의 채팅이 진행 중이다.
2. 매칭하기를 누르면 **M-05(매칭 불가)** 화면이 뜬다.
3. "동시 2명까지 가능. 프리미엄은 무제한" 안내 + 구독 유도.

> **UX 포인트**: 제한은 명확한 사유 + 업셀 동선으로 전환.

---

### 시나리오 5 — 신고 후 나가기

1. 상대가 광고성 메시지를 반복 전송한다.
2. 현우가 **나가기** → 팝업에서 **"신고 후 나가기"** 선택.
3. 즉시 자동 차단되고 신고 화면 진입.
4. 사유 "광고" 선택, 스크린샷 2장 첨부, 설명 입력 후 제출.
5. 허위 신고 경고문을 확인하고 접수 완료.

---

### 시나리오 6 — 평가 시 재매칭 금지

1. 대화가 불쾌했던 지민은 종료를 선택한다.
2. 평가 화면에서 낮은 점수 + **"다시 만나고 싶지 않음"** 체크.
3. 해당 상대는 자동 차단 + 재매칭 풀에서 제외된다.
4. 나중에 마음이 바뀌면 설정 > 차단 목록에서 해제 가능.

---

## 3. 엣지 케이스 & 처리

| 케이스 | 처리 |
| --- | --- |
| 카운트다운 중 앱 종료 | 매칭 취소 처리 (큐 미진입) |
| 매칭 대기 중 상대 없음 | 일정 시간 후 재시도/취소 안내 |
| 연장 시 한쪽만 동의 | 종료로 처리, 양측 평가 |
| 24시간 만료 시 오프라인 | 재접속 시 연장/종료 모달 노출 (유예시간 정책) |
| 반복 매칭 취소 | 패널티 누적 → 경고 → 매칭 금지 |
| 그냥 나가기 반복 | 패널티 부여 |
| 친구 신청 거절 | 세션 종료 + 평가, 재신청 제한 |
| 차단 상대 재매칭 | 매칭 풀에서 원천 제외 |
| 닉네임 욕설/중복 | 실시간 검증 에러 표시 |
| 14세 미만 가입 시도 | 가입 차단 + 안내 |

---

## 4. UX 원칙 (Design Principles)

1. **가벼움**: 타임 채팅으로 부담 없는 시작
2. **안전함**: 신고·차단·패널티를 어디서나 즉시 접근
3. **명확함**: 제한·만료·연장 상태를 항상 가시화 (타이머·뱃지)
4. **익명성 보호**: 사진·실명·연락처 노출 경로를 UI에서 원천 차단
5. **점진적 친밀감**: 매칭 → 연장 → 친구로 이어지는 단계적 관계 형성
