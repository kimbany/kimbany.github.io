⚙️ 백엔드 설정 (Cloudflare Worker 배포 안내)

샤오홍슈는 공식 공개 API가 없어 백엔드 서버에서 우회 요청해야 합니다. 무료 Cloudflare Workers를 사용합니다.

  1. Cloudflare 계정 만들기 (무료 가입)
  2. Workers & Pages → Create Worker → 이름 정하고 Deploy
  3. "Edit code" 클릭 → 우리 저장소의 xhs-search/worker.js 내용 통째로 붙여넣기 → Save and Deploy
  4. 발급된 Worker URL (예: https://xhs-proxy.your-name.workers.dev) 복사
  5. 아래에 붙여넣고 저장:

백엔드 코드: xhs-search/worker.js (저장소에 포함됨)
