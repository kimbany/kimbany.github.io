# CLAUDE.md — 네이버 쇼핑 통합 대시보드

> 이 문서는 Claude Code 세션 연속성을 위한 프로젝트 청사진이다.
> 새 세션 시작 시 이 파일을 먼저 읽고 현재 상태를 파악할 것.
>
> 배포 위치: `kimbany.github.io/market-research/` (모노레포 성격 저장소의 하위 폴더)

## 1. 프로젝트 개요

네이버 검색 API + 데이터랩 쇼핑인사이트를 한 화면에서 보는 시장조사 대시보드.
반려동물 이커머스(ZEAL, Ziwi, 아첨 등) 운영을 위한 경쟁 모니터링·가격추적·트렌드 분석 도구.

**한 문장 목표**: 키워드 하나 검색하면 상품·가격·판매처·관심도 트렌드·인구통계가 한 번에 정리되는 PWA.

## 2. 기술 스택 (고정 — 변경 금지)

- **프론트**: 단일 HTML + Tailwind CSS(CDN) + Chart.js(CDN), Vanilla JS
- **API 프록시**: Cloudflare Workers (네이버 API는 브라우저 CORS 차단 → 프록시 필수)
- **배포**: GitHub Pages (정적) + PWA(manifest + service worker)
- **저장**: localStorage (프록시 주소만 저장, 서버 상태 없음)
- **코드 주석**: 한국어

> 이 스택은 운영자의 기존 프로젝트(WMS, 벤딩매니저 등)와 동일. 새 라이브러리·프레임워크 도입하지 말 것.

## 3. 파일 구조

```
market-research/
├── index.html      # 대시보드 본체 (단일 파일, 모든 JS 인라인)
├── worker.js       # Cloudflare Workers 프록시 (별도 배포)
├── manifest.json   # PWA 매니페스트
├── sw.js           # 서비스 워커 (앱 셸 캐싱)
├── icon-192.png    # (선택) PWA 아이콘
├── icon-512.png    # (선택) PWA 아이콘
└── README.md       # 배포 가이드
```

## 4. 아키텍처

```
[브라우저 대시보드]  ──fetch──▶  [Cloudflare Workers]  ──▶  [네이버 오픈API]
 GitHub Pages 정적                 CORS 우회 + 키 은닉         검색 / 데이터랩
```

- 대시보드는 절대 네이버를 직접 부르지 않는다 (CORS + Secret 노출 방지).
- Workers가 `X-Naver-Client-Id/Secret` 헤더를 붙여 중계.
- **프록시 미설정 시 데모 데이터로 폴백** → UI 개발/검증이 키 없이 가능.

## 5. 데이터 모델

### 5.1 검색 API 응답 (상품 1건)
| 필드 | 의미 | 용도 |
|---|---|---|
| title | 상품명(`<b>` 태그 포함) | stripTag 후 표시 |
| lprice / hprice | 최저가 / 최고가 | 가격 분석 |
| mallName | 판매처("네이버"=가격비교묶음) | 판매처 분포 |
| link | 상품 URL | 링크 |
| image | 썸네일 | (현재 미표시) |
| productId | 상품 ID | 식별 |
| productType | "1"=가격비교카탈로그, "2"=단독상품 | 유형 배지 |
| brand / maker | 브랜드/제조사(비어있을 수 있음) | 브랜드 집계 |
| category1~4 | 카테고리 4단계 | 카테고리 매핑 |
| (응답 최상단) total | 전체 검색 결과 수 | 키워드 경쟁강도 |

### 5.2 데이터랩 응답
- `results[].data[].period / ratio` — 기간별 상대지수(최댓값 100 기준, 절대 판매량 아님)
- 인구통계(age/gender/device): `results[0].data[].group / ratio` 형태 → `mapRatios()`로 그룹 평균 집계
- 차원: 키워드 비교 / 연령 / 성별 / 기기(PC·모바일)

## 6. Workers 엔드포인트 (worker.js에 구현됨)

| 경로 | 메서드 | 대상 네이버 API |
|---|---|---|
| `/search` | GET | search/shop.json |
| `/datalab` | POST | datalab/shopping/category/keywords |
| `/datalab-age` | POST | .../keyword/age |
| `/datalab-gender` | POST | .../keyword/gender |
| `/datalab-device` | POST | .../keyword/device |

- 환경변수: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` (하드코딩 금지)
- `ALLOWED_ORIGINS`에 본인 GitHub Pages 도메인 등록 필요

## 7. 화면 구성 (4개 탭)

1. **개요** — 통계카드(결과수/최저가/평균가/브랜드수) + 판매처 분포 막대 + 가격 히스토그램
2. **상품·가격** — 상품 테이블, 가격순 정렬, 가격비교만 필터
3. **키워드 트렌드** — 다중 키워드 관심도 라인차트(최근 12개월) + 데이터랩 카테고리 드롭다운
4. **연령·성별·기기** — 인구통계 차트 (실API 3개 병렬 호출)

## 9. 알려진 제약 (중요)

- 검색 API는 **인기순/실제 쇼핑 랭킹 정렬 미지원** (sim/date/가격순만).
- **리뷰수·평점·판매량·찜수** → 공식 API에 없음. 필요 시 페이지 파싱(스크린샷 등) 별도 트랙.
- 검색 결과 최대 100건(display 100 / start 1000 한계).
- 데이터랩은 **상대지수**지 절대 판매량이 아님.
- 무료 호출 한도: 검색 25,000/일, 데이터랩 1,000/일 수준 (초과 주의).
- 인구통계 응답의 `group` 키 표기는 API 문서 기준(age: "10"~"60", gender: "f"/"m",
  device: "pc"/"mo")으로 매핑. 실제 응답 키가 다르면 `mapRatios()` order 인자 조정 필요.
