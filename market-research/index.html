SKU를 설정하고 오늘 수집을 누르면, 내 가격과 쿠팡·네이버 경쟁상품을 kg당가로 비교해줍니다.

※ 방식 A(검색 API): 검색 대표가 기준, 옵션·배송비 미반영 → 'kg당가'는 참고 지표입니다. 정밀 비교(옵션별 가격·배송비)는 상세페이지 수집(2단계)이 필요해요. 등급 매칭: A 완전동일 / B 같은등급(kg당 비교) / C 같은품목.

미설정이면 이 브라우저에만 기록됩니다. Firebase 프로젝트를 만들어 config를 넣으면 영구저장으로 전환돼요.

키워드를 고르고 오늘 수집을 누르면 순위표가 뜨고, 다음날 또 누르면 어제와 자동 비교됩니다.

※ 순위는 네이버 검색 API 순서(참고순위)입니다. 실제 검색화면 "랭킹순"과 다를 수 있어요(정확한 화면순위는 크롬 화면수집=방식B 필요). 리뷰수·구매건수·광고여부는 검색 API 미제공으로 빈칸입니다. 가격은 대표가(최저옵션) 기준.
