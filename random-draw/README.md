# 랜덤 뽑기

참가자와 응모 횟수를 설정하고 무작위로 당첨자를 뽑는 단일 페이지 앱입니다.
빌드 도구·외부 라이브러리 없이 `index.html` 하나로 동작합니다.

열기: <https://kimbany.com/random-draw/>

## 화면

### ⚙️ 뽑기 설정
- **뽑을 인원** — 몇 명을 뽑을지 지정합니다.
- **참가자 목록** — 아이디 또는 이름 입력란을 `+ 입력란 추가`(또는 `+ 5칸 추가`)로 만들고, 각 줄의 `✕`로 지웁니다.
  - 이름 칸에서 `Enter`를 누르면 바로 아래에 새 입력란이 생깁니다.
  - `빈칸 삭제`는 이름이 비어 있는 줄만 정리합니다.
- **응모 수** — 기본값 1. 2를 넣으면 그 아이디가 응모권 2장으로 들어가 당첨 확률이 2배가 됩니다.
- **당첨 확률 미리보기** — 1명 뽑을 때 기준으로 각자의 확률을 표와 막대로 보여줍니다.

설정은 브라우저 `localStorage`에 저장되어 새로고침해도 유지됩니다.

### 🎯 뽑기 추첨
- `뽑기 시작`을 누르면 룰렛이 돌다가 당첨자가 확정됩니다.
- 여러 명을 뽑을 때 **한 번 당첨된 참가자는 다시 뽑히지 않습니다**(응모권이 전부 제거됨).
- 뽑을 인원이 참가자 수보다 많으면 참가자 수만큼만 뽑습니다.
- `결과 복사`로 당첨자 명단을 클립보드에 복사합니다.

## 추첨 방식

응모 수만큼 응모권을 만들어 한 장을 고르는 가중 추첨입니다.
난수는 `crypto.getRandomValues`를 쓰고, 나머지 연산 편향을 없애기 위해
상한을 넘는 값은 버리고 다시 뽑습니다(`Math.random`은 지원하지 않는 환경에서의 대체 수단).

예) A=1, B=2, C=3, D=4 → 응모권 10장 → 각각 10% / 20% / 30% / 40%
