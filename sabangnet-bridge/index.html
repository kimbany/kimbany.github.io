준비할 것

가미락 발주 양식과 사방넷 운송장 업로드 양식이 이미 들어 있어서 따로 올릴 것이 없습니다. 아래 두 가지만 처음에 한 번 확인해 주세요.

  1. 설정 탭 → 보내는분 정보 — 몽프루이 김포 주소가 기본으로 들어 있습니다. 바뀌었거나 창고가 여러 곳이면 여기서 추가하고, ① 탭 드롭다운에서 골라 쓰면 됩니다.
  2. 설정 탭 → 상품 변환표 — 매드베리 딸기가 기본으로 등록되어 있습니다. 가미락으로 보내는 품목이 늘면 품목 불러오기를 눌러 목록에서 고르고, 가미락이 쓰는 품목명으로 고쳐 주세요. 여기 등록된 품목만 가미락으로 나갑니다.

매일 쓰는 순서

  1. 아침 — 사방넷 출고 리스트 다운로드 → ① 탭에 올림 → 변환하기 → 엑셀 다운로드 → 가미락에 전달
  2. 오후 — 가미락에서 송장 파일 수신 → ② 탭에 올림 → 변환하기 → 엑셀 다운로드 → 사방넷에 업로드

② 탭은 아침에 ① 탭에 올려둔 사방넷 파일을 자동으로 이어 씁니다(쇼핑몰 주문번호를 사방넷 주문번호로 바꾸는 데 필요합니다). 브라우저를 닫았다 열었다면 ① 탭에 그날 사방넷 파일을 다시 올리기만 하면 ② 탭에 자동으로 연결됩니다. ② 탭 2번 칸에 연결됨이라고 떠 있으면 준비된 것입니다.

가공 옵션

  • 그대로 — 값을 텍스트로 그대로 출력합니다.
  • 숫자 — 숫자로 저장합니다(수량, 금액 등).
  • 숫자만 — 하이픈·공백·문자를 지우고 숫자만 남깁니다(송장번호 등).
  • 전화(하이픈) — 01055556666 → 010-5555-6666 형태로 맞춰줍니다.
  • 우편번호만 — 사방넷 주소는 [352-51] 대전 서구 문예로 16처럼 우편번호가 주소 안에 들어 있습니다. 여기서 35251만 뽑아냅니다.
  • 주소만(우편번호 빼기) — 같은 값에서 앞의 [352-51]을 떼고 대전 서구 문예로 16만 남깁니다.
  • 공백제거 — 앞뒤 공백을 제거합니다.
  • 우편번호([] 포함) — [049-35] 형태 그대로 넣습니다(가미락 양식이 이 형태일 때).
  • 상품명 변환 — 설정 탭의 상품 변환표대로 품목명을 가미락 명칭으로 바꿉니다.
  • 택배사 변환 — 설정 탭의 규칙표대로 이름을 바꿉니다.

채우는 방법

  • 파일에서 가져오기 — 올린 파일의 컬럼 하나를 그대로 씁니다.
  • 여러 컬럼 합치기 — 예를 들어 가미락 양식의 상품명 칸에 상품명(확정) + 옵션별칭을 이어붙여 넣습니다. 구분자(예: / )를 지정할 수 있습니다.
  • 고정값 — 모든 행에 같은 값을 넣습니다(예: 택배사 CJ대한통운, 결제구분 선불).
  • 비움 — 빈 칸으로 둡니다.

참고

  • 업로드한 파일은 어디에도 전송되지 않습니다. 모든 변환은 브라우저에서 처리됩니다.
  • 양식 파일과 매핑 설정은 이 브라우저(localStorage)에 저장됩니다. 브라우저 데이터를 지우면 사라지니 설정 탭에서 백업해 두세요.
  • 양식 파일이 5MB를 넘으면 서식 유지 저장은 사용할 수 없고, 컬럼만 등록됩니다.
  • 양식 파일이 .xls여도 읽을 수 있습니다. 저장은 .xlsx가 기본이며(서식이 더 잘 남습니다), 저장 형식에서 .xls로 바꿀 수 있습니다.
  • 사방넷 파일에 시트가 여러 개면(예: 주문서확인처리_송장출력, Sheet1) 파일명 옆의 시트에서 골라주세요.
