설정 백업 / 복원

양식·매핑 설정은 이 브라우저에 저장됩니다. 다른 PC에서 쓰려면 내보내기 한 파일을 가져오기 하세요.

처음 한 번만 하면 되는 준비

  1. ① 탭에서 A업체 빈 양식 파일을 양식 파일 올리기로 등록합니다.
  2. 사방넷 출고 엑셀을 하나 올린 뒤 자동 매핑을 누르고, 틀린 부분만 손으로 고칩니다.
  3. ② 탭에서 사방넷 운송장 업로드 양식을 등록하고, A업체 송장 파일 샘플로 매핑을 맞춥니다.
  4. 여기까지 하면 설정이 저장되어, 다음부터는 파일 올리기 → 변환하기 → 다운로드 3단계로 끝납니다.

매일 쓰는 순서

  1. 사방넷에서 출고 리스트 다운로드 → ① 탭에 올림 → 변환 → 나온 파일을 A업체에 전달
  2. A업체에서 송장 파일 수신 → ② 탭에 올림 → 변환 → 나온 파일을 사방넷에 업로드

가공 옵션

  • 그대로 — 값을 텍스트로 그대로 출력합니다.
  • 숫자 — 숫자로 저장합니다(수량, 금액 등).
  • 숫자만 — 하이픈·공백·문자를 지우고 숫자만 남깁니다(송장번호 등).
  • 전화(하이픈) — 01055556666 → 010-5555-6666 형태로 맞춰줍니다.
  • 우편번호만 — 사방넷 주소는 [352-51] 대전 서구 문예로 16처럼 우편번호가 주소 안에 들어 있습니다. 여기서 35251만 뽑아냅니다.
  • 주소만(우편번호 빼기) — 같은 값에서 앞의 [352-51]을 떼고 대전 서구 문예로 16만 남깁니다.
  • 공백제거 — 앞뒤 공백을 제거합니다.
  • 택배사 변환 — 설정 탭의 규칙표대로 이름을 바꿉니다.

채우는 방법

  • 파일에서 가져오기 — 올린 파일의 컬럼 하나를 그대로 씁니다.
  • 여러 컬럼 합치기 — 예를 들어 A업체 양식의 상품명 칸에 상품명(확정) + 옵션별칭을 이어붙여 넣습니다. 구분자(예: / )를 지정할 수 있습니다.
  • 고정값 — 모든 행에 같은 값을 넣습니다(예: 택배사 CJ대한통운, 결제구분 선불).
  • 비움 — 빈 칸으로 둡니다.

참고

  • 업로드한 파일은 어디에도 전송되지 않습니다. 모든 변환은 브라우저에서 처리됩니다.
  • 양식 파일과 매핑 설정은 이 브라우저(localStorage)에 저장됩니다. 브라우저 데이터를 지우면 사라지니 설정 탭에서 백업해 두세요.
  • 양식 파일이 5MB를 넘으면 서식 유지 저장은 사용할 수 없고, 컬럼만 등록됩니다.
  • 사방넷 파일에 시트가 여러 개면(예: 주문서확인처리_송장출력, Sheet1) 파일명 옆의 시트에서 골라주세요.
