# 출고 · 송장 양식 변환기

사방넷 출고 리스트를 A업체 발주 양식으로, A업체가 보내준 운송장 파일을 사방넷 운송장 업로드 양식으로
바꿔주는 정적 웹 도구입니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 사용 흐름

1. **① 출고 → 업체 양식** — 사방넷 출고 엑셀 업로드 → 변환 → A업체 전달
2. **② 송장 → 사방넷 양식** — A업체 송장 엑셀 업로드 → 변환 → 사방넷 업로드

## 처음 한 번만 하는 설정 (실제 폼 기준)

- 각 탭에서 상대방 **빈 양식 파일**을 등록하면 컬럼이 자동 등록되고 `localStorage`에 저장됩니다.
- `자동 매핑`으로 컬럼을 이어준 뒤 틀린 부분만 수정하면 다음부터는 업로드 → 변환 → 다운로드 3단계로 끝납니다.
- 지난번 데이터가 남아 있는 양식 파일을 등록하면, 그 견본을 보고 **고정값(보내는분 정보) · 빈칸 · 우편번호 표기 형식**까지 자동으로 맞춥니다.
- 설정 탭의 **상품 변환표**에 A업체 품목명을 등록하면, 품목명 치환과 **보낼 대상 필터**에 함께 쓰입니다.
- 설정은 `설정` 탭에서 JSON으로 내보내기/가져오기 할 수 있습니다.

## 기능

- 양식 파일 서식을 유지한 채 데이터만 채워서 저장 (5MB 이하 xlsx)
- 컬럼별 가공: 그대로 / 숫자 / 숫자만 / 전화(하이픈) / 우편번호만 / 주소만(우편번호 빼기) / 공백제거 / 택배사 이름 변환
- 사방넷 주소(`[352-51] 대전 서구 문예로 16`)에서 우편번호 자동 분리 — 양식에 우편번호 칸이 있으면 자동 매핑 시 알아서 잡아줍니다
- 여러 컬럼 합치기 — 예: A업체 상품명 칸 = `상품명(확정) / 옵션별칭`
- 송장번호는 텍스트로 저장되어 엑셀 지수(E+) 표기로 깨지지 않음
- 송장 파일에 주문번호만 있을 때, 원본 출고 파일과 **주문번호로 조인**해 나머지 값 채우기
  (연결키는 이름이 아니라 **값이 실제로 일치하는 컬럼**을 찾아 자동 선택하고,
  쇼핑몰 주문번호 하나에 사방넷 주문이 여러 건이면 줄을 나눠 같은 송장번호를 넣습니다)
- 보낼 대상 필터 — 품목별로 골라서 A업체 몫만 내보내기
- `.xls` 양식 읽기/쓰기, 헤더 배경색·열너비 등 서식 유지
- 송장번호 없는 행 / 빈 행 자동 제외, 다중 시트 및 머리글 행 지정, CSV(UTF-8·EUC-KR) 지원
