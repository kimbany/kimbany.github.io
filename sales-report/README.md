# 매출 통합 대시보드 (v2)

여러 판매 채널(자사몰 카페24 · 스마트스토어 · 쿠팡 · 11번가 · SSG)에서 받은 매출 엑셀을
업로드하면 **채널 / 브랜드 / 상품 기준으로 통합 집계**하는 단일 HTML 대시보드입니다.

👉 <https://invedory.com/sales-report/>

## 기본 흐름

1. **셋팅 › 채널** 에 판매 채널을 등록 (이름 + 유형: 카페24/스마트스토어/…). 스마트스토어 계정이 브랜드별로 여러 개면 각각 등록.
2. **셋팅 › 브랜드** 에 브랜드 등록 (몽프루이, 귤타민 …).
3. **셋팅 › 상품** 에 상품(사과 등)과 규격을 등록. 규격은 등급/종류(대과·중과·점보 등) + 용량(3kg·5.5kg)으로 입력.
4. **셋팅 › 매칭** 에서 채널별 상품코드를 내 규격에 연결(자동 등장, `+ 새로 만들기`로 즉석 등록 가능).
5. **데이터 입력** 에서 채널·브랜드를 고르고 파일을 올림 → 미리보기 → 저장.
6. **메인 / 매출** 에서 채널별·브랜드별·상품별로 집계 확인.

## 매출 정의 (채널별)

| 채널 | 매출 | 순매출 | 행 고유키 | 취소 |
|---|---|---|---|---|
| **카페24** | 총 상품구매금액(판매가×수량), 주문번호 dedup | 품목별 결제금액(적립·쿠폰 차감 후) | 품목별 주문번호 | 취소구분 ≠ 취소안함 |
| **스마트스토어** | 최종 상품별 총 주문금액(판매가×수량=고객 구매가) | 동일 | 상품주문번호 | 주문상태 취소/반품/환불/교환 |

- 두 채널 모두 **행(품목) 단위 금액**을 그대로 합산하므로, 한 주문에 여러 품목이 있어도 정확합니다.
- 같은 파일을 다시 올려도 행 고유키로 덮어써져 매출이 2배가 되지 않습니다.
- 취소건은 매출에서 빼고 취소 합계로 별도 표시합니다.

## 매칭 (채널 상품코드 → 내 규격)

- 채널마다 상품코드가 다릅니다. **매칭 관리**에서 채널 상품코드(카페24 상품코드/품목코드, 스마트스토어 상품번호/옵션관리코드)를 내 규격에 연결합니다.
- 매칭하면 그 코드의 **과거 매출까지 자동으로 갱신**됩니다.
- 아직 연결 안 된 코드는 상품별 표에 `⚠ 미매칭`으로 보이고, 상단에 미매칭 배지가 뜹니다. (매출 합계 자체는 매칭과 무관하게 정확)

## 화면

- **메인**: 최근 판매일 기준 매출·순매출·수량·취소 + **채널별 · 브랜드별 · 상품별**
  - 상품별은 상품 합계 아래에 등급·규격별 매출이 함께 보입니다 (예: 사과 → 대과 3kg / 대과 5kg / 중과 3kg)
- **매출**: 기간·퀵버튼(오늘/어제/최근7·30일/전체) + 채널·브랜드 필터 + 합계·일평균 + 채널/브랜드/상품 분해 + CSV 내보내기
- **데이터 입력**: 채널·브랜드 선택 → 드래그&드롭 업로드 → 미리보기 → 저장, 일자·채널별 선택 삭제, 업로드 이력·되돌리기
- **셋팅**: 채널 / 브랜드 / 상품·규격 / 매칭 / 기타(JSON 백업·초기화)

## ⚠️ 스마트스토어 파일은 비밀번호를 풀어서

네이버 스마트스토어에서 받은 주문 엑셀은 **비밀번호로 암호화**되어 있어 브라우저에서 바로 못 읽습니다.
엑셀에서 열어 **다른 이름으로 저장 → 비밀번호 없이 저장(또는 CSV)** 한 파일을 올려주세요.
(암호화된 파일을 올리면 그 안내 메시지가 표시됩니다.)

## 데이터 삭제 3단계

1. **날짜 × 채널** 단위 — 데이터 입력의 "일자·채널별 매출" 표에서 삭제
2. **업로드 파일** 단위 — 업로드 이력의 되돌리기
3. **전체** — 셋팅 › 기타 › 전체 초기화

## 클라우드(Firebase) · 로그인

- Firebase(Firestore)에 연결되어 **회사·집·폰 어디서 넣어도 실시간 공유**됩니다.
- 개인정보(구매자명) 보호를 위해 **이메일·비밀번호 로그인**을 거칩니다(계정은 Firebase Authentication 에서 등록).
- 처음 전환 시 로컬에 넣어둔 데이터가 있으면 `셋팅 › 기타 › 이 브라우저 로컬 데이터 올리기`로 클라우드에 올립니다.
- Firebase 미로딩 환경에서는 자동으로 로컬(localStorage) 모드로 동작.

## 기술

- 단일 HTML + Tailwind(CDN) + SheetJS(xlsx) + Firebase(compat SDK).
- 로컬·클라우드 데이터 계층 동일 인터페이스. 클라우드는 전체를 메모리 캐시에 미러링(읽기 동기), 쓰기는 Firestore 반영 + 실시간 구독.
