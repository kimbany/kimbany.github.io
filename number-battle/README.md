# 파티 박스 🎉

번호가 붙은 피규어·랜덤박스를 오프라인에서 재미있게 나누기 위한 **파티게임 웹앱**입니다.
기기 한 대를 돌려가며 쓰는 것을 기준으로 만들었습니다.

👉 **[바로 실행하기](https://invedory.com/number-battle/)**

대메뉴는 두 개입니다.

| 메뉴 | 이런 때 | 방식 |
|---|---|---|
| 🎯 **번호 쟁탈전** | 원하는 번호를 직접 고르게 하고 싶을 때 | 몰래 고르고, 겹치면 미니게임으로 쟁탈 |
| 🎰 **가챠 뽑기** | 그냥 공평하게 운으로 나누고 싶을 때 | 캡슐을 돌려 숫자를 하나씩. 중복 없음 |

---

## 🎯 번호 쟁탈전

1. **설정** — 진행자가 전체 번호 개수(예: 11개)를 정하고 시작합니다.
2. **비밀 선택** — 참가자가 한 명씩 이름을 넣고 원하는 번호를 고릅니다.
   다른 사람이 무엇을 골랐는지, 몇 명이 골랐는지 **전혀 보이지 않습니다.**
   이미 남이 고른 번호도 자유롭게 고를 수 있습니다.
3. **선택 종료** — 진행자가 [진행자] 메뉴에서 종료를 누릅니다.
4. **공개** — 1번부터 하나씩 공개됩니다. `아무도 안 고름` / `단독 선택!` / `N명 중복!`
5. **쟁탈전** — 겹친 번호마다 미니게임으로 **전원의 순위**를 정합니다.
6. **KEEP / PASS** — 1위부터 선택권을 갖습니다.
   - **KEEP** → 그 번호 확정. 같은 번호를 골랐던 나머지는 FINAL 로.
   - **PASS** → 그 번호를 포기하고 **남은 빈 번호를 먼저** 고릅니다. 선택권은 다음 순위로.
   - 마지막 순위까지 넘어오면 **자동 KEEP** 합니다. 그래서 주인 없는 중복 번호는 생기지 않습니다.
7. **FINAL** — 끝까지 번호를 못 얻은 사람들이 마지막 승부로 순위를 정하고, 남은 번호를 차례로 고릅니다.
8. **결과** — 전원이 서로 다른 번호를 하나씩 갖게 됩니다. 그다음 3·2·1 카운트다운과 함께
   **오프라인에서 실제 피규어를 공개**하세요.

### 미니게임

| 단계 | 기본 게임 | 방식 |
|---|---|---|
| 1차 번호 쟁탈전 | 🎯 **럭키 타이밍** | 빠르게 움직이는 게이지를 STOP. TARGET은 전원이 끝난 뒤 공개되고, 차이가 작은 순서로 순위. 동점이면 동점자끼리 재대결 |
| FINAL 순위 결정전 | 🃏 **운명의 카드** | 뒤집힌 카드를 한 장씩 고르고, 전원이 고르면 동시에 공개. 카드 안의 순위가 곧 번호 선택 순서 |

시작 화면에서 두 단계의 미니게임을 서로 바꿔 쓸 수 있습니다.

## 🎰 가챠 뽑기

1. **설정** — 진행자가 숫자 개수(예: 11개)를 정합니다. 캡슐에 1~11이 하나씩 들어갑니다.
2. **뽑기** — 손잡이나 [뽑기] 버튼을 누르면 캡슐이 배출구로 떨어지고 숫자가 공개됩니다.
3. **반복** — 한 명씩 돌아가며 뽑습니다. 전부 나오면 결과 화면으로 넘어갑니다.

- **중복 없음** — 이미 나온 숫자는 통에서 빠지므로 두 번 나오지 않습니다.
- **확률 균등** — 매 뽑기마다 남은 숫자 전체에서 균등하게 뽑습니다.
  남은 게 k개면 각각 나올 확률이 정확히 `1/k` 이고, 화면에도 그렇게 표시됩니다.
- **이름 기록(선택)** — 켜두면 누가 몇 번을 뽑았는지 목록에 남습니다.
- **마지막 뽑기 취소** — 잘못 눌렀을 때 진행자 메뉴에서 되돌릴 수 있습니다.

> 남아 있는 숫자 목록은 진행자 메뉴에서만 볼 수 있습니다. 참가자에게 보이면 재미가 없습니다.

가챠 화면은 **리퀴드 글래스** 톤으로 따로 디자인되어 있습니다. 밝은 배경 위에 두꺼운
유리 패널이 뜨고 가장자리에 프리즘 빛이 번집니다. 손잡이를 돌리면 캡슐이 흔들리다
배출구로 떨어지고, 반으로 갈라지며 숫자가 나옵니다. 숫자와 라벨은 모노스페이스로 정렬되고,
마지막 캡슐에는 프리즘 링과 파티클이 붙습니다.

## 진행자 메뉴

우측 상단 **[진행자]** 버튼. 메뉴마다 내용이 다릅니다.

**공통** — 현재 상태 확인 · 초기화(확인 팝업 필수)

**번호 쟁탈전**
- 시작 시 PIN 을 걸어두면 참가자가 실수로 열 수 없습니다
- 참가 인원 확인 (**번호는 진행자에게도 보이지 않습니다**)
- 선택 종료 / 다음 단계 진행 (연출·대기 화면만 넘기고, 참가자가 직접 눌러야 하는 입력은 건너뛰지 않습니다)
- 빠른 진행 (애니메이션 축소) · 진행 기록

**가챠 뽑기**
- 나온 개수 / 남은 개수 / 다음 확률
- 남은 숫자 목록 (진행자 전용)
- 마지막 뽑기 취소

## 사용 팁

- **기기 한 대를 돌려쓰는 것**을 기준으로 만들었습니다. 번호 쟁탈전에서 비밀 선택이 끝나면
  화면에서 이름·번호가 즉시 사라지니 그대로 다음 사람에게 넘기면 됩니다.
- 진행이 늘어진다 싶으면 진행자 메뉴의 **빠른 진행**을 켜세요.
- 새로고침하거나 브라우저를 닫아도 진행 상황이 유지되고, **두 메뉴는 각각 따로 저장**됩니다.
  가챠를 하다가 홈으로 나가 쟁탈전을 봐도 서로 영향이 없습니다.
  단, 비밀 선택 중이던 이름·번호는 보안상 저장하지 않으므로 그 사람만 다시 입력하면 됩니다.
- 주소 끝에 `#battle` / `#gacha` 를 붙이면 바로 해당 메뉴로 들어갑니다.

## 개발

빌드 도구가 필요 없는 정적 파일입니다. 로컬에서 볼 때는 ES modules 때문에 정적 서버가 필요합니다.

```bash
npx http-server -p 8899 -s .   # 저장소 루트에서
# http://localhost:8899/number-battle/

node tests/engine.test.mjs     # 번호 쟁탈전 로직 (CASE A~H · 경계 · 무작위 400회)
node tests/gacha.test.mjs      # 가챠 로직 (중복 없음 · 확률 균등 χ² 검정)
node tests/layout.mjs          # 반응형 검사 (위 서버가 떠 있어야 함)
```

구조와 확장 방법(새 미니게임 추가 등)은 [`CLAUDE.md`](./CLAUDE.md) 를 참고하세요.
