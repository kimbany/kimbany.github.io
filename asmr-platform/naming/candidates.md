## 최종 후보 (도메인·상표 체크 완료)

### 🟢🟢 Muirang / 물이랑
- **뜻**: 물결이 만드는 이랑 무늬
- **위험도**: 매우 낮음 — 검색 시 겹치는 브랜드·앱·회사 없음
- **도메인**: muirang.com / .co.kr / .app 모두 잡을 수 있을 것으로 보임
- **강점**: 무주공산. 브랜드 자산 확보 유리
- **약점**: 발음 국제화 애매 (Muirang → 뮤이랑? 뮈랑?)

### 🟢 Dalmuri / 달무리
- **뜻**: 달 주위 은은한 빛의 원
- **위험도**: 낮음 — 소규모 지역 카페·포장마차 몇 개, 옛날 KBS 드라마
- **도메인**: dalmuri.com 판매중(프리미엄 가능), .co.kr / .app 잡을 수 있음
- **강점**: 뜻이 즉시 통함. 밤·수면 감성 정확
- **약점**: 검색 시 지역 카페들과 경쟁

### ⚠️ Osroom / 어스름
- **뜻**: 해 진 뒤 어둑어둑한 그 순간
- **위험도**: 중간 — Play Store에 "어스름" 다이어리 앱 이미 있음 + Osroom 오픈소스 프로젝트
- **판단**: 밀어붙일 순 있지만 검색 혼동 있음

### ❌ Sorosi / 소롯이 (사용 안 함)
- **뜻**: 담뿍 온전히 담아
- **위험도**: 높음 — 소로시(sorosi.co.kr)라는 라이프스타일 브랜드 이미 활발
- **판단**: 사용 지양

## 유보 중인 예쁜 후보들 (다시 볼 때 참고)

**감정·사람 계열**
- 그린내 (사랑하는 이)
- 눈부처 (눈동자에 비친 서로의 모습)
- 아띠 (친한 친구)
- 봄내 (봄의 향)

**자연 감성 계열**
- 잔물결 / 바닷결 / 첫새벽 / 산모롱이

**밤·감성 계열**
- 자오록 (조용하고 아름답게)
- 나빌레라 (나비처럼)
- 별밭 (별이 가득한 밭)

**아늑함 계열**
- 보금자리 (아늑한 자리)
- 오붓 (아늑하고 정다움)
- 도담 (탐스럽고 예쁨)

**소리 계열**
- 여운 (남는 울림)
- 소리지기 (소리를 지키는 이)
- 어우름 (조화)

**희귀 부사·시적**
- 시나브로 (모르는 사이에 조금씩)
- 미리내 (은하수)
- 가온 (사물의 한가운데)
