# Taste OS — Identity Dashboard / 집

> 대시보드가 아닙니다. *집* 이에요.

이 문서는 사용자가 온보딩 이후 *돌아오는 자리* 를 정의합니다. `field.md` 의 Field 표면을 확장한 형태 — 한 페이지 안에 6개 섹션이 모두 보이는 *세로로 긴 거실* 이에요.

함께 읽기: `field.md` (6개 표면의 IA — 이 페이지는 그중 Field의 풍부한 버전), `genome.md` (현재 상태가 어디서 오는지), `voice.md` (한국어 보이스), `report.md` (이 페이지의 시각적 자매).

구현: `taste-os/dashboard/index.html` + `style.css` + `script.js`.

## 0. 집의 은유

대부분의 대시보드는 *통제실* 입니다 — 모든 지표가 한눈에 보이고, 즉시 행동할 수 있어야 하는 자리. Taste OS의 대시보드는 *집* 이에요 — 늦은 오후에 돌아왔을 때 *방금 자기 모습이 살짝 변해 있는* 자리. 변화는 천천히, 통보 없이.

### 다섯 가지 약속

1. **카드 그리드가 *없습니다*.** 섹션 사이의 호흡이 그리드의 역할을 합니다.
2. **숫자가 보이지 않습니다.** *"14주째"* 같은 시간 표현은 있지만 *"73%"* 같은 분석 표현은 없어요.
3. **알림이 *없습니다*.** 빨간 점, 새로운 것 표시, "지금 확인하세요" 같은 압박 모두 없습니다.
4. **모든 섹션은 *지나가도 좋게* 만들어졌어요.** 한 섹션도 읽지 않고 스크롤만 해도 무언가 머뭅니다.
5. **시간이 *드러나 있어요*.** 사용자가 매일 같은 시간에 와도, 같은 시간에 두 번 보지 않아요. 오전과 오후, 봄과 겨울의 결은 다릅니다.

## 1. 화면 구조

하나의 세로 스크롤. 여섯 섹션이 위에서 아래로.

```
                                                                            
   ◌                                                  화 · 16:12            
                                                                            
                                                                            
   1. 지금의 공기                                                            
      ─ 현재 Taste Name + 팔레트 + 한 줄 상태                                
                                                                            
                                                                            
   2. 흐름                                                                  
      ─ 3 개의 반복되는 정서적 끌림                                          
                                                                            
                                                                            
   3. 풍경의 모음                                                            
      ─ 사용자가 둔 것들. 카드 9 개가 부드럽게 떠다님                        
                                                                            
                                                                            
   4. 자꾸 돌아오는 것들                                                      
      ─ 3 개의 echo. 시간선이 아니라 메아리                                  
                                                                            
                                                                            
   5. 오늘의 글                                                              
      ─ 짧은 시적 reflection (3 단락)                                        
                                                                            
                                                                            
   6. 오늘의 결                                                              
      ─ 영혼을 위한 날씨. 천천히 움직이는 그라데이션                          
                                                                            
                                                                            
```

### 시각 토대

- 배경: `night`, 매우 미세한 시간대별 그라데이션 (자정과 정오는 다른 결)
- 본문 폭: 산문은 540px, 시각 섹션은 1080px
- 활자: Cormorant Garamond italic (절정과 강조), Inter (본문), JetBrains Mono Light (시간/메타)
- 색조: rose 액센트, silver-blue 보조, dusty beige가 텍스트 기본
- 빛 구체 4개, 그레인 5%, Sigil 좌상단 호흡

### 시간-인식 (Time-aware)

JavaScript가 사용자 현지 시간을 읽어, 페이지가 다음 변화를 가집니다:

- **아침 (06–11):** silver-blue 그라데이션이 강함. 결: "맑은 오전. 차분한 호숫가."
- **낮 (11–15):** sand + ember 톤. 결: "밝은 한낮. 정원의 한낮."
- **오후 (15–18):** rose 톤. 결: "북향의 오후. 발코니 같아요."
- **저녁 (18–22):** rose-deep + ember. 결: "노을의 시간. 거실의 등불."
- **밤 (22–06):** silver-blue + deep rose. 결: "고요한 밤. 깊은 호수 같아요."

매시간 정각에 페이지 안의 자그마한 라벨이 *천천히* 새로고침됩니다 — 사용자는 거의 알아차리지 못해요.

## 2. Section 1 — 지금의 공기

페이지의 입구. 사용자가 도착하자마자 보는 자리.

### 구성

```
                                                                            
                                                                            
   ─ 지금의 공기                                                            
                                                                            
                                                                            
                                                                            
          오후 네 시 즈음.                                                 
          북향의 빛이 도는 시간이에요.                                      
                                                                            
                                                                            
                                                                            
          옻칠한                                                            
          황혼                                                              
                                                                            
                                                                            
          ▮ ▮ ▮ ▮ ▮                                                         
          oak · ash · ember · fog · ink                                     
                                                                            
                                                                            
                                                                            
          14주째 같은 풍경입니다. 천천히 변하는 중이고요.                   
                                                                            
                                                                            
```

### 요소

1. **시간 줄** — display sm italic, mist. 사용자 현재 시간대 자동 감지.
   - 새벽 04:00 → "동이 트기 전. 가장 조용한 시간이에요."
   - 아침 09:00 → "아침이 시작되는 시간."
   - 오후 16:00 → "오후 네 시 즈음. 북향의 빛이 도는 시간이에요."
   - 저녁 19:00 → "노을의 시간."
   - 밤 23:00 → "고요한 밤이에요."
2. **Taste Name** — display lg italic, 두 단어. 두 번째 단어는 rose.
3. **팔레트 + 이름** — 5개 swatch (40×40), 그 아래 mono 11px lowercase 이름들.
4. **상태 한 줄** — text-md, mist. 사용자의 흐름 안정성을 *문장으로* 알려줍니다.

### 상태 줄의 변형 (사용자의 실제 상태에 따라)

| 상태 | 카피 |
|---|---|
| L2가 4주 이상 안정 | N주째 같은 풍경입니다. 천천히 변하는 중이고요. |
| L2가 최근 흔들림 | 이번 주는 다른 결이 살짝 들어왔어요. |
| 새 흐름 등장 | 새로운 흐름 하나가 자라나는 중이에요. |
| 새 유저 (3주 미만) | 아직 듣는 중이에요. 천천히 만들어갈게요. |

### 모션

페이지 로드 시:

```
t = 0.0s   검은 필드 + 그레인/orb 페이드 인
t = 1.2s   Sigil 등장
t = 1.4s   섹션 라벨 reveal fade
t = 1.8s   시간 줄 reveal blur (1.6s)
t = 3.4s   Taste Name "옻칠한" reveal blur (1.6s)
t = 4.2s   "황혼" reveal blur (rose 색)
t = 5.6s   팔레트 페이드 + 이름들
t = 6.4s   상태 줄 fade in
```

## 3. Section 2 — 흐름

당신이 자꾸 끌리는 것들. 3개의 관찰.

### 구성

```
                                                                            
   ─ 흐름                                                                  
                                                                            
                                                                            
                                                                            
          당신은 조용한 따뜻함에                                            
          반복적으로 끌리고 있어요.                                         
                                                                            
                                                                            
          ────                                                              
                                                                            
                                                                            
          최근에는 완벽함보다                                                
          인간적인 흔적에 더 오래                                            
          머물고 있어요.                                                    
                                                                            
                                                                            
          ────                                                              
                                                                            
                                                                            
          낮 시간보다 늦은 오후에                                            
          두는 것이 많아졌어요.                                              
                                                                            
                                                                            
```

### 요소

3개의 관찰 문장. 각각:

- 1-2 줄짜리 짧은 관찰
- display sm italic, beige
- 사이에 56px 헤어라인 (ash 30%)
- 텍스트 왼쪽 정렬, 본문 폭 480px

### 음성 규칙

- *2인칭*, 현재 진행형이 자주 등장 (*"끌리고 있어요"*, *"머물고 있어요"*, *"많아졌어요"*)
- 비교 ("X보다 Y")가 흔함 — 이 형식이 *변화* 를 보여주는 가장 효과적인 방식
- 시간 표현은 *상대적* (*"최근에는"*, *"이번 주는"*)이고 *절대적* (*"3월 14일"*)이지 않음
- 결코 *"당신은 X를 좋아해요"* 의 단순 단정 형식 아님 — 항상 *반복* 의 관찰

### 모션

섹션이 viewport에 들어오면:
- 라벨 fade in (0.6s)
- 각 관찰이 1.2s 간격으로 reveal blur (1.6s 각)
- 헤어라인 draw in (0.8s, scaleX 0 → 1)

## 4. Section 3 — 풍경의 모음

당신이 둔 것들. 카드 그리드지만 *그리드답지 않게*.

### 구성

```
                                                                            
   ─ 풍경의 모음                                                            
                                                                            
                                                                            
                                                                            
   ┌────┐  ┌────┐         ┌────┐                                            
   │    │  │ ◯  │         │ "  │                                            
   │img │  │ ◯◯ │         │ "  │                                            
   │    │  │ ◯  │         │    │                                            
   └────┘  └────┘         └────┘                                            
                                                                            
            ┌────┐  ┌────┐         ┌────┐                                  
            │    │  │    │         │ "  │                                  
            │img │  │img │         │ "  │                                  
            │    │  │    │         │    │                                  
            └────┘  └────┘         └────┘                                  
                                                                            
   ┌────┐         ┌────┐  ┌────┐                                            
   │ ◯  │         │    │  │    │                                            
   │ ◯◯ │         │img │  │img │                                            
   │ ◯  │         │    │  │    │                                            
   └────┘         └────┘  └────┘                                            
                                                                            
```

### 요소

9개 카드 (이미지 5, 인용 2, 소리 2). 비균일 그리드 — 각 카드가 다른 행 높이, 부드러운 시각적 마디.

각 카드:
- 이미지: 4:5 비율, 그라데이션 + 캡션
- 인용: 5:3 비율, italic 인용
- 소리: 정사각, 회전하는 디스크 + 곡명

카드들은:
- 약간씩 (-2° ~ +2°) 무작위 회전
- 호버 시 2px 위로 + 색온도 +120K
- idle 시 미세하게 (±2px) 떠다님 (8s 주기, 각자 다른 위상)
- 클릭 시 → *큰 보기* 로 부드럽게 확대 (모달 아님, 같은 페이지 안에서 확장)

### 카드의 컨텐츠 (샘플)

1. 북향의 오후 (이미지)
2. 단 하나의 창 (이미지)
3. *"어떤 것들은 한 번 보는 걸로 충분해요."* (인용)
4. 비 온 뒤 거리 (이미지)
5. Sigur Rós · Glósóli (소리)
6. 늦은 카페 (이미지)
7. *"조용한 것이 깊을 수 있다는 걸, 일찍부터 알았어요."* (인용)
8. 오래된 책방 (이미지)
9. Saariaho · Petals (소리)

### 그리드 방식

CSS Grid의 `auto-flow: dense` 와 명시적 row spans. 모바일에서는 2열, 태블릿 이상에서 3열로. *카드 같은 그리드* 가 아니라 *방의 책상에 흩어진 카드처럼* 보이는 게 목표.

## 5. Section 4 — 자꾸 돌아오는 것들

Echo. 시간선의 분석이 아니라 *되돌아옴* 의 표현.

### 구성

```
                                                                            
   ─ 자꾸 돌아오는 것들                                                      
                                                                            
                                                                            
                                                                            
   비 오는 일요일 오후의 정적                                                
   ─ 지난 봄부터 일곱 번 돌아왔어요.                                         
                                                                            
                                                                            
                                                                            
   단 하나의 창                                                              
   ─ 온보딩 때부터 줄곧.                                                     
                                                                            
                                                                            
                                                                            
   낯선 곳의 늦은 카페                                                       
   ─ 짧게, 자주.                                                             
                                                                            
                                                                            
```

### 요소

3개의 echo. 각각:
- **이름** — display sm italic, beige. *"비 오는 일요일 오후의 정적"*
- **빈도** — mist 13px, 작은 ─ 글리프로 시작. *"─ 지난 봄부터 일곱 번 돌아왔어요."*

들여쓰기 없음, 좌측 정렬, echo 사이에 generous (var(--br-2)) 호흡.

### 빈도 표현 — 숫자 같지 않게

| 잘못된 방식 | 올바른 방식 |
|---|---|
| "7번 / 14주" | "지난 봄부터 일곱 번 돌아왔어요" |
| "first seen: onboarding" | "온보딩 때부터 줄곧" |
| "frequency: weekly" | "짧게, 자주" |
| "trending up 12%" | "최근에 더 자주 보입니다" |

숫자를 *사용하더라도* 텍스트로 ("일곱 번"). 영어 표현 "7 times"는 분석 같지만 "일곱 번"은 *지나가는 말* 처럼 들려요.

## 6. Section 5 — 오늘의 글

가장 긴 산문 섹션. AI가 *당신을 위해* 쓴 짧은 reflection.

### 구성

```
                                                                            
   ─ 오늘의 글                                                              
                                                                            
                                                                            
                                                                            
   이번 주, 당신은 도시의 소음 한가운데에서                                  
   조용한 것들을 더 많이 발견했어요.                                         
                                                                            
   작은 것을 작은 채로 두는 일이 점점 능숙해지고                             
   있는 것 같아요. 큰 사건을 만들지 않고도, 어떤                             
   오후들은 충분히 의미 있게 지나갑니다.                                     
                                                                            
   다음 주에 또 만나요. 천천히.                                              
                                                                            
                                                                            
```

### 요소

- 3 단락 산문
- Inter / Pretendard, 17px, 줄 간격 1.78
- 본문 폭 540px
- 단락 사이 var(--s-5)
- 마지막 줄은 *작별 인사* — 친밀하지만 짧게

### 톤

`voice.md` 의 *modern Korean essay register* — 김연수, 김애란, 정혜윤의 산문 톤. 핵심:
- ~ㅂ니다 / ~요 혼용 (이번 단락은 ~요 우세)
- 비교가 흔함 ("작은 사건을 만들지 않고도")
- 결론을 강요하지 않음 — *"의미 있게 지나갑니다"* 정도의 절제
- 마지막 줄은 *다음 만남* 을 약속하되 *오라고 부르지 않음*

### 갱신 주기

실제 제품에서는 *일주일* 마다 갱신. 매번 새로 쓰지 않음 — 한 사용자에게 매일 새로운 reflection을 주면 그 무게가 떨어집니다. *오늘의 글* 은 *이번 주의 글* 의 다른 표현이에요.

### 모션

3개 단락이 800ms 간격으로 reveal blur. 마지막 줄은 약간 더 길게 (1.0s 추가) — *작별의 무게* 를 위한 시간.

## 7. Section 6 — 오늘의 결

영혼을 위한 날씨. 페이지의 마무리이자, 가장 추상적인 섹션.

### 구성

```
                                                                            
   ─ 오늘의 결                                                              
                                                                            
                                                                            
                                                                            
                                                                            
              차분함                                                        
                                                                            
                                                                            
              조용한 호수의 표면 같은 하루예요.                              
                                                                            
                                                                            
                                                                            
                                                                            
                                                                            
   [천천히 움직이는 그라데이션 배경]                                         
                                                                            
                                                                            
```

### 요소

1. **한 단어 — 오늘의 결** — display lg italic, beige. *"차분함"* / *"호기심"* / *"머무름"* / *"기다림"* 등
2. **한 문장 비유** — display sm italic, mist. *"조용한 호수의 표면 같은 하루예요."*
3. **배경 그라데이션** — 섹션 전체에 천천히 움직이는 radial 그라데이션. 시간대에 따라 색이 다름.

### 시간대별 결 (자동 선택)

| 시간 | 결 | 비유 문장 |
|---|---|---|
| 새벽 04-06 | 시작 전의 정적 | 모든 것이 깨어나기 전, 한 순간이에요. |
| 아침 06-11 | 맑음 | 차분한 호숫가 같은 하루예요. |
| 낮 11-15 | 머무름 | 정원의 한낮 같은 시간이에요. |
| 오후 15-18 | 차분함 | 조용한 호수의 표면 같은 하루예요. |
| 저녁 18-22 | 따뜻함 | 거실의 등불 같은 저녁이에요. |
| 밤 22-04 | 깊음 | 깊은 호수 같은 밤이에요. |

### 배경 그라데이션

```css
/* 오후 결 (예시) */
background: radial-gradient(ellipse at 30% 40%, rgba(176, 118, 114, 0.06), transparent 50%),
            radial-gradient(ellipse at 70% 60%, rgba(143, 160, 172, 0.04), transparent 60%);
```

60초 주기로 두 ellipse가 천천히 위치 이동 (CSS transform translate, 미세). 사용자는 알아차리지 못하되, 페이지가 *살아 있다* 고 느낍니다.

### 페이지의 닫음 — 명시적 닫음은 없음

이 섹션 다음에 *"처음으로"* 같은 링크는 없습니다. 페이지가 *끝나지 않아요* — 사용자는 단지 *집을 둘러보고 나갑니다*. 페이지가 *마지막* 을 강요하지 않습니다.

대신 페이지 하단 (180px padding bottom) 에 매우 작은 줄이 mist 40% 으로:

> *내일도 같은 자리에 있을게요.*

### 시간대 감지 (Vanilla JS)

```js
function getPeriod() {
  const h = new Date().getHours();
  if (h < 6)   return 'predawn';
  if (h < 11)  return 'morning';
  if (h < 15)  return 'noon';
  if (h < 18)  return 'afternoon';
  if (h < 22)  return 'evening';
  return 'night';
}
```

각 섹션이 페이지 로드 시점에 현재 시간대를 읽어 카피를 결정합니다.

## 닫는 말

대시보드는 *효율성* 을 위해 만들어졌습니다. 모든 정보를 한 화면에, 즉시. 그리고 그 결과: 우리는 대시보드를 보면서 *덜 알게* 됩니다.

Identity Dashboard는 *효율성* 을 거부합니다. 천천히 읽혀야 하고, 한 번에 다 못 들어와도 괜찮고, 어떤 섹션은 그냥 *지나가도* 좋습니다. 어차피 내일도 같은 자리에 있을 거니까요.

집이 잘 만들어진다면, 사용자는 — 무언가를 *확인* 하러 오지 않고 — *돌아오게* 됩니다. 한 사람이 집에 돌아오는 이유와 같은 이유로요.
