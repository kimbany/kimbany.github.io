## 0. 철학 한 줄

> *시간선이 아니라 *결*. 변화는 측정되지 않고, *느껴집니다*.*

대부분의 타임라인은 *언제 무엇이 있었는가* 를 보여줍니다. 이 타임라인은 *그때의 당신과 지금의 당신 사이에 무엇이 흘렀는가* 를 보여줍니다.

### 절대 없는 것

- y축, x축, 좌표계
- 퍼센트, 그래프, 차트, 막대
- "growth rate", "trending up", 같은 분석 어휘
- 정확한 날짜 ("2024년 3월 14일")
- "X% 더 자주 저장했어요" 같은 비교 표현

### 대신 있는 것

- 연도별 *분위기* (cold blue urban solitude → warmer emotional textures → soft analog warmth)
- 연도별 *팔레트* (실제로 색이 페이지 안에서 바뀜)
- 연도별 *시적 산문* (1-2문장 짧은 reflection)
- 연도 사이의 *Turn* — 한 문장으로 표현된 전환의 순간
- *Echoes* — 모든 해를 가로질러 돌아오는 주제들
- *Constitution Anchor* — 세 해 동안 움직이지 않은 4가지

## 1. 페이지 구조 — 세 해의 영화

세로 한 페이지. 위에서 아래로 시간이 흐릅니다.

```
                                                                            
   1. 입구                                                                   
      ─ "세 해가 지났어요. 그동안 당신은 천천히 변했어요."                   
                                                                            
                                                                            
   2. 2024  ·  차가운 푸름 · 도시의 고독                                     
      [팔레트 strip] [샘플 카드 4개] [reflection 한 단락]                    
                                                                            
                                                                            
   3. ──── Turn 1 (검은 viewport, 한 문장) ────                              
                                                                            
                                                                            
   4. 2025  ·  따뜻해지는 결                                                 
      [팔레트 strip] [샘플 카드 4개] [reflection 한 단락]                    
                                                                            
                                                                            
   5. ──── Turn 2 (검은 viewport, 한 문장) ────                              
                                                                            
                                                                            
   6. 2026  ·  옻칠한 황혼                                                    
      [팔레트 strip] [샘플 카드 4개] [reflection 한 단락]                    
                                                                            
                                                                            
   7. Echoes  ·  세 해를 가로지른 것들                                       
      ─ 3개의 echo                                                           
                                                                            
                                                                            
   8. Constitution Anchor  ·  움직이지 않은 것들                              
      4개의 단어 + 닫는 한 줄                                                
                                                                            
                                                                            
```

### 시간이 흐르게 만드는 시각 장치

- **배경 그라데이션** 이 페이지 안에서 *차가운 색에서 따뜻한 색으로 점진적으로 이동*합니다.
  - 페이지 상단 (2024): silver-blue + night blue 톤
  - 페이지 중간 (2025): 혼합 — 따뜻함과 차가움이 교차
  - 페이지 하단 (2026): ember + rose + warm brown
- **빛 구체 (orbs)** 도 색이 단계적으로 변함.
- **Turn** 은 *검은 viewport* — 변화가 통과하는 *진공* 의 자리.

## 2. 세 개의 챕터 (2024 · 2025 · 2026)

각 챕터는 같은 구조를 가지지만, 분위기가 *완전히 다릅니다*.

### 2.1 챕터의 해부학

```
                                                                            
   ─ 2024                                                                   
                                                                            
                                                                            
   차가운 푸름                                                              
   · 도시의 고독                                                            
                                                                            
                                                                            
   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                          
   [yearly palette strip — 320×40, 5 colors]                                
                                                                            
                                                                            
   [card] [card] [card] [card]                                              
                                                                            
                                                                            
   "이 해, 당신은 도시의 차가운 표면들에                                    
    자주 멈춰 섰어요.                                                       
    사람들 사이에서 자기만의 시간을                                          
    더 필요로 했고요."                                                       
                                                                            
                                                                            
```

요소들:
1. **연도 라벨** — JetBrains Mono Light, 13px, mist 65%, *─ 2024*
2. **연도 이름** — display lg italic, 2 줄. *"차가운 푸름"* + *"· 도시의 고독"*
3. **팔레트 strip** — 5색 swatch, 가로 320×40. 그 해의 dominant colors
4. **샘플 카드 4개** — 그 해 자주 저장한 풍경. 그라데이션 카드 + 캡션
5. **Reflection** — 3-4 줄 짧은 산문 (Inter, 17px, line-height 1.78)

### 2.2 세 챕터의 세부 사양

#### 2024 — 차가운 푸름 · 도시의 고독

```
이름:          차가운 푸름 · 도시의 고독
영문 단서:     (cold blue urban solitude)

샘플 카드:     비 오는 거리, 늦은 지하철, 밤의 도시, 형광등 아래
reflection:    이 해, 당신은 도시의 차가운 표면들에 자주 멈춰 섰어요.
               사람들 사이에서 자기만의 시간을 더 필요로 했고요.
               밤이 더 길게 느껴졌어요. 그래도 좋았어요.
```

#### 2025 — 따뜻해지는 결

```
이름:          따뜻해지는 결
영문 단서:     (warmer emotional textures)
팔레트:        #1A2030 #2A2622 #4A3D2C #7A5040 #B07672
                ↑      ↑      ↑      ↑      ↑
                slate  coal   coal   brown  rose
샘플 카드:     새벽의 부엌, 작은 카페, 책상 위 램프, 비 온 다음 봄
reflection:    예전보다 조금 더 따뜻한 것들에 마음이 머물고 있어요.
               완벽함보다 인간적인 흔적에 오래 시선이 머물기 시작했어요.
               도시가 조용해지는 시간이 좋아졌어요.
```

#### 2026 — 옻칠한 황혼

```
이름:          옻칠한 황혼
영문 단서:     (soft analog warmth)
팔레트:        #2A1F18 #4A3D2C #7A5040 #B07672 #D9A66C
                ↑      ↑      ↑      ↑      ↑
                deep   oak    brown  rose   ember
샘플 카드:     단 하나의 창, 늦은 카페, 모닥불 옆, 오래된 책방
reflection:    이제는 작은 빛이 오래 가는 걸 알아요.
               큰 사건 없이도, 어떤 오후들이 충분히 의미 있게 지나가요.
               자기 자신에게 천천히 가까워지는 중이에요.
```

### 2.3 변화의 시각적 증명

세 챕터를 연속으로 보면:

| | 2024 | 2025 | 2026 |
|---|---|---|---|
| 가장 어두운 색 | `#0F1620` (night) | `#1A2030` (slate) | `#2A1F18` (deep brown) |
| 가장 밝은 색 | `#8FA0AC` (silver) | `#B07672` (rose) | `#D9A66C` (ember) |
| 정체성 | 차가움 | 혼합 | 따뜻함 |

이 변화는 *그래프* 가 아니에요. *눈으로 보이는 색의 이동* 이고, 사용자는 *느낍니다*.

## 3. Turn — 챕터 사이의 시네마틱 이음새

연도 사이에 *작은 검은 정거장* 이 있습니다.

```
                                                                            
                                                                            
                                                                            
                  그러더니, 천천히,                                          
                  빛이 돌아섰어요.                                           
                                                                            
                                                                            
                                                                            
```

### Turn 1 (2024 → 2025)

```
그러더니, 천천히,
빛이 돌아섰어요.
```

### Turn 2 (2025 → 2026)

```
여름이 길어졌어요.
모으는 것이 적어졌고,
남기는 것은 깊어졌어요.
```

### Turn 의 시각

- 자리: 70vh 이상, 화면 가운데
- 폰트: Cormorant Garamond italic, clamp(24px, 3.4vw, 36px)
- 색: beige 88%, 살짝 어둡게
- 배경: 그 시점의 그라데이션이 *고요하게 정지* — 다음 색으로 전환되는 *틈*
- reveal: viewport에 들어오면 reveal blur 1.6s

Turn 은 *읽지 않고 지나가도 되는* 자리예요. 하지만 한 번 멈춰서 읽으면, 다음 챕터가 *이어진다* 는 느낌을 줍니다.

## 4. Echoes — 자꾸 돌아오는 것들

세 해를 가로지른 주제들. 시간선의 분석이 아니라 *되돌아옴* 의 표현.

```
                                                                            
   ─ 세 해를 가로지른 것들                                                  
                                                                            
                                                                            
                                                                            
   단 하나의 창                                                              
   ─ 2024년부터 줄곧.                                                        
                                                                            
                                                                            
   비 온 다음의 거리                                                          
   ─ 봄마다 돌아와요.                                                        
                                                                            
                                                                            
   늦은 오후의 빛                                                            
   ─ 자주, 그리고 점점 더 깊이.                                              
                                                                            
                                                                            
```

3개의 echo. 각각:
- **이름** — display sm italic, beige. *"단 하나의 창"*
- **빈도** — mist 13px, *"─ 2024년부터 줄곧."*

들여쓰기 없음, 좌측 정렬, echo 사이에 generous (var(--br-2)) 호흡.

### 빈도 표현 — 분석이 아닌 회상

세 해 동안의 빈도를 *숫자 없이* 표현하는 패턴:

| ❌ 분석적 | ✅ 시적 |
|---|---|
| 14 / 36 weeks | 자주, 그리고 점점 더 깊이 |
| recurring every 3 weeks | 봄마다 돌아와요 |
| first seen: 2024-03 | 2024년부터 줄곧 |
| frequency: increasing | 점점 자주 |

## 5. Constitution Anchor — 움직이지 않은 것들

페이지의 정서적 절정. 세 해 동안 *변하지 않은* 4가지를 보여줍니다.

```
                                                                            
   ─ 움직이지 않은 것들                                                     
                                                                            
                                                                            
                                                                            
                                                                            
              정적                                                          
                                                                            
              단일 광원                                                     
                                                                            
              늦은 오후                                                     
                                                                            
              혼자                                                          
                                                                            
                                                                            
                                                                            
   세 해가 지나는 동안, 이 네 가지는 그대로였어요.                          
                                                                            
                                                                            
```

### Constitution 4 단어

L3 / Constitution 층 (per `genome.md` §1) 의 6개 축 중 가장 안정된 4개:
- **정적** (Hush)
- **단일 광원** (Vesper, 빛 축)
- **늦은 오후** (Afterlight, 시간 축)
- **혼자** (Solitary, 동행 축)

세로로 stacked, 단어 사이에 generous 호흡 (var(--br-1)). 각 단어가 자기 자리에 *앉아 있는* 모양.

### Reveal 안무

페이지의 가장 느린 reveal:

```
t = 0    섹션 viewport 진입
t = 0.6s    "─ 움직이지 않은 것들" 라벨 fade in
t = 1.4s    "정적" reveal blur (2.0s)
t = 3.4s    "단일 광원" reveal blur (2.0s)
t = 5.4s    "늦은 오후" reveal blur (2.0s)
t = 7.4s    "혼자" reveal blur (2.0s)
t = 10.0s   "세 해가 지나는 동안, 이 네 가지는 그대로였어요." fade in
```

총 10초 이상. 페이지에서 가장 긴 reveal.

이 4 단어는 *변화 위에 변치 않는 자기 자신* — 그게 정체성의 진짜 모양임을 시각화합니다.

### 핵심 모션 시스템

| 패턴 | 어디 | 시간 |
|---|---|---|
| 입구 reveal | 페이지 로드 직후 | 0-3s |
| 챕터 진입 reveal | 각 연도 (스크롤 인) | 1.0-1.6s breath-in |

| 샘플 카드 stagger | 4개 카드 | 200ms 간격 fade |
| Constitution Anchor | 마지막 | 10초 reveal (단어당 2초) |

### 배경 그라데이션 — 페이지 전체에 걸쳐 흐름

각 챕터가 자기 ::before pseudo-element 로 자기 그라데이션을 가짐. 챕터 간 transition은 viewport에서 보이는 비율로 자연스럽게 발생.

```css
.chapter-2024::before {
  background: linear-gradient(180deg,
    rgba(15, 22, 32, 0.5) 0%,
    rgba(58, 69, 85, 0.3) 100%);
}

.chapter-2025::before {
  background: linear-gradient(180deg,
    rgba(58, 69, 85, 0.3) 0%,
    rgba(74, 61, 44, 0.3) 100%);
}

.chapter-2026::before {
  background: linear-gradient(180deg,
    rgba(74, 61, 44, 0.3) 0%,
    rgba(176, 118, 114, 0.2) 100%);
}
```

위에서 아래로 스크롤하면 *눈에 보이는 색* 이 차가운 데서 따뜻해집니다.

### 데이터 모델 (실제 제품)

```ts
type TimelineChapter = {
```

## 닫는 말

이 페이지는 *변화* 의 페이지지만, 그 *변화* 가 *발전* 이나 *성장* 이 아니에요. *결의 변화* — 같은 사람이 다른 결을 입어가는 일.

그리고 그 변화 *밑에는* 변치 않는 4가지가 있어요. Constitution Anchor.

페이지를 다 본 사용자는 *"나는 많이 변했네"* 가 아니라 — *"많이 변한 것 같지만, 어떤 부분은 그대로구나"* 라고 느꼈으면 좋겠어요. 그게 *나아짐* 이 아니라 *나에게 가까워짐* 이라는 진실의 시각화입니다.
