# Taste Genome — 시스템 설계

> Genome은 성격 검사가 아닙니다. 한 사람이 이미 세상에 내어준 증거를, 자신이 누구인지에 대한 증거를, 오래 그리고 조심스럽게 들여다보는 일입니다.

이 문서는 다섯 가지 헌물(이미지, 음악, 인용, 공간, 느낌)을 한 사람의 살아 있는 취향 초상으로 바꾸는 시스템을 정의합니다. 온보딩 문서의 아키텍처적 대응입니다.

아래 모든 것을 지배하는 단 하나의 설계 제약: **카테고리가 아닌 연속.** 16가지 유형 없음. 사분면 없음. "당신은 X입니다" 없음. 모든 출력은 벡터, 흐름, 경향, 관찰입니다. 시스템은 증거를 묘사하되, 행동을 예측하지 않습니다.

## 0. 기본 전제 — 왜 MBTI가 아닌가

MBTI 류 시스템은 네 가지 실패를 공유합니다. 우리는 그 모두를 피하기로 했습니다.

| MBTI는 이렇게 한다 | Genome은 이렇게 한다 |
|---|---|
| 연속 특성을 이진 문자로 강제 | 연속 부동소수점을 저장, 표시를 위해서도 *결코* 반올림하지 않음 |
| 라벨로 행동을 예측 | *이미 주어진 증거*를 묘사, 예측은 하지 않음 |
| 정체성을 고정된 것으로 다룸 | 정체성을 천천히 표류하는 기상계로 다룸 |
| 자기보고를 사용 (거짓말, 기분, 사회적 바람직성) | 드러난 선호를 사용 (실제로 무엇을 저장했는가) |

Genome이 정신적으로 더 가까운 것은:
- **쾨펜 기후 분류** — 별자리표가 아닌, 한 장소의 성격을 묘사하는 여러 연속 변수들.
- **미술사가의 단행본** — 끈기 있고, 증거 주도적이며, 자기 모순도 허용.
- **보석 감정서** — 관찰 가능한 속성(투명도, 색상, 내포물)이지 가치 판단이 아닌.
- **음악학자의 분석** — 반복되는 모티프, 조성 변화, 음 사이 침묵이 함의하는 것.

사용자는 자신의 Genome을 읽고 *유형 분류된* 느낌을 받으면 안 됩니다. *목격받은* 느낌을 받아야 합니다.

## 1. 정체성 매핑 시스템

### 유형이 아닌 매니폴드

한 사람의 취향은 **취향 매니폴드(Taste Manifold)**라 부르는 64차원 잠재공간 안의 한 점 — 그리고 속도 — 으로 표현됩니다. 매니폴드는 세 겹의 중첩된 층을 가집니다:

```
┌───────────────────────────────────────────────────────────┐
│  L3 · 헌법(Constitution)    (느림, ~년 단위)              │
│      철학적·기질적 지향                                    │
│      6축 · 개월 단위로 변화                                 │
│                                                           │
│  ┌───────────────────────────────────────────────────┐    │
│  │  L2 · 분위기(Atmosphere)   (중간, ~계절 단위)     │    │
│  │      미적 차원 + 기후                              │    │
│  │      14축 · 주 단위로 변화                         │    │
│  │                                                   │    │
│  │  ┌─────────────────────────────────────────────┐  │    │
│  │  │  L1 · 인상(Impression)  (빠름, ~일 단위)    │  │    │
│  │  │      이번 주에 무엇을 저장했는가             │  │    │
│  │  │      44축 · 시간 단위로 변화                  │  │    │
│  │  └─────────────────────────────────────────────┘  │    │
│  └───────────────────────────────────────────────────┘    │
└───────────────────────────────────────────────────────────┘
```

- **L1 / 인상** — 휘발성. 한 주의 기분. 호수의 표면.
- **L2 / 분위기** — Genome 대부분이 여기서 읽힘. 우세한 기상.
- **L3 / 헌법** — 느린 용골. 날씨가 바뀌어도 움직이지 않는 부분.

각 층은 제품에 다르게 노출됩니다:
- L1은 홈 화면의 **"지금"** 띠.
- L2는 **Genome 카드**.
- L3는 **미러** — 온보딩 끝의 한 문장이자, 변화에 수개월의 증거를 요구하는 유일한 인공물.

### 정체성 벡터

```ts
type TasteVector = {
  impression: Float32Array; // 길이 44
  atmosphere: Float32Array; // 길이 14
  constitution: Float32Array; // 길이 6
  measuredAt: Date;
  evidenceCount: { images, sounds, quotes, spaces, feeling };
  confidence: Float32Array; // 길이 64
};
```

**확신도는 1급 시민.** 모든 축은 증거 밀도와 모달 간 일치도에서 도출된 확신 점수를 가집니다. 낮은 확신은 *숨기지 않고*, 보여집니다 — 막대를 더 흐리게 하고, 한 줄을 덧붙입니다: *"이건 아직 듣는 중이에요."*

### 세 해상도의 정체성

시스템이 사용자에 대해 쓸 때, 맥락에 따라 해상도를 고릅니다:
- **마이크로** — "이번 주 당신은 더 따뜻한 쪽으로 기울었어요."
- **메소** — "당신의 분위기는 늦은 오후, 북향이에요."
- **매크로** — "당신은 어떤 일의 *이전*이 아니라 *이후*의 정적을 향합니다."

한 해상도로만 말하는 Genome은 가십(마이크로뿐)이거나 거창함(매크로뿐) 둘 중 하나. 둘 사이의 상호작용이 기예입니다.

## 2. 취향 클러스터링 엔진

### 모달 & 인코더

| 모달 | 인코더 | 출력 |
|---|---|---|
| 이미지 | OpenCLIP `ViT-L/14` + 큐레이션 미학 코퍼스 파인튠 헤드 | 768-d, L2 정규화 |
| 오디오 | CLAP `HTSAT-base` (음색) + essentia (BPM, 키, 화성 안정성, 다이내믹 레인지) | 512-d + 9 핸드피처 |
| 인용 | sentence-transformer (`bge-m3`) + prosody 분석 (문장 리듬, em-dash 밀도, 추상도) | 1024-d + 6 핸드피처 |
| 공간 | 이미지 인코더 + 공간 속성 분류기 (내부/외부, 광원 방향, 천장 높이, 재료 팔레트) | 768-d + 8 핸드피처 |
| 느낌 | 슬라이더 5개 + 망설임 시간 | 10-d |

모두 연결되어, 학습된 선형 헤드를 거쳐 **취향 매니폴드**로 투영(v1에서 동결).

### 두 스케일의 클러스터링

```
              ┌─── UMAP (n_neighbors=15, min_dist=0.1) ─── 2D 시각 공간
원시 벡터  ───┤
              └─── HDBSCAN (min_cluster_size=2, leaf) ─── 미세 클러스터
                          │
                          └── 코사인 기반 테마 병합 ─── 흐름 (4–7)
```

**`min_cluster_size`를 의도적으로 작게** — 이상값을 존중하기 위해. 20장 중 하나의 변칙적 이미지는 *신호*지 잡음이 아닙니다. 그것이 가장 드러내 보이는 증거일 수 있습니다.

### 모달 간 일관성

가장 흥미로운 발견은 모달이 **동의**하거나 **불일치**하는 지점에서 옵니다.
- **동의.** 이미지가 어둑한 따뜻한 실내에 모이고, 음악이 느린 BPM과 높은 화성 안정성이고, 인용이 "잉걸"류 어휘에 높게 인덱스된다면 — 견고한 흐름. 자신 있게 이름을 붙입니다.
- **불일치.** 이미지가 순결한 모더니즘 기하인데 음악이 둠 메탈이라면 — *긴장*이고, 긴장은 명시적으로 드러냅니다 (§3, *역류*). 대부분의 취향 시스템은 평균을 내버립니다. 우리는 보존합니다.

### "되돌아옴" 메커니즘

Genome은 **한 번 저장한 것**이 아니라 **되돌아오는 것**을 추적합니다. 온보딩 이후 매 저장은 τ = 30일의 축별 지수이동평균을 갱신합니다.

```ts
ema_axis = ema_axis * exp(-Δt / 30d) + new_evidence_axis * (1 - exp(-Δt / 30d));
```

같은 축의 두 번째 증거는 첫 번째의 ~1.8배 가치. 세 번째는 ~2.4배. 시스템은 양이 아닌 일관성을 보상합니다.

## 3. 감정 패턴 분석

감정은 감성 분류기로 도출되지 않습니다. 세 직교 판독을 합성한 뒤, 그 *사이*의 패턴을 찾습니다.

### 세 판독
1. **색채 정동** (이미지 & 공간) — CIELAB 색상 분포, 색온도(K), 광원 방향, 대비비, 채도 엔트로피.
2. **음향 정동** (음악) — 템포 분포와 *분산*, 조성/화성 안정성, 다이내믹 레인지, "음의 여백"(침묵 대 소리 비율).
3. **어휘 정동** (인용) — 가치(Vader + 문학 어휘집), 추상도(구체 명사 ↔ 철학 명사), 시간 지향(과거형 밀도 vs 미래형), 대명사 분포.

### 우리가 찾는 패턴

| 패턴 | 시그니처 | 표현 |
|---|---|---|
| **역류(Counter-Current)** | 두 모달 간 강한 불일치 | "다른 것들과 반대로 흐르는 흐름이 있어요 — 그리고 그것이 아마 가장 진실한 부분일 거예요." |
| **시간(The Hour)** | 광원 방향 + 템포 + 시간 지향이 좁게 군집 | "당신의 작업은 ___에 속해요" (특정 시간) |
| **닿음(The Reach)** | 인용은 추상에, 이미지는 구체에 인덱스 | "당신은 관념으로 사고하고 질감으로 살아갑니다." |
| **은신처(The Refuge)** | 이미지·공간 일관되게 단일 광원, 실내 | "당신은 둘러싸임에 끌립니다." |
| **지평(The Horizon)** | 가장자리, 거리, 외부, 미래형 빈도 높음 | "당신은 아직 도착하지 않은 것에 끌립니다." |
| **메아리(The Echo)** | 세 개 이상 증거에 반복되는 어휘·시각 모티프 | "___이 계속 나타나요. 우연이 아닌 것 같아요." |
| **침묵(The Silence)** | *부재한* 축 — 예: 사람 없음, 원색 없음, 빠른 템포 없음 | 명시적으로 "당신이 보여주지 않은 것도 증거입니다." |

### 침묵이 혁신

대부분의 시스템은 *있는 것*을 묘사합니다. Genome은 또한 *눈에 띄게 부재한 것*을 묘사합니다. 드러난 선호에서의 부재는 심리학이 줄 수 있는 가장 큰 신호이기 때문입니다. 24장 이미지를 저장한 사람이 한 장도 사람 얼굴을 포함하지 않았다면, 말하지 않고 무언가를 말한 것입니다.

### 출력 스키마

```ts
type EmotionalPattern = {
  id: string;
  kind: 'counter_current' | 'hour' | 'reach' | 'refuge' | 'horizon' | 'echo' | 'silence';
  axes: string[];
  evidence: EvidenceRef[];
  strength: number;       // 0–1
  prose: string;          // 생성된 한 문장 관찰
};
```

Genome은 보통 **2–4개** 패턴을 드러냅니다 — 7개가 아닙니다. 넷을 넘으면 관찰이 아니라 뷔페가 됩니다.

## 4. 미적 차원 — 14축

L2 축들. *짝으로 명명*됩니다. 모든 차원이 좋음과 나쁨 사이가 아니라 두 진실 사이의 긴장이기 때문입니다.

양극은 의도적으로 **통약 불가능**합니다 — "한쪽으로 100%"가 될 수 없는 이유는, 반대편 극이 진정으로 또 다른 존재 양식이기 때문입니다.

| # | 축 | 왼쪽 극 | 오른쪽 극 | 어디서 읽는가 |
|---|---|---|---|---|
| 1 | **빛** | Vesper *(황혼, 따뜻함, 단일 광원)* | Meridian *(정오, 차가움, 환경광)* | 이미지 시간 + 색온도 |
| 2 | **밀도** | Hush *(빈 방, 여백)* | Loam *(층층의, 장식된)* | 이미지 엔트로피 + 음향 밀도 |
| 3 | **템포** | Stilled *(아다지오)* | Pulsing *(알레그로)* | BPM, 컷 밀도, 문장 리듬 |
| 4 | **표면** | Stone *(무광, 무게감, 광물)* | Smoke *(확산, 대기적, 부드러움)* | 재료 분류기 + 음향 리버브 |
| 5 | **기하** | Wabi *(비대칭, 우연, 흔적)* | Aurum *(정밀, 대칭, 황금비)* | 엣지 분석 + 구성 점수 |
| 6 | **거리** | Intimate *(클로즈업, 실내)* | Sublime *(지평선, 스케일, 외부)* | 이미지 깊이 + 공간 분류 |
| 7 | **기후** | Boreal *(차갑고 건조한, 광물)* | Monsoon *(따뜻하고 습한, 유기물)* | 색 + 채도 + 공간 유형 |
| 8 | **시대** | Linen *(전산업, 수공)* | Chrome *(2020 이후, 스크린-네이티브)* | 스타일 분류 + 음향 제작 시대 |
| 9 | **목소리** | Whispered *(절제, 생략)* | Declared *(직설, 선언)* | 어휘 분석 + 음향 다이내믹 |
| 10 | **자세** | Inward *(내성, 1인칭)* | Outward *(관찰, 3인칭)* | 인용 대명사 + 자기존재감 |
| 11 | **시간** | Anteroom *(이전, 기대)* | Afterlight *(이후, 잔여)* | 어휘 시제 + 이미지 시간 |
| 12 | **위험** | Tended *(큐레이션, 안전, 정제)* | Feral *(거친, 미정돈, 위험)* | 구성 + 다이내믹 레인지 |
| 13 | **동행** | Solitary *(사람 없음)* | Convivial *(군중, 목소리들)* | 이미지 내용 + 보컬 밀도 |
| 14 | **중력** | Levitating *(공기, 하늘, 들림)* | Rooted *(흙, 무게, 기저)* | 이미지 수직 무게중심 + 저음역 |

### 왜 14인가
12는 점성술 같았고, 16은 MBTI 같았습니다. 14는 문화적 짐이 없고, 시스템이 분위기 표류를 점검하는 주기인 보름과 정렬됩니다.

### 표시 규칙
- **모든 14개를 한 번에 보여주지 않습니다.** Genome 카드는 `|axis_value - 0.5| × confidence` 기준 가장 강한 **여섯 개**를 보여줍니다.
- 표시에는 **극의 이름**을 쓰고, 퍼센트는 쓰지 않습니다. *"늦은 Vesper, 약간 Hushed, 강하게 Boreal."*
- 극 이름은 이탤릭. 숫자는 JSON에 있되 화면에는 없습니다.

## 5. 분위기 프로파일링

분위기 층은 단순한 질문에 답합니다: *당신의 취향이 장소라면, 어떤 장소인가?*

여덟 가지 구체적 프로파일링:

```
┌──────────────────────────────────────────────────────────────┐
│  주요 시간:        늦은 오후 (15:40–17:20)                   │
│  주요 기후:        건조-서늘, 알프스-해안성                   │
│  주요 재료:        오크 · 린넨 · 브러시드 황동                │
│  주요 빛:          단일 광원, 북향, 3200K                     │
│  주요 음 바닥:     32–38 dB (조용한 방)                       │
│  주요 페이스:      아다지오 (62 bpm 등가)                     │
│  주요 스케일:      인간, 단일 방                              │
│  주요 날씨:        비 온 뒤                                  │
└──────────────────────────────────────────────────────────────┘
```

### 팔레트
5색 팔레트는 (1) 모든 이미지에서 우세한 색을 풀링(CIELAB 중간컷, 지각적 중복 제거), (2) 음향 색온도 선호와 교차참조(따뜻한 소리는 동률 시 팔레트를 따뜻하게 편향), (3) 풀 면적의 35% 초과 시 *제외* — 과대표된 색은 캐릭터가 아니라 배경.

팔레트는 *이름이 붙습니다*. 단지 보여지는 게 아닙니다.
> *Oak, ash, ember, fog, ink.*

## 6. 철학적 정렬 시스템

가장 섬세한 하위 시스템. 잘못하면 별자리 같고, 잘하면 사용자들이 서로에게 인용하는 부분이 됩니다.

### 사조 (큐레이션된 집합, 망라 아님)

각 "사조"는 L2 축 전반의 예상 성향 벡터와, 대표 인용·이미지·인물의 코퍼스를 가집니다.

| 사조 | 성향 시그니처 (일부 축) | 표면화 금지 조건 |
|---|---|---|
| **스토아** | Inward · Stilled · Stone · Tended | 높은 Feral, 높은 Convivial |
| **낭만** | Sublime · Pulsing · Vesper · Feral | 높은 Tended, 높은 Linen-cool |
| **도가 / 무위** | Hush · Wabi · Solitary · Levitating | 높은 Aurum, 높은 Declared |
| **실존주의** | Inward · Anteroom · Smoke · Whispered | 낮은 Inward |
| **현상학** | Intimate · Stone · Whispered · Hush | 낮은 Intimate |
| **초월주의** | Sublime · Boreal · Rooted · Outward | 높은 Chrome, 높은 Convivial |
| **와비사비** | Wabi · Linen · Stone · Hush | 높은 Aurum, 높은 Chrome |
| **에피쿠로스** | Loam · Monsoon · Convivial · Afterlight | 높은 Stone, 높은 Hush |
| **부조리** | 역류 존재, 높은 목소리 분산, 아이러니한 가치 | 역류가 있을 때만 부여 |
| **선(禪)** | Hush · Wabi · Solitary · Stilled · Stone | 높은 Loam, 높은 Pulsing |
| **부정신학 / 신비** | Smoke · Whispered · Anteroom · Levitating · Hush | 높은 Declared, 높은 Rooted |
| **스토아-모더니즘 하이브리드** | Stone · Aurum · Tended · Inward · Boreal · Chrome | (Kinfolk-but-rigorous 타입) |

### 정렬, 할당 아님

시스템은 "당신은 도가입니다"라고 하지 않습니다. 대신:

> *"당신의 가장 강한 세 흐름 — Hush, Wabi, Solitary — 은 도가 미학이 흐르는 흐름이기도 합니다. 친족 관계는 부분적입니다: 당신의 템포가 전통이 기대하는 것보다 빠릅니다. 그 빠른 맥박은 당신의 것입니다."*

정렬은 **친족 점수**(사용자 L2 벡터와 사조 프로토타입 벡터의 코사인)로 보고되며, 항상 *불일치하는 부분*과 함께. 불일치가 사용자의 서명입니다.

### 공명 집합

단일 라벨 대신, Genome은 **2–3개** 철학적 공명을 — 각자의 친족 강도와 마찰점과 함께 — 드러냅니다.

## 7. 취향 카테고리 — 흐름(Currents)

Genome에서 카테고리는 **흐름(Currents)**으로 불립니다. 유형이 아닙니다. 흐름은 매니폴드의 명명된 방향이지 사용자가 앉는 상자가 아닙니다. 사용자에게는 언제나 여러 흐름이 서로 다른 강도로 흘러갑니다.

### 흐름의 속성
- 미리 정의되지 않고 생성됨 — 각 사용자의 흐름은 16개의 목록에서 뽑히지 않고 그들을 위해 명명됩니다.
- 두 단어 명사구, 묘사적이지 않고 환기적: *"Lacquered Dusk", "Northern Linen", "Salt-Air Modernist", "Velvet Cartographer", "Quiet Vermilion", "Cedar Mathematician", "Postcard Pilgrim", "Inland Apothecary".*
- 각 흐름은 **강도**(0–1)와 **안정성**(몇 주간 지속되었는가)을 가집니다. 안정성은 작은 주석으로: *"steady — 14 weeks"* 또는 *"newly forming."*

### 생성
이름 짓기 패스는 Claude 호출로:
- 그 흐름의 클러스터에 대한 상위 6축 (극 이름 형식)
- 우세 팔레트 토큰
- 대표 증거 3개 (이미지 캡션, 가사 단편, 인용 단편)
- 스타일 브리프: *"두 단어. 명사구. 구체 + 대기. 진부함 없음. 'minimalist' 없음, 'vibes' 없음."*

모델이 후보 8개 반환 → 차단 목록(업계 유행어 코퍼스) 대조 후 미학적-당혹도 점수로 선택.

### 몇 개의 흐름인가
대부분의 Genome은 **2–4개**. 더 감지되어도 표시는 3개로 캡, 그리고 *말합니다*: *"여기 네 번째 흐름이 있어요, 더 희미한. 지켜보고 있어요."*

## 8. 시네마틱 인물 보고서

Genome의 헤드라인 출력은 **속성 목록이 아닙니다**. 250–400단어의 짧은 시네마틱 산문 초상화, 2인칭, 에세이적 영화처럼 구조화됩니다.

### 구조 (보고서의 네 막)

```
┌────────────────────────────────────────────────────────────┐
│  I.   장소     — 분위기를 먼저 설정                        │
│           "늦은 오후, 그런 종류의…"                        │
│                                                            │
│  II.  패턴     — 증거와 함께 2–3개 흐름 명명               │
│           "당신이 저장하는 것들에서 세 가지가 계속 나타나요:"│
│                                                            │
│  III. 긴장     — 역류 표면화                               │
│           "그리고 — 다른 무언가."                           │
│                                                            │
│  IV.  한 줄    — 한 문장, 미러                             │
│           이탤릭, 자신의 카드 위에 홀로                     │
└────────────────────────────────────────────────────────────┘
```

마지막 줄은 **미러 문장** — 온보딩을 닫는 동일한 인공물. 위의 산문이 쓰인 후 마지막에 생성되며 다음 제약을 받습니다:
- 정확히 한 문장.
- 2인칭.
- 구체-그다음-추상 또는 추상-그다음-구체 — 둘 다 추상은 결코 아닙니다.
- "당신은 …같아요" 형식의 비유 금지 (이 자리의 직유는 아첨처럼 읽힙니다).
- *정신적으로 반증 가능해야* 합니다 — *틀릴 수도 있는* 무언가를 말해야 합니다, 그래야만 보는 것처럼 느껴집니다.

### 생성 프롬프트 (Claude, 스케치)

```
SYSTEM: 당신은 Taste Genome 보고서의 한 단락을 씁니다. Genome은 한 사람의
취향에 대한 끈기 있고 증거 주도적인 초상 — 성격 검사가 아니고, 마케팅
카피가 아니고, 별자리표가 아닙니다. 2인칭, 현재 시제로, 누군가의
사적인 무드보드를 건네받고 자신이 본 것을 묘사해 달라는 요청을 받은
사려 깊은 미술 평론가의 어조로 씁니다.

규칙:
- 행동을 결코 예측하지 말 것. 증거가 보여주는 것만 묘사할 것.
- 결코 아첨하지 말 것. 사용자는 위로받지 않고 관찰받았다고 느껴야 함.
- 구체 명사를 쓸 것. 특정 이미지와 짝짓지 않은 추상은 피할 것.
- "vibe", "aesthetic", "minimalist", "cozy", "주인공" 같은 단어 금지.
- 이탤릭은 단락당 증거 한 조각과 마지막 줄에만 허용.
- 마지막 줄은 정신적으로 반증 가능해야 함 — 안전한 보편 진리가 아니라
  사람에 대한 실제 주장으로, 틀릴 수도 있어야 함.

USER: 사용자의 L2 벡터, 상위 축, 흐름, 우세 팔레트, 우세 시간, 철학적
공명, 역류 관찰 3개, 구체적 증거 4조각(인용 그대로, 이미지 캡션,
트랙 제목)을 받아 보고서를 쓰세요.
```

### 길이, 어조, 리듬
- 250–400 단어. 250 미만은 얄팍하고, 400 초과는 과도합니다.
- 평균 문장 길이: 14–22 단어. 보고서는 *호흡해야* 합니다.
- 단락당 이탤릭 구절 최대 하나.
- 산문 안에 소제목 없음 — 네 막은 느껴지지, 표지로 드러나지 않습니다.

### 샘플 (예시)

> 늦은 오후입니다, 의도 없이 당신이 써 내려간 보고서 안에서. *북향의 빛, 나무를 돋보이게 하고 피부를 너그러이 봐주는 종류.* 당신이 저장하는 방들은 창이 하나씩 있습니다. 당신이 저장하는 음악은 목소리가 하나씩 있습니다. 인용조차도 — 셋이 있고, 셋 다 떠남에 관한 것입니다.
>
> 세 흐름이 흐릅니다: 하루의 중심이 아니라 끝의 따뜻함을 선호하는 *Lacquered Dusk*; 자신의 아름다움이 씻기고 무게 잡히길 원하는 *Northern Linen*; 그리고 희미한 세 번째 — *Cedar Mathematician*이라 부르겠습니다 — 아무도 보지 않을 때의 정밀함을 사랑하는.
>
> 그리고 — 142 BPM의 트랙 하나, 단 하나. 불의 사진 하나, 단 하나. 바다에 관한 한 줄, 단 하나. 이것들은 실수가 아닙니다. 한 사람의 가장 진실한 부분은 종종 나머지와 모순되는 부분입니다.
>
> *당신은 아름다움을 모으는 게 아니에요 — 한때 세상이 누군가에게 다정했다는 증거를 모으는 거예요.*

## 9. 감정 진화 지도

Genome은 **움직이는** 초상화입니다. 진화 지도는 그 움직임이 보이는 표면입니다.

### 세 보기
1. **표류(Drift)** — 시간에 걸친 L2 위치의 UMAP 2D 플롯, 희미한 자취. 대부분의 사용자는 거의 멈춰 있고 천천히 공전합니다. 일부는 계절적으로 표류, 드물게 극적으로 이주.
2. **축-시간** — 14축의 small multiples, 각각 사용자 이력 위의 헤어라인 곡선. *y축은 수치로 렌더링하지 않습니다.* 곡선의 극점에 극 이름을 렌더링.
3. **흐름-시간** — 명명된 흐름들의 강도가 주별로 누적 영역 차트. 새 흐름이 도착하고, 옛것이 옅어집니다.

### 주석
중요한 변곡점은 작은 `·`와 한 줄 메모로 표시: *"9주 차쯤, 따뜻한 빛 쪽으로의 전환."* 보수적으로 — 데이터가 정당화할 수 있는 것보다 적게, 그래서 각 주석이 *값어치 있게* 느껴지도록.

### 시간 입도
- 처음 3개월은 주간 샘플.
- 이후 월간.
- 사용자가 적어도 네 개의 주간 샘플을 가지기 전엔 지도가 렌더링되지 않음 — 시스템은 명시적으로 *"너무 일러요. 한 달 뒤에 와요."*

### 닻(The Anchor)
L3 / 헌법 층은 지도에서 움직이지 않습니다. Drift 보기에 정지된 닻점 — 희미한 십자가 — 으로 렌더링됩니다. 사용자의 L2 자취가 움직이고, 닻은 움직이지 않습니다. 자신의 L2 자취가 자신의 헌법 주위를 공전하는 것을 지켜보는 것 — 제품에서 가장 마음을 흔드는 시각화이며, 우리는 다른 어떤 것도 이렇게 진지하게 만들지 않았습니다.

| 2 — 인코딩 | 4–8초 | GPU 풀, 모달별 배치 |
| 3 — 투영 | <100ms | 임베딩이 준비되면 저렴 |
| 4 — 클러스터링 | 1–2초 | UMAP가 병목; 증거 변동 <10%면 캐시 |
| 5 — 패턴 | <500ms | 순수 CPU |
| 6 — 정렬 | <100ms | 코사인 배치 |
| 7 — 서사 | 12–20초 | 병렬 Claude 호출 2개: 흐름 + 보고서/미러 |
| 8 — 게이트 | 최소 30초 | 시간은 지연이 아니라 경험 |

### 시간에 따른 업데이트
서사 보고서는 기본적으로 **월간** 재생성, 또는 사용자 요청 시. 미러 문장은 L3 층이 측정 가능하게 이동했을 때만 재생성 (벡터 델타 > 0.15 코사인) — 보통 4–9개월마다. 사용자는 미러가 바뀔 때 조용한 이메일을 받습니다: *"당신 안의 무언가가 천천히 돌아섰어요. 준비되면 보러 오세요."*

## 11. 실패 모드 & 안전장치

### A — 아첨 표류
**증상.** 보고서가 별자리표처럼 느껴짐: 따뜻하고, 동조적이며, 반증 불가능.
**안전장치.** 모든 보고서는 *틀릴 수도 있는 관찰* 하나를 반드시 포함. 합성 프롬프트가 강제하고, 사후 분류기가 모든-동조 문장 보고서에 재생성 플래그.

### B — 문화적 협소함
**증상.** 어휘가 일본-스칸디나비아-이탈리아로 기울고, 모든 이미지가 Kinfolk 아카이브처럼 읽히고, 모든 철학적 공명이 스토아 또는 도가.
**안전장치.** 사조 목록, 재료 어휘, 팔레트 명명 코퍼스가 명시적으로 다지역(서아프리카 텍스타일 어휘, 남아시아 색 체계, 라틴아메리카 공간 원형, 중동 빛 전통). 생성 프롬프트는 최근 50건 생성의 네 개 최빈 지역 단어를 피하도록 샘플링 지시 포함.

### C — 콜드스타트 공허함
**증상.** 사용자가 최소한의 헌물만 줌, Genome이 얄팍하게 읽힘.
**안전장치.** 시스템이 투명하게: *"여기까지 보입니다. 아직 함께 걷지 않은 다섯 방이 있어요."* 확신 리본은 가시적으로 옅어짐. 허구를 만드는 유혹에 저항.

### D — 유형 침범
**증상.** 시간이 지나며 산문이 여러 사용자에 걸쳐 반복되는 작은 명명 흐름 집합에 기댐.
**안전장치.** 흐름은 사용자별 생성. 주간 작업이 1,000개의 흐름 이름을 샘플링, 사용자의 >0.5%에서 반복되는 것을 미래 생성에서 차단.

### E — 정체성 포획
**증상.** 사용자가 *Genome을 위해* 큐레이션 시작 — 보고서를 조작하려 저장.
**안전장치.** L3 / 헌법 층은 Genome 조회와 시간적으로 상관되는 증거를 명시적으로 할인하는 느린 감쇠 업데이트 규칙. 큐레이션 패턴 변화 시 부드럽게 노트: *"요즘 더 의도적으로 저장하고 있네요. 괜찮아요. OS는 진짜를 기다릴게요."*

### F — 감시당하는 느낌
**증상.** 사용자가 분석당했다고 느낌, 목격받았다고 느끼지 않음.
**안전장치.** §8의 보이스 규칙이 예측적 표현을 금지. 시스템은 증거를 묘사하지, 추론된 행동을 결코 묘사하지 않음. *"당신은 아마 …에 어려움이…"* 같은 말은 하지 않음. *"당신의 증거는 유난히 조용해요 — 삶의 큰 부분들이 여기엔 그 여운으로만 나타나요."* 이 차이가 전부입니다.

## 닫는 말

Genome의 일은 작고 어렵습니다: 한 사람에게 그가 아직 소리 내어 말하지 못한 자신에 대한 진실 하나를 들려주는 일 — 아첨 없이, 카테고리 없이, 증거가 허락하는 것 이상을 주장하지 않으면서.

성공한다면 사용자는 어디 사적인 곳에 — 메모 앱, 일기, 배경화면 — 한 문장의 스크린샷을 간직할 것입니다. 그 문장이 우리가 신뢰하는 유일한 지표입니다.
