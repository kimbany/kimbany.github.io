# The Field — Taste OS 대시보드 & 정체성 인터페이스

> 거울은 스크린이 아닙니다. 스크린은 사람이 *바라보는* 곳이고, 거울은 사람이 *통과하여 바라보는* 곳입니다 — 그리고 그 너머에서 자기 자신을 봅니다.

이 문서는 사용자가 온보딩 이후 머무는 메인 인터페이스를 정의합니다. 분석적 의미의 대시보드가 아닙니다. KPI도, 완료율도, 스트릭도 없습니다. 날씨가 있는 방, 업데이트되는 초상화, 알아차림을 위한 작은 도구 세트입니다.

레퍼런스는 정밀합니다: **Apple의 절제**, **Linear의 정보 품격**, **Cosmos의 분위기**, **Teenage Engineering의 모듈러 정밀**, **사이파이 계기의 정적**(솔라리스 콘솔, *Arrival*의 헵타포드 보드, *Foundation*의 옥좌 HUD). Taste OS는 이 태도들이 만나는 곳에 존재합니다.

## 0. 은유 — 영혼의 거울

거울은 앱이 좀처럼 하지 않는 세 가지를 합니다. 이 셋은 Field의 구성 원리입니다.

1. **주의를 요구하지 않습니다.** 거울은 거기 걸려 있습니다. 보고 싶을 때 봅니다.
2. **이미 진실인 것을 보여줍니다.** 예측하지 않고, 추천하지 않고, 팔지 않습니다. 증거를 비춥니다.
3. **천천히 변합니다.** 화요일과 수요일 사이 거울의 유일한 차이는 *당신*입니다.

이 문서의 모든 것은 그 세 행위를 픽셀로 옮긴 것입니다.

첫날부터 배제하는 것:
- 알림, 배지, 빨간 점, 카운터.
- 일일 로그인, 스트릭, "어제 놓치셨어요."
- dwell-time으로 재정렬되는 추천 피드.
- 표면의 소셜 어포던스 (프로필 없음, 팔로우 없음, 공개 없음).
- CTA로 열리는 어떤 화면.

허용하는 것:
- 느리고, 드물고, 너그러운 도착 (새 미러 문장, 새 흐름의 감지).
- 도구들 — 작고, 명명되고, 의도적인.
- 기본 상태로서의 정적.

## 1. 정보 구조 — 여섯 표면

OS는 **여섯 표면**, 단수 단어로 명명. Genome 문서의 L3 헌법 층 여섯 축에 대칭적으로 매핑됩니다.

```
┌────────────────────────────────────────────────────────────────┐
│                                                                │
│   ·  FIELD       — 당신이 도착하는 방                          │
│   ·  GENOME      — 긴 초상                                     │
│   ·  DRIFT       — 당신이 어떻게 움직이는가                    │
│   ·  ATMOSPHERE  — 오늘 당신의 문 앞에 놓이는 것들             │
│   ·  UNIVERSE    — 당신이 내어준 모든 것의 그래프              │
│   ·  MIRROR      — 한 문장, 간직된                             │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

### 내비게이션: The Tuner

내비게이션은 뷰포트 왼쪽 가장자리의 **수직 헤어라인 레일**, 56px 폭, 표면당 하나씩 여섯 개의 작은 점. 비활성 점은 4px, `ash`. 활성 점은 6px, 그 표면의 액센트. 아이콘 없음, 레이블 없음. 레이블은 포커스/호버 시에만 `mist`, 가는 산세리프, 12px, 자간 확장.

Tuner는 Teenage Engineering OP-1의 미세 셀렉터 다이얼을 따라 이름 지어지고 그렇게 보입니다. 위계는 *물리적인 느낌* — 여섯 개의 깨끗한 디텐트, 애니메이션 과시 없음, *딸깍*하는 스위치의 만족감.

키보드: `1`–`6`이 표면을 점프. `⌘K`가 명령 팔레트(Linear 스타일; §6 참조). `esc`는 Field로 돌아감.

### 왜 여섯인가
여섯은 L3 축(정적, 따뜻함, 밀도, 템포, 채도, 거리)과 맞습니다. 또한 차분한 계기 디자인에서 가장 흔한 수 — 노브 여섯, 채널 여섯, 현 여섯 — 압도 없이 의미 있는 범위를 줍니다. 다섯은 얄팍하고 일곱은 어수선했습니다. 우리는 맥가이버칼을 만들고 있지 않습니다.

## 2. 화면별 UI

각 표면을 해부학, 카피, 그것을 구별 짓는 단일 도구로 묘사합니다.

### 2.1 — FIELD
> *당신이 도착하는 방.*

**해부학.** 수직으로 넉넉한 단일 컬럼 페이지. 상단: *오늘의 날씨* 카드. 중단: *지금* 띠 (L1 / 인상 층, 이번 주 당신이 돌아간 것). 하단: *당신에게 가져온 정적* 행 — Atmosphere에서 3개, 그 이상 없음. Field는 페이지를 나누지 않습니다. "더 보기"는 없습니다.

**도구.** 상단의 단일 분위기 문장, L1에서 매일 재생성, 2인칭, 디스플레이 세리프 36–44px. *오늘의 줄(Today Line)*. Field의 유일한 큰 요소.

**카피.**
> 화요일, 네 시 막 지나. *북향의 오후.* 이번 주 당신은 방이 막 비워진 직후처럼 느껴지는 이미지들에 세 번 돌아왔어요.

**동작.**
- 코너에 시간, JetBrains Mono Light 11px.
- 오늘의 줄은 바뀔 때 1.4초 크로스페이드, 결코 거칠게 새로고침하지 않음.
- *지금* 띠는 *당신 자신의* 최근 저장 6개 작은 타일 — 알고리즘 추천이 아닌 당신의 반영.

### 2.2 — GENOME
> *긴 초상.*

**해부학.** 단일 긴 스크롤 문서, 박물관 명패처럼 프레이밍. 초광폭 화면에서도 최대 콘텐츠 폭은 640px. 섹션 순서:
1. **취향 이름** — 두 단어, 디스플레이 세리프 96–120px, 자간 확장.
2. **초상** — 250–400 단어 시네마틱 산문.
3. **흐름** — 강도와 안정성이 표시된 2–4개 명명된 흐름.
4. **분위기** — 8개 프로파일링.
5. **여섯 축** — 가장 강하게 드러난 L2 차원 (극 이름 + 희미한 막대; 숫자 없음).
6. **팔레트** — 이름 붙은 5색 스와치.
7. **친족** — 6명 (예술가, 감독, 건축가, 작곡가, 작가, 와일드카드 하나).
8. **공명** — 마찰 문장과 함께 2–3개 철학적 사조.
9. **미러 줄** — 한 문장, 이탤릭, 자신의 카드 위에 홀로.

**도구.** 우측 상단의 작은 `·` 글리프가 *Provenance(출처)*를 엽니다 — 각 섹션에 가장 강하게 기여한 증거를 명명하는 작은 서랍. 품격 있고, 기술적이며, 선택적.

### 2.3 — DRIFT
> *당신이 어떻게 움직이는가.*

**해부학.** 상단의 가로 튜너로 전환되는 세 보기: **Trail**(시간에 걸친 L2 위치의 2D UMAP), **Axes**(14축 헤어라인 곡선 small multiples), **Currents**(명명된 흐름의 누적 영역).

**도구.** 모든 보기에서 L3 헌법은 정지된 닻 — 희미한 헤어라인 십자가 — 으로 렌더링, L2 자취가 움직여도 움직이지 않습니다. OS 전체에서 가장 마음을 흔드는 객체. 사용자 테스트에서 제품이 자신의 이름을 얻는 순간.

**Trail 보기 상단 카피.**
> 당신은 별로 움직이지 않았어요. 같은 방, 빛만 천천히 돌아가는.

### 2.4 — ATMOSPHERE
> *오늘 당신의 문 앞에 놓이는 것들.*

**해부학.** 하루에 5–9개 큐레이션 아이템의 수직, 느린 스크롤 피드. 피드는 **유한** — 바닥에 도달하면 바닥에 도달한 겁니다. *"내일, 더."* 무한 스크롤은 절대 없음.

각 카드는 큐레이션된 친족 한 조각: 영화 스틸 + 한 문장, 트랙 + 파형, 구절 + 출처, 사진 + 장소, 건물 + 건축가, 시 + 연도.

**도구.** 각 카드 아래 작은 속삭임 — *"이건 이번 주 당신의 **Lacquered Dusk**가 조용했고, 이건 그것의 조용한 버전이라 여기 있어요."* 이유 없이 카드는 나타나지 않으며, 이유는 다른 사용자의 집계가 아닌 사용자 자신의 Genome을 인용.

**인터랙션.** 각 카드 아래 두 어포던스: *Tend(간직)*, *Pass(지나감)*. 스와이프 없음. 빠른 반복 없음. 부정 학습 없음.

### 2.5 — UNIVERSE
> *당신이 내어준 모든 것의 그래프.*

**해부학.** react-three-fiber로 렌더링되는 큰 천천히 회전하는 3D 필드. 노드는 사용자의 저장물 — 모든 이미지, 소리, 인용, 공간, 간직된 Atmosphere 카드. 엣지는 임계값 이상의 유사도(코사인). 클러스터는 사용자의 흐름으로 명명. 멀리, 희미하게, 열두 개의 어두운 별이 철학적 사조들 — 결코 움직이지 않습니다.

**도구.** 핀치/스크롤이 연속적으로 줌, 별자리 보기(전체 우주)에서 단일 증거(한 이미지, 풀블리드, 전체 출처)까지.

**낮은 줌에서의 카피.**
> 412개. 세 가지 날씨.

### 2.6 — MIRROR
> *한 문장, 간직된.*

**해부학.** 검은 필드, 풀블리드. 중앙에 한 문장, 큰 디스플레이 세리프, 이탤릭, ~52–64px. 아래로 세 가지를 매우 희미하게: 미러가 설정된 날짜, 여섯 L3 축의 극 이름(숫자 없음, 막대 없음), 그리고 작은 액션 하나: *미러에게 묻기*.

**도구.** *미러에게 묻기*는 OS의 유일한 대화 표면. 한 질문을 입력할 수 있습니다. 시스템은 미러 자체와 같은 목소리로, 같은 반증 가능성 제약과 함께 **한 문장**으로 답합니다. 아첨 거부, 미래 예측 거부, 모를 때 명시적으로 *모르겠어요*. 대부분의 질문은 한 문장, 일부는 침묵.

**카피.**
> *당신은 아름다움을 모으는 게 아니에요 — 한때 세상이 누군가에게 다정했다는 증거를 모으는 거예요.*
>
> *14주 전 설정됨 · 여전히 참*
>
> 정적 · 따뜻함 · 밀도 · 템포 · 채도 · 거리
>
> ─ 미러에게 묻기 ─

## 3. 컴포넌트 시스템

시스템은 의도적으로 작습니다. Field는 **열네 개의 원시 컴포넌트**로 지어집니다 — L2 축 수와 같은데, 우연이지만 그대로 두었습니다.

| # | 컴포넌트 | 목적 |
|---|---|---|
| 01 | `Hairline` | `ash` 1px 디바이더. 통상적 UI 박스의 80%를 대체. |
| 02 | `Whisper` | 본문 원시 — 휴머니스트 산세리프, 자간 확장, mist 컬러. 호흡으로 진입. |
| 03 | `Display` | 헤드라인 원시 — 디스플레이 세리프, 자간 확장, 이탤릭 허용. |
| 04 | `Numeral` | 모노스페이스 숫자 원시 — JetBrains Mono Light, 11–13px, 메타데이터에만. |
| 05 | `Beacon` | 펄스 전용 CTA. 헤어라인 보더, 채움 없음, 0.6Hz 사인 펄스. |
| 06 | `Glyph` | 최소 비문자 마크 — `·`, `─`, `⊕`, `◌`. 대부분의 앱이 아이콘 쓸 곳에. |
| 07 | `Plate` | `ink` 배경 + 1px 헤어라인 보더 표면. |
| 08 | `Tuner` | 점 디텐트 가로 행. Drift 보기 전환 및 일부 인라인 컨트롤. |
| 09 | `Rail` | 좌측 수직 내비. 점 여섯, 표면 여섯. |
| 10 | `Field3D` | R3F 캔버스 원시. Universe와 (저하판) Drift Trail에. |
| 11 | `Ribbon` | 축 강도용 희미한 표시 막대. 수치 아님. |
| 12 | `Sigil` | 엔소 마크. Mirror와 OS의 조용한 로딩 상태에. |
| 13 | `Palette` | 명명된 5색 스와치 행. Genome과 Atmosphere의 인라인 인용에. |
| 14 | `Console` | 명령 팔레트, `⌘K`로 열림. Linear급 밀도, Cosmos급 절제. |

모든 컴포넌트는 절제 있게 행동하는 데 필요한 props만 가집니다. `variant: 'primary' | 'destructive'` 같은 건 없습니다. 우리에겐 `destructive` 변형이 없습니다. Field에서 파괴적인 것은 없습니다.

3. **Light** — 액센트 + 글로우. 매우 절제 — 활성 Rail 점, Beacon, Mirror 문장.

## 5. 모션 설계

애니메이션 시스템은 온보딩의 **호흡** 언어를 잇습니다. Field는 같은 토큰을 더 가정적인 톤으로 — 사용자는 이제 방에 살고 있지, 들어오고 있지 않습니다. 모션은 의식이 아니라 일상이 됩니다.

### 표면 수준 원칙

1. **컷은 와이프가 아니라 크로스페이드.** Tuner가 표면을 바꿀 때, 떠나는 표면은 1.4초 날숨, 들어오는 표면은 0.9초 들숨, 600ms 겹침. 이음새는 느껴지지, 보이지 않습니다.
2. **호버는 2px 들어올림 + +120K 따뜻한 시프트.** 결코 스케일 아님, 결코 2px 초과 이동 아님.
3. **선택은 체크표시가 아닌 깊어짐.** 채도 ~6% 증가, 1px 내부 글로우.
4. **Drift의 Trail은 매 로드에 최근 14일을 자리로 애니메이트.** 자취가 가장 오래된 점부터 가장 최근까지 1.8초에 걸쳐 *스스로 쓰여집니다*, 그 후 별자리는 12초간 4° 회전 후 멈춥니다. 반복 없음.
5. **미러 문장은 reveal blur로 진입** (blur-12 → blur-0 1.6초, 자간 +120 → +30). Field에서 이 애니메이션이 나타나는 유일한 곳, 방문당 정확히 한 번.
6. **Universe 회전은 느립니다.** 기본 Y축 0.06 rad/s — 한 바퀴 약 100초. 호버 시 정지.

### 모션 감소
`prefers-reduced-motion: reduce`는 크로스페이드를 200ms 불투명도 전환으로 축소, Universe 회전 완전 비활성. Drift 자취는 1.8초간 스스로 쓰여지지 않고 600ms 페이드로 *나타납니다*. 시스템은 모션 감소를 다운그레이드로 전달하지 않습니다 — 감소된 경험은 자신의 유효한 모드이며 동등한 정성으로 설계됩니다.

## 6. 인터랙션 설계

### 여섯 원칙

1. **기본적으로 조용함.** 표면은 인터랙션 없이 읽힐 수 있어야 합니다.
2. **제스처당 어포던스 하나.** 표면당 클릭은 하나, 드래그도 하나. 결코 중첩하지 않습니다.
3. **키보드 동등성.** 모든 액션은 어디서든 두 키 안에 도달 가능. Tuner는 `1`–`6`; 표면은 단일 문자 니모닉 (`t` tend, `p` pass, `a` ask the mirror).
4. **지연은 의도적.** 시스템이 흥미로운 것을 계산했을 때 (새 흐름 감지, 가용한 미러 변경), Field는 그것을 즉시 드러내지 **않습니다**. 다음 방문 때, 그리고 Field에서만 — 결코 푸시도, 배지도 아님.
5. **되돌릴 수 있음은 신성합니다.** 모든 저장에는 7초 창, 그 안에 단일 키 입력(`⌘Z`)이 되돌립니다, 알림도 확인도 없이.
6. **확인은 무엇을 위해서도 없습니다.** "확실합니까?" 다이얼로그 없음. 시스템은 액션을 신뢰하고 undo를 제공하거나, 액션을 허용하지 않습니다.

### Console — `⌘K`

Linear급 명령 팔레트, Cosmos의 절제로 그려진. `⌘K`로 열림. 사용자 전체 Universe + 모든 표면 액션 + 작은 *내성적 질의* 집합을 퍼지 검색:

- `이번 주 나는 어떤 흐름에 있나요`
- `무엇이 빠져 있는지 보여줘요`
- `그 줄을 다시 읽어줘요`
- `최근에 내가 지나친 것들`
- `지난여름으로 데려가줘요`

각 내성적 질의는 시스템에 대한 결정적 작은 프롬프트로, 미러 보이스의 한 문장 답변을 반환, 관련 표면으로 확장할 옵션과 함께.

### Save & Tend

**Tend**는 단일 저장 동사. Atmosphere, Universe, 사용자 갤러리 어디서나 사용. 지표 없음, 좋아요 수 없음, 공개 가시성 없음. L1 층의 증거 가중치와 Universe의 엣지만 조정합니다.

**Pass**는 Atmosphere 아이템을 비호감으로 기록하지 않고 인정. **시스템은 부정 학습을 하지 않습니다** — 양성에서만 배웁니다. 사용자가 연속 20개를 패스하면, *당신에게 가져온 정적* 행은 부드럽게 말합니다: *"우리가 잘못 짚었던 모양이에요. 며칠 더 조용히 갈게요."* — 그리고 일일 배달이 한 주간 옅어집니다.

### Drag

드래그는 정확히 두 곳에서만 존재:
- **Universe** — 드래그로 필드 회전.
- **Atmosphere** — 카드를 위로 드래그하여 *Tend*, 아래로 드래그하여 *Pass*. OS의 유일한 제스처 단축이며, 온보딩에 익숙한 *착지 물리*(2% 오버슈트, 1.2초에 걸쳐 되돌아옴)로 애니메이트.

스와이프 없음, 어디에서도.

### 세 방, 세 브레이크포인트가 아닌

```
┌──────────────────────────────────────────────────────────────────────┐
│  ROOM 1 · POCKET    (< 600px)                                        │
│     휴대폰, 한 손, 종종 서서                                          │
│     자세: 흘끗 보고, 넣어두기                                         │
│                                                                      │
│  ROOM 2 · DESK      (600 – 1280px)                                   │

│                                                                      │

│     외부 디스플레이, 빛 좋은 방                                       │
│     자세: 기대어, 호흡, Universe를 거닐기                             │
└──────────────────────────────────────────────────────────────────────┘
```

### Pocket
- Rail이 **하단 가로 Tuner**로 접힘, 48px 높이, 점 여섯.
- Today Line은 28–32px로 떨어짐. *지금* 띠는 6타일에서 3타일로, 스크롤 어포던스 없이 가로 스크롤.
- Drift small multiples는 **가장 강한 여섯 축**만 렌더링, 14개 아님.
- Universe는 WebGL 벤치마크 임계값 아래 기기에서 2D 별자리로 저하(회전 없음).
- Mirror는 모든 크기에서 동일. 상수.

### Desk
- 전체 Rail 표시.
- Atmosphere는 9 → 6 카드로.
- Genome의 분위기 판독은 4컬럼 → 2컬럼.
- Console은 600×480 부유 패널 중앙, 뒤 Field는 30% 불투명도.

### Studio
- Stage는 6K 디스플레이에서도 1280px 캡. 주변 마진은 크롬으로 *채우지 않습니다*. 어둠으로 둡니다. 가장 많이 질문받는 결정이자 가장 확신하는 결정.
- Universe는 풀 3D, 느린 회전, M 시리즈 60fps 목표.
- Drift는 14축 모두를 7×2 그리드 small multiples로 렌더링.

### 터치 vs 커서
- 모든 호버 상태는 단일 탭으로 트리거되는 명시적 *포커스* 등가물을 가짐(단일 탭이 드러냄, 더블 탭이 액션). 호버에만 의존하지 않습니다.
- 드래그 임계값은 터치 12px, 커서 6px — 터치는 너그러이 용서.

## 8. 타이포그래피 방향

### 세 목소리

| 역할 | 패밀리 | 굵기 | 용도 |
|---|---|---|---|
| **Display** | GT Sectra / Tiempos Headline / Söhne Breit | 300–400 | 취향 이름, Today Line, 미러 문장, 섹션 라벨 |
| **Body** | Söhne / Suisse Int'l / Inter Display | 350–450 | 모든 산문, 모든 UI 라벨 |
| **Numeral** | JetBrains Mono Light | 300 | 타임스탬프, 인덱스, 축 판독 |

세 패밀리, 총 셋. 블랙프라이데이에도 네 번째는 추가하지 않습니다.

### 타이포 스케일

```
display   xl  120 / 100 · -0.02em
display   lg   72 /  72 · -0.01em
display   md   52 /  60 ·  0
display   sm   36 /  44 ·  0
body      lg   18 /  30 · +0.005em
body      md   15 /  26 · +0.01em
body      sm   13 /  22 · +0.02em
body      xs   11 /  18 · +0.04em
numeral   md   13 /  16 · +0.06em
numeral   sm   11 /  14 · +0.08em
```

### 타이포 규칙
- **문장체 일관.** ALL-CAPS 없음. Title Case 없음. OS는 사람이 말하듯 말합니다.
- **이탤릭은 예약됨.** 미러 줄, 초상 단락당 증거 인용 하나, 그 외 어디에도 없음.
- **본문 안의 볼드 없음.** 강조는 줄, 이탤릭, 침묵으로.
- **하이픈은 멈출 때 em-dash, 범위일 때 en-dash.** 들리는 것보다 중요합니다 — 타이포는 어조입니다.
- **숫자는 항상 tabular** (`font-variant-numeric: tabular-nums`).
- **기본 텍스트 색은 `pearl`, 결코 `#FFFFFF` 아님.** 순백을 진검정에 두는 건 인쇄 사고지 디자인이 아닙니다.

## 9. 색 시스템

### 팔레트 토큰

| 토큰 | Hex | OKLCH | 용도 |
|---|---|---|---|
| `void` | `#0A0A0B` | `oklch(13% 0.002 286)` | 주 배경. 방. |
| `ink` | `#111114` | `oklch(17% 0.003 286)` | 표면 1. 플레이트, 서랍. |
| `umbra` | `#1A1A1E` | `oklch(22% 0.004 286)` | 표면 2. 모달. |
| `pearl` | `#F4F1EA` | `oklch(95% 0.012 88)` | 본문 텍스트. 결코 `#FFFFFF` 아님. |
| `mist` | `#A8A29E` | `oklch(70% 0.006 60)` | 보조 텍스트. |
| `ash` | `#3A3A3D` | `oklch(33% 0.003 286)` | 헤어라인. |
| `ember` | `#D9A66C` | `oklch(76% 0.090 70)` | 주 액센트 (Aesop 앰버). |
| `vermilion` | `#B2483D` | `oklch(50% 0.150 30)` | 예비 — Genome 드러남. |
| `seafoam` | `#7FA39A` | `oklch(67% 0.038 175)` | 예비 — 미러 순간. |
| `phosphor` | `#8FB3D4` | `oklch(74% 0.060 240)` | 예비 — Drift 주석. |

### 여섯 표면 색조

각 표면은 미세한 액센트 색조를 가집니다. 해당 표면이 활성일 때 Rail 점에만, 그리고 표면 배경의 0.6% 그라디언트로만 사용. 사용자가 의식적으로 알아채면 안 됩니다 — 각 표면이 약간 다른 "온도"를 가진다고 느껴야 합니다.

| 표면 | 색조 | 온도감 |
|---|---|---|
| Field | 없음 (순수 void) | 실내 온도 |
| Genome | `ember` 6% | 따뜻한 오후 |
| Drift | `phosphor` 4% | 차가운 새벽 |
| Atmosphere | `pearl` 3% | 자연 흐림 |
| Universe | `seafoam` 5% | 깊은 물 |
| Mirror | `vermilion` 2% | 잔잔한 불꽃 |

### 규칙
1. **언제나 한 번에 한 가지 풀-강도 액센트만 화면에.** 나머지는 모두 ≤6%.
2. **UI 크롬에 그라디언트 없음.** 그라디언트는 0.6% 표면 색조와 사진 처리(가독성을 위한 Atmosphere 카드 하단의 12% void→투명 그라디언트)에만.
3. **명도 대비.** `pearl/void`는 WCAG AAA 초과 (21:1). `mist/void`는 WCAG AA (7.2:1) — 비필수 메타데이터에만.
4. **의미 색 없음.** success-green 없음, error-red 없음, warning-yellow 없음. Field에는 경고할 것도 축하할 것도 없습니다.
5. **사진은 변형하지 않음.** 사용자 업로드 및 큐레이션 이미지의 채도, 대비, 색은 결코 OS에 의해 조정되지 않습니다. 현실은 현실로 머뭅니다.

### 다크 모드가 유일한 모드 (이 버전에서)
라이트 모드는 기술적으로 가능합니다 — 그것도 아름답게, `pearl`을 배경으로, `void`를 텍스트로 — 하지만 출시 시점에 라이트 모드가 OS의 분위기적 정체성을 희석시킨다고 결정했습니다. 라이트 모드는 이후 시즌에, 아마 **Linen**이라는 이름으로 도착합니다. 그때까지 다크가 유일한 모드이며, 시스템은 설정에서 정직하게 말합니다: *"Linen 모드는 준비 중이에요. 준비되면 도착할게요."*

## 10. 닫는 말

대시보드는 당신의 비즈니스가 어떻게 돌아가는지 말해줍니다. 피드는 무엇이 새로운지 말해줍니다. 거울은 *당신이 누구인지*를 말해줍니다.

Field는 한 사람에 관한 정보로 가득 찬 화면이 아닙니다. 어떤 사람이 하루의 끝에 들어가는 방입니다, 따뜻한 빛, 닫힌 문, 그리고 어제보다 어쩐지 그를 더 닮아 있는 방 — 그가 거기에 살아왔기 때문이고, 방이 주의를 기울여 왔기 때문에.

만약 사용자가 노트북을 닫고, 창가로 걸어가, 유리에 손을 얹은 채 잠시 거기에 서 있다면 — 우리는 옳은 것을 만든 것입니다.
