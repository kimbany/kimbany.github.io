# Taste OS — Sharing Studio / 보내기

> 좋아요도, 댓글도, 팔로워도 없는 *나눔*. 피드가 아니라 *서신*.

이 문서는 `sharing.md` 의 개념을 정적 페이지로 구현한 **Sharing Studio** 의 사양입니다. 컨셉의 깊은 토대는 `sharing.md` 를 참조하세요. 이 문서는 *이번 데모에서 무엇이 실제로 작동하는가* 에 집중합니다.

함께 읽기: `sharing.md` (7개 카드 타입의 컨셉 사양 — Mirror, Threshold, Genome, Atmosphere, Current, Palette, Kin), `voice.md` (한국어 보이스), `system.md` (디자인 토큰).

구현: `taste-os/share/index.html` + `style.css` + `script.js`.

## 0. 철학 한 줄

> *"좋아요" 대신, 한 사람이 카드 앞에서 보낸 *시간* 을 알 수 있어요. 댓글 대신, *그 사람의 카드 한 장* 이 답으로 와요.*

이 페이지는 *사용자가 자기 자신을 어떻게 내어줄지* 결정하는 작업실 — 작업실이지 *광장* 이 아닙니다.

---

## 1. 페이지 구조

세로 한 페이지. 다섯 섹션.

```
1. 인사  "당신의 풍경, 누군가에게 보낼까요?"
2. 네 장의 Taste Card 갤러리  (Quiet Warmth · Urban Nostalgia · Emotional Minimalism · Warm Futurism)
3. 카드 선택 시: 시네마틱 확장 보기  + 세 가지 내보내기 옵션
4. 정서적 공명 안내  ("좋아요 대신, 이렇게 답해요")
5. The Room 미리보기  "당신의 자리도 만들 수 있어요"
                                        
            ─ 닫는 한 줄 ─
                                        
```

---

## 2. 네 장의 Taste Card

사용자의 4가지 풍경 — 같은 사람의 다른 결. 한 명의 사용자가 *4개의 다른 정체성* 을 갖는 게 아니라, *한 정체성의 4가지 표현* 입니다.

| Card | Korean | 핵심 분위기 | Mirror Line |
|---|---|---|---|
| 1 | 조용한 따뜻함 | 늦은 오후 · 단일 광원 | 큰 빛보다, 작은 빛이 오래 가는 걸 알아요. |
| 2 | 도시의 향수 | 자정 · 도시 · 비 온 직후 | 사람들로 가득한 곳에서 가장 자기 자신이에요. |
| 3 | 감정의 미니멀리즘 | 정오 · 단일 색 · 여백 | 조용한 것이 깊을 수 있다는 걸, 일찍부터 알았어요. |
| 4 | 따뜻한 미래 | 새벽 · 빛 · 부드러운 금속 | 내일도 다정할 수 있다고 믿어요. |

### 카드의 시각 사양

`sharing.md` 의 공통 사양을 따릅니다:
- 5:7 portrait (모바일은 자동 조정)
- Sigil 좌상단, mist 24%
- 발신자 이름 (이 데모에서는 *"m."*)
- 헤어라인 구분
- 카드 자체 분위기에 맞춘 미세한 배경 tint
- 1° 미만의 무작위 회전 (시각적 따뜻함)
- 호버 시 2px 위로 + 색온도 +120K

### 갤러리 배치

2×2 그리드. 각 카드는 다른 idle drift 위상 (서로 동시에 움직이지 않게).

## 3. 확장 보기 — 시네마틱 카드

카드 클릭 시:

```
t = 0.0s    클릭한 카드가 1.0s 동안 화면 중앙으로 이동 (translate + scale 1.2)
            나머지 카드들이 0.32 불투명도로 fade
            배경에 검은 오버레이 (rgba(0,0,0,0.7)) + blur(8px)
t = 1.0s    카드가 자리잡음
t = 1.2s    카드 아래 메타데이터 fade in:
              "발신자: m."
              "오늘 만들어졌어요."
              "분위기: 늦은 오후 · 단일 광원 · 린넨"
t = 1.8s    내보내기 옵션 3개가 차례로 fade in (200ms 간격)
t = 2.6s    "─ 보내기 ─" Beacon 등장
t = 3.0s    "닫기" 링크 등장
```

ESC 또는 "닫기" 클릭 시 역순으로 600ms 안에 갤러리로 복귀.

### 보내기 시뮬레이션

"보내기" Beacon 클릭 시 (실제 발신은 일어나지 않음 — 데모이므로):

```
1. Beacon이 0.5s 동안 rose 톤으로 따뜻해짐
2. 확장된 카드가 1.4s 동안 검은 필드로 페이드
3. 단 한 줄이 등장: "잘 갔어요."
4. 1.6s 머묾
5. 또 한 줄: "다른 사람의 자리에 도착했어요."
6. 1.6s 후 모든 것이 페이드 아웃
7. 갤러리로 복귀
```

## 4. 세 가지 내보내기 (Export)

`sharing.md` §2 의 세 가지 포맷:

| 옵션 | 한국어 라벨 | 사양 |
|---|---|---|
| Live web | (이번 데모에는 포함 안 함) | URL: `taste.os/c/<token>` |
| PNG | 이미지로 두기 | 2400×3360 (5:7) PNG, 5MB 미만 |
| Film | 영상으로 두기 | 24초 9:16 MP4 (6개 4초 scene + 1초 sigil + 1초 closing) |
| Print | 종이로 두기 | 4×6 inch PDF + crop marks, 종이 친화 잉크 |

데모에서는 클릭 시 *작은 acknowledgment 토스트* 만 보여줍니다:
- 이미지로 두기 → *"이미지로 만들고 있어요…"* (실제 PNG 다운로드는 v1.1)
- 영상으로 두기 → *"24초짜리 짧은 영상으로 천천히 만들고 있어요…"*
- 종이로 두기 → *"인쇄용 종이로 준비하고 있어요."*

(실제 제품에서는 HTML2Canvas + FFmpeg.wasm 또는 server-side 렌더링을 사용합니다.)

## 5. 정서적 공명 (Emotional Resonance)

페이지의 가장 중요한 섹션. 좋아요/댓글이 없는 대신 *세 가지 응답 방식* 이 있습니다.

### 1. 머무름 (Dwell)

받은 사람이 카드를 30초 이상 본 채로 머물면, 발신자에게 *조용한 한 줄* 이 도착합니다:

> *이 분위기에 오래 머물렀어요.*

- 누가 봤는지는 안 알려줘요 — 그저 *누군가가 머물렀다* 만
- 카운트 없음 — 한 번 또는 여러 번, 시스템은 *횟수를 알려주지 않아요*
- 알림 없음 — 사용자가 다음에 페이지에 *돌아왔을 때* 그 자리에서 한 번 보입니다

### 2. 공명 (Resonance)

받은 사람이 *자기 카드 한 장* 을 답으로 보냅니다. 좋아요 한 번이 아니라 — *자기의 한 부분을 똑같이 내어주는* 일.

> *비슷한 감정의 결이 느껴졌어요.*

답으로 온 카드는 발신자의 *Drift / 자꾸 돌아오는 것들* 에 자그마한 echo로 등록됩니다 — 같은 분위기의 카드가 들어오면, 시스템이 그것을 *기억* 합니다.

### 3. 답장 (Reply)

받은 사람이 *한 줄* 을 직접 적어 답으로 둡니다. 좋아요 대신, 코멘트 대신 — *작은 편지*.

```
─ 답장
   "당신의 빛이 내 안에서도 잠시 머물렀어요."
```

답장은 *공개되지 않아요*. 발신자만 봐요. 카드 전체에 코멘트가 *쌓이지* 않아요.

### 시각적 표현

세 개의 작은 패널이 가로로 배치 (모바일은 세로 스택). 각 패널:
- 응답 이름 (display sm italic)
- 작은 예시 텍스트
- 헤어라인 구분

## 6. The Room — 공개 프로필 미리보기

페이지 하단에 *"당신의 자리도 만들 수 있어요"* 섹션. The Room (per `sharing.md` §4) 의 작은 미리보기.

```
┌──────────────────────────────────────────────┐
│  ◌                                            │
│                                               │
│                                               │
│              m.                               │
│                                               │
│              옻칠한 황혼                       │
│                                               │
│  ─────────                                    │
│                                               │
│  16:00 · 북향 · 오크 · 린넨 · 황동             │
│                                               │
│  ▮ ▮ ▮ ▮ ▮                                    │
│                                               │
│  ─────────                                    │
│                                               │
│  "큰 빛보다, 작은 빛이                         │
│   오래 가는 걸 알아요."                        │
│                                               │
│                                               │
│  ─ 카드 두기 ─                                 │
│                                               │
└──────────────────────────────────────────────┘
```

이건 *데모의 데모* — 실제로는 사용자의 `taste.os/<handle>` URL에 사는 페이지의 미니어처 표현. 가까이 보면 *방* 처럼 느껴지게 디자인.

설명 한 줄:

> *이 페이지는 누군가가 *당신의 이름* 으로 찾아왔을 때 보는 풍경이에요. 피드가 아니라, 방이에요.*

## 8. 구현 노트

### 파일 구조

```
taste-os/share/
├── index.html
├── style.css
└── script.js
```

### 데모와 실제 제품의 차이

| 영역 | 데모 (이 페이지) | 실제 제품 |
|---|---|---|
| 발신자 | 하드코딩 "m." | 사용자 계정 |
| 카드 4종 | 미리 정해진 샘플 | 사용자의 실제 Genome 으로부터 동적 생성 |
| 보내기 | 시뮬레이션 (애니메이션만) | 실제 발신 (서버 + 이메일/링크) |
| 내보내기 | acknowledgment 토스트만 | 실제 PNG/MP4/PDF 다운로드 |
| 머무름 추적 | 없음 (개념만 설명) | 받은 사람 페이지의 IntersectionObserver + 30s 타이머 |
| Room 미리보기 | 정적 미니어처 | 사용자 URL `taste.os/<handle>` 의 실제 페이지 |

### 데이터 모델 (실제 제품용)

`sharing.md` §1.3 의 `Card` 타입을 따릅니다. 추가로:

```ts
type Resonance =
  | { kind: 'dwell';     viewedAt: Date }
  | { kind: 'echo';      cardId: string;  // 답으로 보낸 카드
                         from: UserId }
  | { kind: 'reply';     text: string;
                         from: UserId;
                         writtenAt: Date };
```

발신자는 자기 카드에 대한 모든 Resonance를 *받는다* — 다른 사람들에게는 보이지 않음.

## 닫는 말

좋아요와 댓글은 *빠른 응답* 의 도구예요. 머무름·공명·답장은 *깊은 응답* 의 도구입니다. 빠른 응답은 *많이* 와요. 깊은 응답은 *드물게* 오고, 그래서 *기억* 에 남아요.

이 페이지는 *드문 응답* 을 위한 도구예요. 많은 사람의 좋아요보다 한 사람의 *비슷한 감정의 결* 한 줄이 더 멀리 가는 시스템 — 이걸 디자인의 핵심으로 두었어요.
