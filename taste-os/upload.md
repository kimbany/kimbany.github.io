# Taste OS — Upload System / 두기

> 파일을 *업로드* 하는 게 아니에요. 좋아하는 것을 *방 안에 두는* 거예요.

이 문서는 **이미 온보딩을 마친 사용자가 새로운 증거를 더하는** 표면을 정의합니다. `field.md`의 *"add to your taste / 더 두고 싶은 게 있다면"* 입구를 통해 들어오는 곳이에요. 온보딩의 큐레이션된 카드 대신, 여기서는 사용자가 *진짜 자기 것* 을 가지고 옵니다.

함께 읽기: `field.md` (Field에서 이 표면으로 들어가는 입구), `genome.md` (저장된 증거가 L1 임프레션 층에 어떻게 영향을 주는지), `voice.md` (한국어 보이스), `pipeline.ko.md` §1 (실제 제품에서의 업로드 파이프라인).

구현: `taste-os/upload/index.html` + `style.css` + `script.js`.

## 0. 은유 — 클라우드가 아니라 방

대부분의 업로드 UI는 *클라우드 저장소* 의 은유 위에 만들어집니다 — 폴더 트리, 파일 사이즈 표시, 진행률 바, "Drag files here" 점선 사각형. 이 모두는 *어딘가 멀리 있는 곳에 파일을 보낸다* 는 가정 위에 있어요.

Taste OS의 업로드는 다른 은유 위에 있습니다 — **방**. 사용자는 무언가를 *멀리 보내지* 않아요. *자기 자신의 자리* 에 두는 거예요.

### 다섯 가지 약속

1. **"업로드" 라는 단어는 어디에도 없어요.** 동사는 *두다*, 명사는 *둔 것* / *자리*.
2. **파일 사이즈, 형식, 진행률은 보이지 않습니다.** 시스템이 알아서 처리해요. 사용자는 그것을 알 필요가 없습니다.
3. **드롭존 점선 사각형은 없어요.** 화면 전체가 드롭존입니다. 드래그하면 화면 전체가 살짝 따뜻해질 뿐이에요.
4. **첫 번째 아이템부터 *카드* 입니다.** 파일 아이콘 + 파일명 형태로 표시되지 않아요. 즉시 그 자체로 보입니다 — 이미지면 이미지로, 인용이면 종이 카드로.
5. **삭제는 *내려놓기*.** 휴지통도 없고, "정말 삭제할까요?" 다이얼로그도 없어요. 한 번의 입력으로 사라지고, 600ms 안에 한 번 더 누르면 되돌릴 수 있어요.

### 절대 없는 것

- "Drag & drop files here" 점선 사각형
- 파일 사이즈, MIME 타입 표시
- 진행률 바 (%)
- "X / 10 uploaded" 카운터
- 폴더, 컬렉션, 태그 (분위기 태깅은 카드별 — 폴더 시스템 아님)
- 휴지통 아이콘
- "Are you sure?" 확인 다이얼로그

## 1. 표면 구조

화면은 세 층으로 구성됩니다:

```
                                                                            
   ◌    당신의 자리에 둘 것이 있어요?              지금까지 7개를 두셨어요.  
                                                                            
                                                                            
                                                                            
                                                                            
       (드래그하거나, 아래에서 골라보세요)                                  
                                                                            
                                                                            
   ┌────────────────────────────────────────────────────────────────────┐  
   │                                                                    │  
   │           ┌──────┐         ┌──────┐                                │  
   │           │      │         │      │                                │  
   │           │ img  │         │ disc │                                │  
   │           │      │         │      │                                │  
   │           └──────┘         └──────┘                                │  
   │                                                                    │  
   │                  ┌──────────────┐                                  │  
   │                  │ "..."         │     ┌──────┐                    │  
   │                  │ "..."         │     │ img  │                    │  
   │                  └──────────────┘      └──────┘                    │  
   │                                                                    │  
   └────────────────────────────────────────────────────────────────────┘  
                                                                            
                                                                            
          [이미지]   [소리]   [말]   [공기]                                
                                                                            
                                                                            
```

### 세 층

1. **위 — 헤더.** 작은 안내 + 카운터. 양식이 아니라 인사예요.
2. **가운데 — 자리(Canvas).** 사용자가 둔 아이템들이 떠다닙니다. 무한 스크롤 아니에요 — 자리의 크기는 사용자가 둔 만큼만.
3. **아래 — 모드 선택기.** 4개의 작은 단어 버튼. 가장 자주 쓰는 건 *이미지*, 그래서 그게 가장 왼쪽에.

### 자리의 시각적 성격

- 검은 필드, 부드러운 그레인
- 같은 4개의 빛 구체가 떠다님 (랜딩과 동일)
- 아이템들은 절대 위치로 배치되며, 약간씩 (-2° ~ +2°) 회전됨
- 아이템끼리 가까이 있으면 미세하게 *서로를 향해 끌리는* 시각적 인력 (실제로는 CSS transform만)

## 2. 네 가지 입력 방식

### 2.1 이미지

세 가지 방법:
1. **파일을 화면에 드래그.** 화면 전체가 따뜻해지고, 놓는 순간 그 위치에 카드 settled.
2. **"이미지" 버튼 탭.** 시스템 파일 선택기가 열림.
3. **클립보드 붙여넣기 (Ctrl/Cmd+V).** 클립보드에 이미지가 있으면 자리 중앙에 추가.

여러 장 동시 업로드 가능 — 한 번에 모두 드래그하면 100ms 간격으로 한 장씩 등장합니다 (자리에 떨어지는 종이처럼).

### 2.2 소리

"소리" 버튼을 누르면 작은 입력 패널이 자리 아래에서 슬라이드 업:

```
                                                              
       곡 이름이나 링크. 무엇이든.                            
                                                              
   ┌──────────────────────────────────────────────┐          
   │ Sigur Rós — Glósóli                          │          
   └──────────────────────────────────────────────┘          
                                                              
                          ─ 두기 ─                            
                                                              
```

- 텍스트 입력. URL 자동 감지 (Spotify, Apple Music, YouTube)
- 두기를 누르면 vinyl-disc 카드가 자리에 떨어짐
- 파일 업로드는 v1.1에서 — 데모에서는 텍스트만

### 2.3 말

"말" 버튼을 누르면 비슷한 입력 패널:

```
                                                              
       기억에 남은 한 줄.                                     
                                                              
   ┌──────────────────────────────────────────────┐          
   │ 어떤 것들은 한 번 보는 걸로 충분해요.       │          
   └──────────────────────────────────────────────┘          
                                                              
                          ─ 두기 ─                            
                                                              
```

- textarea, 최대 140자
- "두기" → 종이 카드 모양으로 자리에 떨어짐

### 2.4 공기 (분위기)

가장 추상적인 입력. 사용자가 *느낌의 단어들* 을 직접 둘 수 있어요.

"공기" 버튼을 누르면:

```
                                                              
       어떤 분위기가 머물고 있어요?                          
                                                              
   ┌──────────────────────────────────────────────┐          
   │ 비 온 일요일 오후의 정적                     │          
   └──────────────────────────────────────────────┘          
                                                              
                          ─ 두기 ─                            
                                                              
```

- 짧은 자유 입력 (최대 60자)
- 카드는 거의 텍스트만 있는 작은 카드로 떨어짐 — 시처럼

### 입력 패널의 등장과 사라짐

- 모드 버튼 클릭 → 자리 아래에서 패널이 1.0s 들숨으로 등장
- "두기" 또는 ESC → 1.4s 날숨으로 사라짐
- 패널이 열려 있는 동안 자리는 0.65 불투명도로 dimmed
- 화면 어두워진 부분 클릭하면 패널 닫힘

## 3. 빈 상태와 첫 두기

### 빈 상태 — 자리에 아무것도 없을 때

화면 중앙에 한 줄, 그 아래 작은 안내:

```
                                                                            
                                                                            
                                                                            
                                                                            
                                                                            
                                                                            
                                                                            
                  당신의 자리에                                             
                  둘 것이 있어요?                                           
                                                                            
                                                                            
                  여기로 드래그하거나, 아래에서 골라보세요.                 
                                                                            
                                                                            
                                                                            
                                                                            
          [이미지]   [소리]   [말]   [공기]                                
                                                                            
                                                                            
```

display-md italic이 가장 큰 요소. 빈 자리도 그 자체로 의미가 있어요 — *"비어 있는 자리도 풍경의 일부다."*

### 첫 아이템이 떨어진 후

빈 상태의 안내가 사라지고, 헤더가 작아지면서 상단으로 올라감. 자리는 이제 아이템들의 무대가 됩니다.

상단 카운터에 한 줄:

> *"잘 두었어요."*

이 한 줄은 첫 아이템이 떨어진 후 4초만 보이고 mist 색으로 페이드 아웃됩니다.

## 4. 아이템 카드 — 모양과 물리

각 입력 타입은 자기만의 카드 형태를 가집니다.

### 4.1 이미지 카드

```
   ┌──────────────────┐
   │                  │
   │                  │
   │   [user image]   │
   │                  │
   │                  │
   │                  │
   └──────────────────┘
   ─ ─ ─ ─ ─ ─ ─
   3분 전
```

- 4:5 종횡비 (200×250 정도)
- 1px hairline 보더, `ash` 색
- 약간의 무작위 회전 (-2° ~ +2°)
- 이미지가 부드럽게 잠시 saturate(0.92)에서 saturate(1)로 페이드
- 호버 시 2px 위로 + 색온도 +120K

### 4.2 소리 카드

```
   ┌──────────────────┐
   │       ◉          │
   │      ◯ ◯         │
   │     ◯ · ◯        │
   │      ◯ ◯         │
   │       ◯          │
   │                  │
   │   Glósóli        │
   │   Sigur Rós      │
   └──────────────────┘
```

- 4:5 종횡비
- 상단: 디스크 그래픽 (동심원 + 가운데 점) — 12초 주기로 한 바퀴 회전
- 하단: 곡명 + 아티스트 (URL이면 도메인만)

### 4.3 말 카드

```
   ┌──────────────────────┐
   │                      │
   │  "어떤 것들은        │
   │   한 번 보는         │
   │   걸로 충분해요."    │
   │                      │
   │                      │
   └──────────────────────┘
```

- 5:3 종횡비 (가로로 더 긴 종이 모양)
- 약 4% pearl 톤이 도는 미세한 종이 텍스처 (subtle radial gradient)
- 인용은 italic 디스플레이 세리프
- 따옴표 없음 (인용 부호는 카드 자체가 인용이라는 뜻이니까)

### 4.4 공기 카드

```
   ┌────────────────────┐
   │                    │
   │  비 온 일요일      │
   │  오후의 정적       │
   │                    │
   └────────────────────┘
```

- 1:1 정사각 가까운 비율
- 텍스트만 — 보더는 더 흐림
- 폰트는 italic 디스플레이 세리프, 더 작게

### 카드 공통 행동

- 드롭 시 settle 물리 (2% 오버슈트, 1.2s 정착)
- 자리에 떨어진 직후 약 800ms 동안 ember 글로우 (방금 도착했다는 표시)
- 호버 시 2px 위로 + 분위기 칩 자리가 카드 아래 fade-in
- 클릭 시 → 확장 보기 (§6)

### 카드의 배치 규칙

처음에는 무작위 위치로 떨어집니다. 하지만 같은 *타입* 끼리 미세하게 끌립니다 — 이미지는 이미지끼리 (약 0.3% 인력), 말은 말끼리. 결과적으로 자리가 부드럽게 *구역* 으로 나뉘어요.

10개 이상 두면 자리가 살짝 부족해질 수 있는데, 그때 카드들이 더 작아지진 않습니다 — 자리가 *세로로 자랍니다*. 스크롤 가능한 자리.

## 5. 분위기 태깅

각 카드는 *분위기 칩* 으로 태깅할 수 있어요. 호버 시 카드 아래에 12개의 큐레이션된 분위기 칩이 등장합니다.

### 12개의 큐레이션된 분위기

3개의 줄, 각 줄 4개:

```
   새벽    아침    오후    황혼
   정적    친밀    멀리    혼자
   따뜻    차가움  오래된  단일 광원
```

### 인터랙션

- 클릭 → 칩이 ember 톤으로 채워짐, 카드 자체도 살짝 따뜻해짐
- 한 카드에 최대 5개 칩
- 다시 클릭 → 해제

### 카드 호버 안에서의 표시

```
   ┌──────────────────┐
   │                  │
   │   [image]        │
   │                  │
   └──────────────────┘
    [황혼] [정적] [+]    ← 호버 시 등장; 선택된 칩은 채워짐
```

기본 상태에서는 보이지 않다가, 카드 호버 시 200ms 페이드 인. 칩이 0개인 카드는 호버 시 모든 칩이 빈 상태로 등장; 1개 이상 선택된 카드는 호버 안 해도 카드 아래에 작은 점이 보임 (칩 개수만큼).

### 분위기는 강요되지 않습니다

칩을 누르지 않아도 괜찮아요. 카드는 *무분위기* 상태로도 자리에 존재할 수 있습니다 — 시스템이 나중에 추론해도 되고, 영원히 추론 안 되어도 돼요. 분위기 칩은 *허락* 이지 *과제* 가 아닙니다.

## 6. 아이템 확장 보기

카드를 클릭하면 *시네마틱 확장 보기* 가 열립니다.

```
                                                                            
                                                                            
                                                                            
                                                                            
                                                                            
                   ┌────────────────────────────┐                          
                   │                            │                          
                   │                            │                          
                   │       [user image]         │                          
                   │                            │                          
                   │                            │                          
                   │                            │                          
                   │                            │                          
                   └────────────────────────────┘                          
                                                                            
                   3월 14일 오후 4시에 두었어요.                            
                                                                            
                   분위기:  황혼 · 정적                                    
                                                                            
                                                                            
                            ─ 닫기 ─       ─ 내려놓기 ─                    
                                                                            
                                                                            
```

### 시네마틱 확장의 안무

```
사용자 클릭
   ↓
0ms        다른 모든 카드가 0.32 불투명도로 dimmed (1.0s)
           검은 오버레이가 자리 위로 0.65 불투명도로 fade in
200ms      클릭한 카드가 자리에서 이탈 — 화면 중앙으로 이동 (1.0s settle)
1200ms     카드가 1.6배 확대 (1.0s)
2200ms     아래에 메타데이터 + 분위기 fade-in
           ─ 닫기 ─ / ─ 내려놓기 ─ 등장
```

ESC 또는 닫기 클릭 → 역순으로 600ms 안에 자리로 복귀.

## 7. 내려놓기 (제거)

확장 보기 안에서 **─ 내려놓기 ─** 를 누르면:

```
1. 카드가 0.6s 동안 0.5 불투명도로 페이드
2. 동시에 화면 하단 가운데에 작은 줄 등장:
   "내려놓았어요. (되돌릴까요?)"
3. 7초 동안 이 메시지가 머묾
4. 그 안에 클릭 → 카드가 자리로 복귀 (1.0s settle)
5. 7초 후 → 카드 영구 제거
```

휴지통도, 확인 다이얼로그도 없습니다. *되돌리기* 가 항상 가능하고, *명시적 확인* 은 결코 요청되지 않아요.

내려놓기 메시지 카피:

> *내려놓았어요. (되돌릴까요?)*

7초 후에는 메시지가 페이드 아웃되고, 카드는 정말 사라집니다.

---

## 8. 로딩 상태

이미지를 드래그해서 떨어뜨릴 때:

```
1. 파일 받음 → 자리 위에 placeholder 카드가 즉시 등장 (200ms)
2. placeholder 카드는 fog 색 + 가운데에 호흡하는 작은 점
3. FileReader가 image data URL 만드는 동안 (보통 100-400ms)
4. 데이터 준비되면 → 카드의 placeholder가 reveal blur로 실제 이미지로 교체
   (filter: blur(14px) → 0, 1.6s)
```

여러 장 한꺼번에 드롭하면 100ms씩 간격을 두고 카드가 차례로 등장 — *종이가 떨어지는 것처럼*, 동시에 우르르 떨어지지 않고.

### 큰 이미지 안내

이미지가 매우 크면 (>10MB 추정) 로딩이 길어질 수 있어요. 그런 경우 placeholder 위에 작은 한 줄:

> *"천천히 받고 있어요…"*

진행률 % 는 보이지 않습니다.

## 9. 모션 언어

### 핵심 토큰 (landing-v2와 동일)

```css
--t-fast:        0.20s;
--t-base:        0.7s;
--t-breath-in:   1.0s;
--t-breath-out:  1.6s;
--t-reveal:      1.8s;
--t-settle:      1.2s;
```

### 업로드 페이지 특수 모션

| 모션 | 어디 | 설명 |
|---|---|---|
| 카드 settle | 새 아이템 등장 | translateY 12 → 0, 2% 오버슈트, 1.2s |
| 카드 첫 글로우 | 떨어진 직후 | 0.8s 동안 ember 글로우, 페이드 아웃 |
| 호버 lift | 카드에 마우스 | translateY -2px, +120K 색온도 |
| 칩 페이드 | 카드 호버 시 | 200ms 페이드 인 |
| 확장 보기 진입 | 카드 클릭 | 위 §6의 5단 안무 |
| 입력 패널 등장 | 모드 버튼 | translateY 100% → 0, 1.0s breath-in |
| 입력 패널 종료 | 두기/ESC | translateY 0 → 100%, 1.4s breath-out |
| 드래그 hint | 화면에 파일 드래그 진입 | 자리 전체에 0.04 ember 글로우 페이드 인 |
| 내려놓기 페이드 | 카드 제거 | opacity 1 → 0.5 (0.6s), 7s 후 0 |

### 미세 모션 (계속 살아 있는 느낌)

- **빛 구체** (orbs) — 랜딩과 동일, 42초 주기
- **카드 호흡** — 자리에 있는 카드들은 매우 미세하게 ±2px 떠다님 (8s 주기, 각자 랜덤 위상)
- **디스크 회전** (소리 카드만) — 12s 주기 0.06 rad/s

## 10. 반응형

### Pocket (≤ 768px)

- 모드 선택기가 화면 하단 고정 (sticky), 4개 버튼이 가로로 동등 분할
- 입력 패널이 전체 화면 하단 모달 형태로 슬라이드 업
- 카드 종횡비는 같지만 크기가 화면에 맞춰 더 작아짐 (≈ 140×175)
- 분위기 칩은 호버 대신 *카드 탭* 으로 펼침 (다시 탭하면 닫힘)
- 확장 보기는 풀스크린

### Desk (768-1280px)

- 모드 선택기 하단 중앙 floating
- 카드 자리 그리드는 자동 배치 (CSS Grid auto-flow dense)

### Studio (≥ 1280px)

- 카드들이 더 흩어지고, 각각 더 큰 무작위 회전 (±3°)
- 호버 효과가 더 풍부 (확실히 들림 + 그림자가 약하게 보임)

### 정적 미리보기 (이 저장소)

```
taste-os/upload/
├── index.html
├── style.css
└── script.js
```

데이터는 메모리에만 저장. 새로고침 시 초기화 (방을 새로 들어오는 것처럼).

### 아이템 데이터 모델

```ts
type UploadItem = {
  id: string;                              // ulid
  type: 'image' | 'music' | 'quote' | 'atmosphere';
  content: ItemContent;
  atmosphere: Set<string>;                 // chip ids
  x: number;                               // canvas position (px or %)
  y: number;
  rotation: number;                         // -3 to +3 deg
  addedAt: Date;
};

type ItemContent =
  | { type: 'image';      dataUrl: string; name?: string }
  | { type: 'music';      value: string; source: 'url' | 'text' }
  | { type: 'quote';      text: string }
  | { type: 'atmosphere'; text: string };
```

### 실제 제품에서의 업로드 처리

`pipeline.ko.md` §1을 따릅니다:

1. 클라이언트 측 검증 (형식, 크기 ≤ 8MB)
2. 옵티미스틱 미리보기 (FileReader 또는 createObjectURL)
3. 백그라운드 업로드 (presigned URL → S3, 사용자 키로 암호화)
4. 정규화 (sRGB, 최대 2048px, -14 LUFS 오디오)
5. perceptual hash로 중복 제거
6. `Evidence` 객체 생성, DB 기록

이 미리보기는 1-2단계만 실행합니다. 실제 업로드는 일어나지 않아요.

## 닫는 말

업로드 UI는 *기능* 으로 봤을 때 가장 단순한 화면입니다. 파일을 받고 표시하는 것. 그런데 *경험* 으로 봤을 때는 — 사용자가 자기 자신의 *사적인 것* 을 처음으로 시스템에 내미는 순간이에요. 그 순간을 *클라우드 저장소* 의 어휘로 응대하면, 신뢰는 거기서 끊겨버립니다.

이 화면이 잘 만들어진다면, 사용자는 *파일을 업로드했다* 가 아니라 *내 방에 무언가를 두었다* 고 느낍니다. 그게 전부예요.
