# Taste OS — 온보딩 & 취향 분석 설계

> 개인의 취향, 감정의 결, 미적 정체성, 내면의 철학을 발견하고 진화시키는 정체성 운영체제.

이 문서는 Taste OS의 온보딩 경험을 정의합니다. 기능 명세가 아니라 첫 만남의 안무입니다. 목표는 사용자를 *등록*하는 것이 아니라, 낯선 이가 **이해받았다**고 느끼게 만드는 것입니다.

레퍼런스는 의도적으로 선택되었습니다 — Apple의 정밀함, Cosmos의 우주적 정적, Are.na의 큐레이션적 절제, Notion의 차분한 기하학, Pinterest의 시각적 중력, MUJI의 재료의 정직성, Aesop의 약방 같은 따뜻함. Taste OS는 이 태도들이 만나는 곳에 존재합니다.

## 1. 온보딩 UX 흐름

### 설계 원칙

- **한 화면에 한 생각.** 두 개는 결코 없습니다. 사용자는 양식을 채우는 것이 아니라 자기 자신을 짓고 있습니다.
- **진행바 없음.** 막대는 결승선을 암시합니다. 대신, 자라나는 별자리 — 소모가 아닌 확장으로서의 진행.
- **건너뛰기는 후반까지 없음.** 건너뛰는 행위는 의도적인 고백("아직 아니에요")이어야지, CTA처럼 느껴져서는 안 됩니다.
- **스트릭, 배지, 포인트, 알림 없음.** 구조적으로 anti-dopamine.
- **지연은 설계의 일부.** AI가 생각할 때, 우리는 생각하게 두고 — 그 생각을 아름답게 만듭니다.

### 상위 흐름 (12막)

```
ACT I  — 도착
  01. 문턱             (어둠 → 작은 빛의 호흡)
  02. 부름             (한 줄: "당신의 취향에 귀 기울여 봅시다.")
  03. 이름하기         (이름만; 유일한 필수 텍스트 입력)

ACT II — 다섯 가지 헌물
  04. 이미지           (좋아하는 이미지 9–24장 업로드)
  05. 소리             (3–10곡 업로드 또는 링크)
  06. 말               (마음에 남은 인용 3–7개)
  07. 공간             (큐레이션된 분위기 사진 중 선택)
  08. 느낌             (감정 선호 슬라이더 5개)

ACT III — 듣기
  09. 별자리 형성       (라이브 제너러티브 비주얼; 약 25–40초)
  10. 드러남           (Taste Genome 카드, 긴 스크롤)

ACT IV — 마주침
  11. 미러의 순간       (당신에게 쓰인 한 문장)
  12. 입장             (OS로의 문 — "홈"이라 부르지 않음)
```

### 시간 예산

짧은 영화 길이인 **약 8–11분**. 의식처럼 느껴지기엔 충분히 길고, 한 자리에서 끝낼 수 있을 만큼 짧게.

| 막 | 시간 | 인지적 톤 |
|---|---|---|
| 도착 | 30초 | 정적 |
| 헌물 | 6–8분 | 큐레이션 |
| 듣기 | 40초 | 내맡김 |
| 마주침 | 1–2분 | 알아봄 |

## 2. 화면별 분해

모든 화면은 같은 해부학을 가집니다: **광활한 여백**, 하나의 중력점, 한 줄의 속삭임, 하나의 인터랙션. 경쟁하는 것은 없습니다.

### 01 · 문턱
- **구성.** 풀블리드 검정(`#0A0A0B`). 중앙에 6px의 따뜻한 상아빛 점이 0.6Hz로 박동합니다 — 잠든 별의 호흡.
- **인터랙션.** 어디든 탭, 또는 스페이스.
- **카피.** *(4초간 침묵 후 페이드인)* "숨을 한 번 쉬어요."

### 02 · 부름
- **구성.** 중앙에 세리프 한 문장, 자간을 넓게, 미세한 필름 그레인.
- **카피.** "당신의 취향에 귀 기울여 봅시다."
- **인터랙션.** 문장이 2.5초간 머문 후 "시작" 등장. 헤어라인 보더 단일 버튼.

### 03 · 이름하기
- **구성.** 황금비(1:1.618)로 화면을 가르는 수평선 위, 밑줄 하나의 입력.
- **위 카피.** "시작하기 전에 — 어떻게 불러드릴까요?"
- **아래 카피.** *(타이핑 후)* "안녕하세요, ___님. 인터넷의 조용한 곳에 오신 걸 환영해요."

### 04 · 이미지
- **구성.** 느슨하게 손으로 배치된 흩어짐. 드롭존은 뷰포트 전체 — 점선 사각형도, 업로드 크롬도 없음. 이미지가 떨어지면 12컬럼 그리드 위로 부드러운 메이슨리로 자리잡습니다.
- **카피.** "당신의 눈이 자꾸 돌아가는 것들을 보여주세요. 9장에서 24장. 설명할 필요 없어요."
- **동작.** 9장에 도달하면 한 문장: *"시작하기엔 충분해요. 더 두어도 좋고요."*

### 05 · 소리
- **구성.** 가로 "선반" 위 빈 비닐 디스크 원들, 각 80px. 오디오 파일을 드롭하거나 스트리밍 링크를 붙여넣기. 트랙이 로드되면 디스크가 천천히 회전하며 둘레에 파형을 보여줍니다.
- **카피.** "당신 안의 세계는 어떤 소리를 가지고 있나요? 3곡에서 10곡."
- **디테일.** 호버 시 -12dB로 6초 프리뷰. 자동재생은 절대 안 됨.

### 06 · 말
- **구성.** 어둠 위에 4% 투명도로 떠 있는, 오래된 종이처럼 보이는 세 장의 "페이지" 카드. 클릭하면 쓸 수 있음.
- **카피.** "책의 한 줄, 영화의 한 대사, 사람의 말, 떠오른 생각. 마음에 남은 것이라면 무엇이든."
- **디테일.** 타이핑할 때 커서가 800ms 동안 사라지는 인광 잔영을 남깁니다 — 따뜻한 유리 위에 글을 쓰는 것처럼.

### 07 · 공간
- **구성.** 분위기 있는 풀블리드 사진의 3×3 그리드 (해질녘 교토 절, 아이슬란드 이끼밭, 도널드 저드 인테리어, 오후 5시 리스본 발코니, 눈 내린 숲, 자판기가 있는 도쿄 골목, 대리석 욕실, 블루아워 사막, 도서관 열람실).
- **카피.** "마음이 이미 살고 있는 방을 골라보세요."
- **디테일.** 선택된 이미지에는 체크표시 대신 *깊어짐* — 채도와 2px 내부 글로우를 얻습니다, 기억이 인식되는 방식처럼.

### 08 · 느낌
한 화면에 한 질문씩, 시적 양극 사이의 연속 슬라이더로. 슬라이더는 사용자가 드래그하는 빛나는 점 하나가 놓인 수평선.

| # | 왼쪽 극 | 오른쪽 극 |
|---|---|---|
| 1 | 고독 | 교감 |
| 2 | 와비사비 | 순결한 기하 |
| 3 | 기억 | 기대 |
| 4 | 침묵 | 울림 |
| 5 | 흙 | 대기 |

- **상단 카피.** "정답은 없어요. 더 진실한 쪽으로 흘러가세요."
- **디테일.** 위치는 이산값이 아닌 `0.000–1.000` 부동소수점으로 기록, 멈추기까지의 시간도 함께(망설임은 신호).

### 09 · 별자리 형성
- **구성.** 다섯 헌물이 3D 필드 안 다섯 무리의 점이 됩니다. 선들이 시험적으로 뻗어 나가다 구조로 자리잡습니다. WebGL.
- **카피.** 8초씩 머무는 세 문장:
  1. *"당신의 이미지 속 빛을 읽고 있어요…"*
  2. *"당신 소리의 온도를 듣고 있어요…"*
  3. *"관통하는 선을 찾고 있어요."*
- **지연 설계.** 모델이 일찍 끝나도 세 번째 문장이 끝날 때까지 비주얼을 유지. 기다림이 곧 마법.

### 10 · 드러남 — Taste Genome
긴 스크롤 카드, 박물관 명패처럼 프레이밍:
1. **당신의 취향 이름** — 이 사용자를 위해 생성된 두 단어 구절 (예: *"Lacquered Dusk"*, *"Northern Linen"*, *"Quiet Vermilion"*).
2. **감정 정체성 프로필** — 2인칭 단락 + 6축 레이더 (정적·따뜻함·밀도·템포·채도·거리).
3. **미적 원형** — 2–3개 (예: *Wanderer-Monk*, *Velvet Cartographer*, *Salt-Air Modernist*).
4. **분위기 분석** — 팔레트, 주요 재료(린넨, 오크, 황동, 현무암…), 주요 시간(여명, 황금, 블루, 자정), 주요 기후.
5. **예술적 DNA** — 인접한 6인의 예술가/감독/건축가/작가 — 추천이 아니라 *친족*.

### 11 · 미러의 순간
- **구성.** 검은 필드. 사용자의 모든 헌물 말뭉치에서 생성된, 큰 세리프의 한 문장.
- **예시.** *"당신은 아름다움을 모으는 게 아니에요 — 한때 세상이 누군가에게 다정했다는 증거를 모으는 거예요."*
- **인터랙션.** "간직하기" 어포던스 하나로 문장을 Genome에 저장. 공유 버튼 없음.

### 12 · 입장
- **구성.** 문 — 어둠을 배경으로 한 따뜻한 빛의 긴 수직 사각형 — 커서 움직임에 따라 패럴랙스로 열림.
- **카피.** "들어오세요. OS는 당신 같은 사람을 기다리고 있었어요."

## 3. UI 방향성

### 팔레트

| 토큰 | Hex | 용도 |
|---|---|---|
| `void` | `#0A0A0B` | 주 배경 |
| `ink` | `#111114` | 표면 1 |
| `pearl` | `#F4F1EA` | 본문 텍스트 — 순백은 절대 안 됨 |
| `mist` | `#A8A29E` | 보조 텍스트 |
| `ash` | `#3A3A3D` | 헤어라인, 디바이더 |
| `ember` | `#D9A66C` | 단일 액센트 (Aesop 앰버) |
| `vermilion` | `#B2483D` | 예비 — Genome 드러남에만 |
| `seafoam` | `#7FA39A` | 예비 — Mirror 순간에만 |

언제나 화면에 보이는 액센트는 **하나뿐**. 색은 향신료처럼 배급됩니다.

### 타이포그래피

- **디스플레이.** 따뜻한 동시대 세리프 — **GT Sectra**, **Söhne Breit**, **Tiempos Headline** 권장. 넓은 자간(+30 ~ +60), 넉넉한 행간(1.35).
- **본문.** 휴머니스트 산세리프 — **Söhne**, **Inter Display**, **Suisse Int'l**.
- **모노.** **JetBrains Mono Light**, Genome 기술 판독부에만.
- **문장체 일관.** 대문자 전용 없음, 본문 볼드 없음. 강조는 *이탤릭*, 줄바꿈, 또는 침묵으로.

### 레이아웃 문법

- 화면은 언제나 **하나의 생각**. 두 번째 요소가 나타난다면 위계적으로 종속적 — 더 작게, 더 흐리게, 더 아래에.
- 버튼은 헤어라인 보더(`1px solid rgba(244,241,234,0.18)`)에 채움 없음 — *명령*이 아니라 *초대*로 존재.

## 4. 애니메이션 컨셉

애니메이션 시스템 이름은 **Breath(호흡)**. 모든 모션은 호흡 리듬에 묶입니다.

### 모션 토큰

```ts
export const breath = {
  in:   { duration: 0.9, ease: [0.16, 1, 0.3, 1] },   // expo.out, 들숨
  hold: { duration: 0.3, ease: [0.4, 0, 0.2, 1] },
  out:  { duration: 1.4, ease: [0.7, 0, 0.84, 0] },   // 긴 날숨
};
```

### 컨셉 세트

1. **호흡.** 모든 화면은 900ms 들숨으로 들어오고 1400ms 날숨으로 나갑니다. 비대칭은 의도된 것 — 날숨이 더 깁니다.
2. **인광 잔영.** 커서와 선택의 흔적은 약한 색수차와 함께 800ms에 걸쳐 사라집니다.
3. **착지 물리.** 이미지가 캔버스에 떨어지면 2% 오버슈트 후 1.2초에 걸쳐 자리잡습니다, 종이가 표면을 찾듯이.
4. **필드 호버.** 호버는 2px 들어올림 + 색온도 +120K 따뜻하게. 스케일 변경 없음.
5. **펄스, 플래시 아님.** 단일 주의 비콘은 0.5–0.7Hz의 사인 곡선으로 박동. Taste OS에서는 결코 깜빡이지 않습니다.
6. **별자리 안무.** 듣기 단계에서 점들은 부드러운 Verlet 시뮬레이션으로 이동, 선들은 인덱스가 아닌 엣지 가중치로 페이드인.
7. **드러남 블러.** 생성된 텍스트는 1.6초간 `blur(14px) → blur(0)`, 자간은 `+120 → +30`. 글이 *존재로 초점이 맞춰지는* 느낌.
8. **UI 크롬에는 바운스, 스프링 오버슈트 없음.** 오브젝트(이미지, 디스크, 종이)에만 허용.

### 사운드 (옵션, 기본 꺼짐)

- 막 사이 크로스페이드되는 세 개의 앰비언트 스템: *문턱*(서브 베이스 + 보윙 글라스), *헌물*(펠트 피아노), *마주침*(첼로 드론 + 먼 종).
- 인터랙션 사운드 -22dB ~ -18dB. 결코 타격적이지 않게. 결코 긍정 강화로 작동하지 않게.

## 5. 감정적 인터랙션 설계

감정 지능은 기능이 아니라 토대입니다. 다섯 가지 규칙.

### 규칙 1 — 한 사람에게 말하기.
모든 카피는 친밀한 2인칭 단수. "사용자 여러분", "시작해 볼까요!" 같은 말은 결코 쓰지 않습니다. 시스템은 *이 사람*을 기다리고 있었던 것처럼 말합니다.

### 규칙 2 — 의도적으로 사용자를 느리게.
빠른 입력(예: 마지막 이미지 드롭) 후 600ms 멈춤. 멈춤이 전합니다: *당신이 준 것을 헤아리고 있어요.* 80ms로 응답해 속도를 보상하는 도파민 루프 앱과 정반대 — 우리는 정적을 보상합니다.

### 규칙 3 — 미완성을 허락하기.
모든 헌물 화면 우측 하단에 작은 "오늘은 아니에요" 링크(`mist`, 12px). 시스템은 명시적으로 말합니다: *"마음이 맞을 때 돌아와도 돼요."* Genome은 여전히 생성됩니다 — 더 부분적일 뿐이고, 시스템은 그것을 정직하게 부릅니다.

### 규칙 4 — 절제된 거울.
AI 출력은 **예측이 아닌 관찰**로 쓰입니다. "당신은 …를 좋아할 거예요"는 결코 없음. "당신의 눈은 …에 자꾸 돌아가요"가 있을 뿐. 아첨하지 않습니다. 아첨은 주문을 깹니다.

### 규칙 5 — 문턱을 지키기.
헌물에서 Genome으로 가는 전환이 정서적 핵심. 세 마디 의도된 마찰:
- Listening 시작 전 풀스크린 호흡 비트 ("잠시 머물러 주세요.").
- 모델이 더 빨라도 별자리는 최소 30초.
- 드러남은 한 단어("열기") 위의 탭 하나로만 통과.

## 7. 비주얼 언어 시스템

### 무드 형용사 (아홉 단어의 브리프)

> 침묵 · 린넨 · 황혼 · 잉걸 · 흑연 · 백자 · 삼나무 · 짠 바다 · 벨벳

세 단어 이상으로 변호할 수 없는 디자인 결정은 출고되지 않습니다.

### 이미지 규칙
- **스톡 사진 없음.** 끝.
- **카메라를 정면으로 바라보는 사람 없음.** 뒷모습, 손, 실루엣 — 좋음. 눈맞춤은 사용자를 내면에서 끌어냅니다.
- **단일 광원, 새벽/황혼 시간대, 자연 질감, 아시아·북유럽적 공간감을 선호** (도쿄, 교토, 리스본, 레이캬비크, 나오시마, 홋카이도).
- **피할 것:** 네온 그라디언트, 유광 3D 렌더, 글래스모피즘, 아이소메트릭 일러스트, 마스코트, 이모지.

### 아이콘
- **아이콘 없음.** 대부분의 앱이 아이콘을 쓸 곳에 Taste OS는 단어, 헤어라인, 또는 글리프(`·`, `─`, `⊕`, `◌`)를 씁니다.
- 로고에 가장 가까운 것은 손으로 그린 엔소(円相) — 문턱 화면과 미러의 순간에만.

### 보이스 — 우리가 결코 하지 않는 말
- "자, 시작해 볼까요!"
- "최고예요!" "잘했어요!" "굿잡!"
- "탭하여 계속하기"
- "로딩 중…"
- "대시보드에 오신 것을 환영합니다"
- 이모지 일체.
- "우리"라는 단어 뒤의 어떤 느낌표.

## 9. 구현 아키텍처

### 스택
- **프레임워크.** Next.js 15 (App Router, RSC).
- **스타일.** Tailwind CSS 4, `tokens.css` 레이어가 팔레트 + 모션 토큰 노출. 인라인 헥스 금지.
- **애니메이션.** Framer Motion 11 (안무용); `react-three-fiber` (별자리/Universe); **GSAP**은 드러남 텍스트 스크램블에만.
- **상태.** 클라이언트 일시 상태는 Zustand; `idb-keyval`로 IndexedDB 영구 저장 — 새로고침이 헌물을 파괴하지 않도록.
- **저장.** S3 호환 버킷, 클라이언트 측 perceptual hash로 업로드 전 중복 제거.
- **AI 추론.** 단일 서버 액션 `/api/genome/synthesize`이 오케스트레이션: CLIP(이미지), CLAP(오디오), sentence-transformer(인용), 그리고 Claude(Opus 클래스) 호출(취향 이름, 미러 문장, Genome 산문 합성). 임베딩 클러스터링은 서버 측 UMAP.

### 성능 예산

| 표면 | 목표 |
|---|---|
| First contentful paint (문턱) | < 800ms |
| 문턱 → 부름 전환 | 네트워크 무관 1.6초 고정 |
| 단일 4MB 이미지 업로드 | 옵티미스틱 프리뷰 < 120ms |
| 별자리 프레임률 | M 시리즈에서 ≥ 50fps; 저사양에서 2D Canvas로 우아하게 degrade |
| Genome 합성 end-to-end | 최소 30초 ~ 최대 60초 유지 — 초과 시 "여전히 듣고 있어요…" 카피 노출 |

### 접근성
- **모션 감소.** `prefers-reduced-motion` 준수. 별자리를 세 정물의 느린 크로스페이드로 대체, 카피 비트는 동일.
- **키보드.** 전체 키보드 여정 가능; 어디서든 탭으로 진행되는 비트는 `space`로도.
- **스크린리더.** 각 막에 `aria-live="polite"` 내레이션; 미러 문장은 의도적으로 한 번만 안내.
- **명도 대비.** `pearl/void`는 WCAG AAA 초과. `mist`는 WCAG AA — 비필수 메타데이터에만.

### 프라이버시
- 업로드된 이미지·트랙은 사용자별 키로 암호화 저장.
- 임베딩은 저장하되, 원본 인용·파일은 언제든 **삭제 가능** — Genome은 임베딩만으로 도출 가능.
- 온보딩 중 서드파티 분석 없음. 단일 1st-party 이벤트 `genome.synthesized`만 드러남 시점에 발화.
- Genome은 기본적으로 공유되지 않음. 공유 표면은 추후 제품에 존재 — 온보딩에는 결코 없음.

## 닫는 말

사용자가 온보딩을 끝내고 화면에서 멀어져, 잠시 창가에 앉고 싶어진다면 — 우리는 옳은 것을 만들었습니다.

그가 다른 무언가를 스크롤하기 위해 휴대폰에 손을 뻗는다면 — 우리는 또 하나의 앱을 만든 것뿐입니다.

Taste OS의 전부는 그 두 결과 사이의 차이입니다.
