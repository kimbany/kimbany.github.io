# 판매가 설정 도우미

판매 전에 **가격과 제품코드를 정하는** 단일 HTML 웹앱입니다.

- **판매가** — 원가를 넣으면 채널 수수료 · 브랜드 포장비 · 택배비를 각각 대입해
  채널마다 얼마에 팔아야 하는지 영수증 카드로 보여 줍니다.
- **제품코드** — `MO-GP-SH-2000G-0203` 처럼 브랜드·분류·중량·입수량을 조합한
  제품코드를 만들고, 검색하고, 복사합니다.

👉 <https://invedory.com/pricing-helper/>

**모든 금액은 VAT 포함 기준입니다.** 입력칸과 결과 표기 모든 곳에 안내가 붙어 있습니다.

## 화면

```
판매가
  ├ 원가 계산      입고 단위 → 판매 단위 환산 원가
  └ 판매가 계산    채널별 판매가 역산 (결과: 채널별 영수증 카드)
제품코드
  ├ 제품코드 목록  검색 · 정렬 · 복사 · 수정 · 삭제
  ├ 제품코드 생성  드롭다운 5개로 조합, 미리보기 후 저장
  └ 분류           대분류 · 중량·수량 · 입수량 · 브랜드 (코드의 재료)
채널 기본설정       채널명 · 수수료% · 연결 브랜드
자사 브랜드
  ├ 브랜드         브랜드명 · 브랜드 코드 · 포장비
  └ 택배           택배명 · 택배비 + 기본 택배비 라디오 선택
```

## 처음 쓸 때 순서

1. **자사 브랜드 › 브랜드** — 브랜드명 · 브랜드 코드 · 포장비를 등록합니다. (예: 마담팜 / MO / 800원)
2. **자사 브랜드 › 택배** — 택배비를 등록하고 라디오로 **기본 택배비**를 지정합니다.
   (예: 일반택배 3,000원 · 제주도서 6,000원 → 일반택배를 기본으로)
3. **채널 기본설정** — 채널명 · 수수료% · 연결 브랜드를 등록합니다.
   (예: 스마트스토어 5.6% / 마담팜)
4. **판매가 › 판매가 계산** — 제품명 · 무게·수량 · 원가 · 마진율을 넣고 계산합니다.

## 원가 계산 — 단위가 다를 때

> 사과가 **3kg 9,000원**에 입고됐는데 **2kg 단위**로 팔고 싶다

입고 3kg / 9,000원, 판매 기준 2kg 을 넣으면 환산식과 **2kg 기준 원가 6,000원**이 나옵니다.
`판매가 계산으로 보내기` 를 누르면 제품명 · 원가 · 무게·수량이 판매가 계산 화면에 자동으로 채워집니다.

무게(g·kg)끼리, 개수(개)끼리만 환산됩니다. 단위가 섞이면 경고가 뜹니다.

## 판매가 계산

| 입력 | 설명 |
|---|---|
| 제품명 | 필수 |
| 무게·수량 | 필수. g / kg / 개 선택 후 숫자 |
| 입수량 | 선택. n개 ~ n개 — **표기용이며 계산에는 반영되지 않습니다** |
| 원가 | 필수. 판매 1건(1세트) 기준 · VAT 포함 |
| 택배비 | 등록해 둔 택배 항목을 드롭다운에서 선택. 기본 택배비가 미리 선택됩니다 |
| 마진율 | 필수. `+ 마진율 추가` 로 여러 개를 동시에 비교할 수 있습니다 |

### 계산식

```
판매가 = (원가 + 포장비 + 택배비) ÷ (1 − 수수료율 − 마진율)
```

- **마진율은 판매가 대비**입니다. 마진율 30% = 판매가의 30% 가 마진으로 남습니다.
- `수수료율 + 마진율 ≥ 100%` 이면 계산이 불가능하므로 카드에 **계산 불가**로 표시됩니다.
- 채널에 연결된 브랜드의 **포장비**, 드롭다운에서 고른 **택배비**가 원가에 더해집니다.

### 끝자리

- **최종 판매가 = 100원 단위 올림** (12,340원 → 12,400원)
- 그 아래 작게 **끝자리가 800원인 가격**도 함께 표시합니다.
  13,450원 → 13,800원 · 14,110원 → 14,800원 (항상 올림 방향)
- 두 가격 모두 **올림한 뒤의 실제 수수료 · 마진 · 마진율**을 다시 계산해 보여 줍니다.

### 결과 카드

채널 1개당 영수증 카드 1개. 카드 안에서 마진율별로 구분해
`원가 · 포장비 · 택배비 · 합계 원가 · 채널 수수료 · 마진 · 최종 판매가` 를 모두 표시합니다.

## 제품코드

`MO-GP-SH-2000G-0203` 을 예로 들면 이렇게 조합됩니다.

| 조각 | 뜻 | 어디서 등록 |
|---|---|---|
| `MO` | 브랜드 코드 | 자사 브랜드 › 브랜드 (또는 제품코드 › 분류 › 브랜드 생성) |
| `GP` | 대분류 코드 (포도) | 제품코드 › 분류 › 대분류 생성 |
| `SH` | 옵션분류 코드 (샤인머스캣) | 제품코드 › 분류 › 대분류 생성 |
| `2000G` | 중량·수량 | 제품코드 › 분류 › 중량·수량 생성 |
| `0203` | 입수량 2개~3개 | 제품코드 › 분류 › 입수량 생성 |

두 가지 형태로 함께 저장되고, 목록에서 각각 복사할 수 있습니다.

```
구분형코드   MO-GP-SH-2000G-0203
연속형코드   MOGPSH2000G0203
```

### 쓰는 순서

1. **분류** — 대분류(+옵션분류) · 중량·수량 · 입수량 · 브랜드를 먼저 등록합니다.
2. **제품코드 생성** — 드롭다운 5개를 골라 코드를 만듭니다. 고르는 즉시 미리보기가 뜹니다.
3. **제품코드 목록** — 만들어진 코드를 검색 · 정렬 · 복사합니다.

### 규칙

- **입수량은 두 자리씩** 붙습니다. 2개~3개 → `0203`, 10개~12개 → `1012`. **0~99 만** 등록됩니다.
- **중량 단위는 G / EA 두 개뿐**입니다. 2kg 은 `2000` + `G` 로 넣으면 `2000G` 가 됩니다.
  입력칸 아래에 `2,000 G (2kg)` 로 환산해서 보여 줍니다.
- **코드는 대문자로 저장**됩니다. `gp` 라고 넣어도 `GP` 가 됩니다.
- **옵션분류는 `+` / `−` 로 줄을 늘려 한 번에 여러 개**를 등록합니다.
  `감귤류 CT` 에 `만감 MG` · `노지감귤 NJ` · `한라봉 HL` 을 한 번에 넣을 수 있습니다.
  빈 줄은 건너뛰고, 한쪽만 채운 줄이나 코드가 겹치는 줄은 저장 전에 막습니다.
- 이미 있는 대분류에 옵션분류만 더 붙일 때는 목록의 대분류 머리에 있는
  **`+ 옵션분류`** 를 누르면 대분류명·코드가 폼에 채워집니다.
- **옵션분류 드롭다운에는 고른 대분류에 묶인 것만** 나옵니다.
- **대분류명·대분류 코드를 고치면 그 대분류에 달린 옵션분류가 모두 함께** 바뀝니다.
- **같은 제품은 두 번 만들 수 없습니다.** 브랜드 · 대분류 · 옵션분류 · 중량·수량
  네 가지가 같으면 **입수량이 달라도 같은 제품**으로 보고 기존 코드를 알려 줍니다.
  입수량이 바뀌었으면 새로 만들지 말고 그 코드를 **수정**하세요.
- **코드를 만든 뒤에도 생성 화면에 그대로 머무릅니다.** 방금 만든 코드는 화면에 남고
  드롭다운만 비워지므로 연달아 만들기 편합니다. (목록에서 「수정」으로 들어온 경우에는
  저장 후 목록으로 돌아갑니다.)
- **분류를 고치면 그 재료로 만든 제품코드가 자동으로 다시 계산**됩니다. 바뀐 건수를 알려 줍니다.

### 목록에서 할 수 있는 것

- **분류로 검색** — 제품분류 · 중량·수량 · 브랜드 · 입수량 네 가지.
  여러 개를 고르면 조건을 모두 만족하는 것만 나옵니다.
- **키워드로 검색** — 분류명 · 코드 · 옵션분류 · 브랜드 어디에든 걸리면 나옵니다.
- **정렬** — `제품코드` / `생성 날짜` 버튼을 누르면 그 기준으로, 같은 버튼을 다시 누르면 오름↔내림이 바뀝니다.
- **복사** — 행마다 구분형 · 연속형 개별 복사 버튼이 있고,
  체크박스로 여러 개를 골라 형태를 정해 한 번에 복사할 수도 있습니다.

## 저장 위치

- 채널 · 브랜드 · 택배 설정은 **Firebase Firestore** 에 저장하도록 만들었습니다.
- `index.html` 상단 `파이어베이스설정` 이 **비어 있으면 이 브라우저의 localStorage** 에 저장됩니다.
  (좌측 상단 배지가 `로컬 저장 (이 브라우저)` 로 표시됩니다.)
- Firestore 설정값을 채우면 코드 수정 없이 `Firestore 저장` 모드로 바뀝니다.

  ```js
  const 파이어베이스설정 = {
    apiKey: "...", authDomain: "....firebaseapp.com", projectId: "...",
    storageBucket: "....firebasestorage.app", messagingSenderId: "...", appId: "..."
  };
  ```

  저장 구조는 컬렉션 `pricing_helper` 아래 문서 5개입니다.
  `channels` · `brands` · `shipping` · `categories` · `product_codes`
