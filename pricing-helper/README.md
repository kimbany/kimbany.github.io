# 판매가 설정 도우미

원가를 넣으면 **채널마다 얼마에 팔아야 하는지**를 역산해 주는 단일 HTML 웹앱입니다.
채널 수수료 · 브랜드 포장비 · 택배비를 각각 대입해서 채널별 판매가를 영수증 카드로 보여 줍니다.

👉 <https://invedory.com/pricing-helper/>

**모든 금액은 VAT 포함 기준입니다.** 입력칸과 결과 표기 모든 곳에 안내가 붙어 있습니다.

## 화면

```
판매가
  ├ 원가 계산      입고 단위 → 판매 단위 환산 원가
  └ 판매가 계산    채널별 판매가 역산 (결과: 채널별 영수증 카드)
채널 기본설정       채널명 · 수수료% · 연결 브랜드
자사 브랜드
  ├ 브랜드         브랜드명 · 포장비
  └ 택배           택배명 · 택배비 + 기본 택배비 라디오 선택
```

## 처음 쓸 때 순서

1. **자사 브랜드 › 브랜드** — 브랜드와 포장비를 등록합니다. (예: 마담팜 / 800원)
2. **자사 브랜드 › 택배** — 택배비를 등록하고 라디오로 **기본 택배비**를 지정합니다.
   (예: 일반택배 3,000원 · 제주도서 6,000원 → 일반택배를 기본으로)
3. **채널 기본설정** — 채널명 · 수수료% · 연결 브랜드를 등록합니다.
   (예: 스마트스토어 5.6% / 마담팜)
4. **판매가 › 판매가 계산** — 제품명 · 무게·수량 · 원가 · 마진율을 넣고 계산합니다.

## 원가 계산 — 단위가 다를 때

> 사과가 **3kg 9,000원**에 입고됐는데 **2kg 단위**로 팔고 싶다

입고 3kg / 9,000원, 판매 기준 2kg 을 넣으면 환산식과 **2kg 기준 원가 6,000원**이 나옵니다.
`판매가 계산으로 보내기` 를 누르면 제품명 · 원가 · 무게·수량이 판매가 계산 화면에 자동으로 채워집니다.

무게(g·kg)끼리, 개수(개)끼리만 환산됩니다. 단위가 섞이면 경고가 뜹니다.

## 판매가 계산

| 입력 | 설명 |
|---|---|
| 제품명 | 필수 |
| 무게·수량 | 필수. g / kg / 개 선택 후 숫자 |
| 입수량 | 선택. n개 ~ n개 — **표기용이며 계산에는 반영되지 않습니다** |
| 원가 | 필수. 판매 1건(1세트) 기준 · VAT 포함 |
| 택배비 | 등록해 둔 택배 항목을 드롭다운에서 선택. 기본 택배비가 미리 선택됩니다 |
| 마진율 | 필수. `+ 마진율 추가` 로 여러 개를 동시에 비교할 수 있습니다 |

### 계산식

```
판매가 = (원가 + 포장비 + 택배비) ÷ (1 − 수수료율 − 마진율)
```

- **마진율은 판매가 대비**입니다. 마진율 30% = 판매가의 30% 가 마진으로 남습니다.
- `수수료율 + 마진율 ≥ 100%` 이면 계산이 불가능하므로 카드에 **계산 불가**로 표시됩니다.
- 채널에 연결된 브랜드의 **포장비**, 드롭다운에서 고른 **택배비**가 원가에 더해집니다.

### 끝자리

- **최종 판매가 = 100원 단위 올림** (12,340원 → 12,400원)
- 그 아래 작게 **끝자리가 800원인 가격**도 함께 표시합니다.
  13,450원 → 13,800원 · 14,110원 → 14,800원 (항상 올림 방향)
- 두 가격 모두 **올림한 뒤의 실제 수수료 · 마진 · 마진율**을 다시 계산해 보여 줍니다.

### 결과 카드

채널 1개당 영수증 카드 1개. 카드 안에서 마진율별로 구분해
`원가 · 포장비 · 택배비 · 합계 원가 · 채널 수수료 · 마진 · 최종 판매가` 를 모두 표시합니다.

## 저장 위치

- 채널 · 브랜드 · 택배 설정은 **Firebase Firestore** 에 저장하도록 만들었습니다.
- `index.html` 상단 `파이어베이스설정` 이 **비어 있으면 이 브라우저의 localStorage** 에 저장됩니다.
  (좌측 상단 배지가 `로컬 저장 (이 브라우저)` 로 표시됩니다.)
- Firestore 설정값을 채우면 코드 수정 없이 `Firestore 저장` 모드로 바뀝니다.

  ```js
  const 파이어베이스설정 = {
    apiKey: "...", authDomain: "....firebaseapp.com", projectId: "...",
    storageBucket: "....firebasestorage.app", messagingSenderId: "...", appId: "..."
  };
  ```

  저장 구조는 컬렉션 `pricing_helper` 아래 문서 `channels` · `brands` · `shipping` 3개입니다.
